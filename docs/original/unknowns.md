# 待确认事项登记表

关于原版游戏、尚未完全确认的事项都登记在这里，由 `U-###` 唯一标识。P0 的退出条件要求每一项都“已确认”，或有明确的研究计划和负责阶段（总计划 §12）。

**状态**：未确认 → 进行中 → 高概率 → 已确认；不再影响项目的标为“不再需要”。结论写在本表或链接的文档中，不在其他地方重复。
