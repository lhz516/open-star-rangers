# 原版键位冲突表

来源：光盘 `MAIN/README.TXT` 中的键位说明（已确认存在），其余键位待试玩补充。“浏览器分类”是根据总计划 §1.2 的预判，**全部需要在 Windows、macOS、Linux 实机验证**；自动化测试的合成按键不能作为证据。

分类说明：**页面可拦截** = 飞行中 `preventDefault` 即可；**全屏锁键** = 需要全屏 + Keyboard Lock（仅 Chromium）；**系统层** = 无法拦截，只能兜底。

|---|---|---|---|---|---|---|
| 开火（主炮） | Alt | Windows：单按 Alt 激活菜单栏或浏览器菜单 | 页面可拦截 | 待测 | 待测 | 待测 |
| 发射导弹 | 空格 | 页面滚动 | 页面可拦截 | 待测 | 待测 | 待测 |
| 选择导弹 | `<` `>` | 无 | 无冲突（按 `code` 识别） | 待测 | 待测 | 待测 |
