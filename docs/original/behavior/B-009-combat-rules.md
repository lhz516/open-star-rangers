#### 场景与输入

- **操作者：** agent 独自运行（[agent 独自运行](../../guides/runtime-measurement.md#agent-独自运行)）。全部游戏输入都是配方声明、由工具写入并逐条记录的[模拟器内输入](../../guides/runtime-measurement.md#模拟器内输入)：按键在飞行键盘轮询 `0x262c3` 写入 BIOS 键盘缓冲，由同一次轮询读到；主扳机为 BIOS 换档标志 Alt，在设备读取时取样（[输入轮询](../formats/executable.md#input-polling-p3-0201)）。没有宿主层输入，也不用 Computer Use。

- **配方族：** 26 可以按需拆分或合并。每次运行尽量短，因为宿主显示器的开关会使 DOSBox-X 崩溃（09）。

#### 参考钟与时间隔离

- **只用游戏时钟：** 判据只用样本、步长与游戏写入的时间字段，不用真实秒。调试器停住时，游戏计数与模拟器时间都不前进（[B-006](./B-006-simulation-timing.md#观测量)）。
- **暂停的影响：** 暂停只拉长被停的帧：09 估计逐帧段每帧约长 5 毫秒模拟器时间。这改变步长序列，但判据按每个记录的步长归一化，所以不受影响；暂停方式只影响能取到哪些区分情形。步长分布与速率统计只取稀疏暂停（能量更新、键盘轮询）的停止帧。
- **诊断用的时间：** 每个暂停的 `stop.json` 中的模拟器时间与宿主时间只用于诊断（停顿开销、与 B-006 的一致性），不进入判据。
- **隔离：** 比较窗口内不出现游戏暂停、菜单、地图、通讯、Warp 或被毁视角（玩家被毁序列除外），由窗口两端的主流程状态与视角模式核对，不符的窗口作废。
- **锚：** 窗口以两次运行各自的事件为锚，不按任务原点的绝对时刻：原版的原点含过场用时，新版不计。

#### 比较链的读法

spec 的判据要求每个链节的偏差 d 与窗口的 S 都取自同一次运行的记录：

- **截止链节：** d = 生效样本 − 锚 − P₂。生效样本与锚取自同一条链的时间字段，例如能量更新暂停时的时钟与 +0x20、开火暂停时的时钟与挂点 +0x04 的旧值；核对有效范围用的 s 取生效帧暂停时的步长。
- **帧链节：** d = Σ(sⱼ − 2)，每帧的步长取该帧的暂停。只有一帧的链节也可以由时间字段得出：导弹的“阶段 0 回调的样本 − 发射样本”取自 G 的绝对时刻（减去导弹记录的相对时长）与挂点的发射时刻；弹丸的取自“到期 − 寿命”与发射时刻。
- **按 dt 的量：** dt = 时钟 − 上次更新（+0x20），a(dt) 按 [D14](../formats/executable.md#d14-energy-updates--confirmed-code) 由同一暂停读到的操作数计算。
- **由场景决定的 S：** 几何判定的结果、触发样本、引信间隔的距离分支、受伤的时刻与伤害值，取自同一窗口的读数。随机抽取的结果，例如碎片到期时刻的随机部分、子系统 3 受损时的锁定，以各自记录的值代入，不要求与新版相同。

#### 覆盖与样本

- 至少 2 次 `complete` 的合格运行，合计满足 spec 的[采样覆盖下限](../../plan/p3/07/spec.md#对照方法与判据)，以及 [D-02 逐类判据](../../plan/p3/07/spec.md#d-02-连续行为判据)的最少样本与区分情形。预算要求更多样本时，不在下限处停止。
- **区分情形的预期：** 预实验中，重排周期 d ≥ 2 的比例约为 5%（能量更新）至 20%（主炮）；首次回调的步长不为 2 的约占三分之一；交战与爆炸场景的步长更长。区分情形不足时，优先在交战场景中补采。
- **R-10 中归表现层的部分**不计入样本，见[归表现层的观察](#归表现层的观察交-p3-12p3-14)。

#### 误差来源

| 来源 | 预实验的观测（09） | 判据中的处理 |
|---|---|---|
| 时间分辨率 | 样本每次加 2，同一运行内奇偶不变 | 相对时刻都是偶数，精确比较 |
| 截止的超出量 | 0 至（生效帧步长 − 2）；稀疏停止帧的步长 2 为 159、4 为 16、6 为 1 | 以记录的 d 归一化，并核对有效范围 |
| 重排的累积 | 10 个周期后最大 18 至 20 单位（模型估计） | 逐周期归一化 |
| 帧链节 | 每帧 −2 至（s − 2）；步长可为 0 | 以记录的各帧步长归一化 |
| 输入取样边界 | 键盘轮询间隔至少 18 单位、设备读取至少 8 单位；按下 Alt 到第一发为 6 或 8 单位 | 窗口以事件为锚；从取样帧到首个效果在单次转移层核对；取样节奏归 P3-05 |
| 暂停的扰动 | 逐帧段每帧约长 5 毫秒模拟器时间 | 只改变步长序列，判据不受影响；不做分布统计 |
| 运行间离散 | 九次启动中有三种开局时钟状态 | 独立性规则；每个窗口按自己的 S 与 d 判定 |
| 随机数 | 原版与新版的序列不同 | 抽取结果作为 S 代入；分布在单次转移层按支持集核对 |
| 场景不同 | 新版没有自动驾驶（G-09）与 AI（P3-08），不重现原版的交战过程 | 事件锚与配对条件；轨迹只做单次转移核对 |
| 浮点与超越函数 | f32 写回；FSIN、FCOS、FPATAN | spec 中单次转移层的连续数值 |
| cycles | 步长随 cycles 与场景负荷变化 | 判据与 cycles 无关；结论只适用于 fixed 40000（U-021） |

#### 判据

判据以 spec 的 [D-02 连续行为判据](../../plan/p3/07/spec.md#d-02-连续行为判据)为准，本页不另立。要点：

- 新版的值等于按已确认规则在 2 单位步长下合成的值，原版的值等于同一规则按原版记录的偏差合成的值，两者都精确成立，没有残余容差；确定性的分支由规则从原始操作数推出，不取自被测运行。
- 跨版本的结论只来自配对窗口（规则参数、工作条件与分支序列相同）；起点状态或随机结果不可能相同的部分，只比较与其无关的量或使用 spec 写明的界。
- 已批准的差异单列，不判为不一致。
- 窗口按事先写定的规则机械选取，并列出每个排除的原因。
- 每类须出现区分情形；单次转移层的连续数值按 spec 的允许误差，边界样本不计入。
- 只有全部样本都满足才判为“一致”；任一样本不满足即为“不一致”，不放宽判据，也不为求通过而重做。
