# B-002 练习模式与玩家被毁流程

- **状态**：本次试玩中的敌方类别、通讯/Warp 无响应和被毁流程已确认；成功条件、完整敌方集合、模式到 SCCT/SCEN 的精确对应未确认。
- **适用范围**：用户于 2026-10-03 试玩的练习模式；难度、循环次数及是否修改基准设置未记录，不外推到战役模式。
- **证据**：用户同日试玩反馈及本地截图。动态过程依据用户观察，静态截图不能单独证明按键无响应或自动视角切换。

## 观察结果

| 项目 | 结论与置信度 | 证据及限制 |
|---|---|---|
| 敌方类别 | **已确认（本次观察）**：用户报告五种敌方单位，超过两种；不是全量枚举 | 本地截图 `local/StarRang/captures/srangers_020.png`、`srangers_018.png`、`srangers_028.png`、`srangers_046.png`、`srangers_047.png`；机型名称不复制到跟踪文档 |
| 友军/僚机 | **已确认（本次观察）**：用户未遇到友军或僚机 | 不据此断言战役不生成僚机，也不关闭 U-023 |
| 基地/通讯 | **已确认（本次观察）**：用户未发现基地，按 `C` 无响应 | 不是所有距离、目标或模式下的穷举测试 |
| Warp | **已确认（本次观察）**：按 `W` 无响应 | 未报告地图 `M` 的测试；不据此推导所有地图功能不可用或具体输入门禁 |
| 成功/结束条件 | **未确认**：最后一类遭遇未被击败，未观察到成功结果 | 不推断击败全部敌方就会成功，也不推断练习模式没有结束条件 |
| 被毁流程 | **已确认（一次用户观察）**：临近被毁时自动切到机外第三视角，显示玩家飞船爆炸，然后进入失败页面 | 页面由 `local/StarRang/captures/srangers_049.png` 核对；切换阈值、时长和帧数未测量 |

### 截图对应限制

本地核对发现用户列出的第二项和第四项与截图里的目标标签不一致；`srangers_046.png` 与 `srangers_047.png` 显示同类目标。截图仍支持至少四类不同目标，但不能当作五种机型各一张的完整映射。第五类依据用户观察保留，精确名称到截图及 M2ID 槽位的绑定待核对；不从外形猜测条目身份。

## 测量方法与后续验证

- 场景：从练习入口进入，逐类锁定遭遇目标，分别按 `C`、`W`，继续到玩家被毁。
- 样本：一次用户汇报的试玩流程；各按键尝试次数未记录。
- 观测量：敌方类别、目标身份、基地交互、按键响应、视角和页面的离散状态变化。本次没有时间或数值测量。
- 后续原版对照应记录进入模式、设置、输入与结果；被毁流程按“机外视角 → 爆炸 → 失败页”的顺序对照。阈值/时长容差待测量，不能用本次静态截图确定。

## 对研究与切片选择的影响

- **已确认（资格判定）**：本次练习模式不满足 P2-01 的一至两种敌机、基地交互和 Warp 闭环要求；不需要补充成功结果就能排除该玩法候选。
- **高概率**：共用 SCCT slot 0 对应练习入口，线索为其唯一特殊模式标志、共用结构及本次练习观察；仍须用入口代码或运行时身份确认，不能仅凭失败页面把 SCEN entry 3121 绑定为已确认。
- 战役任务是否合格需要另行证据；不把练习模式的失败结果、无通讯或无 Warp 外推成战役规则。战役地图事实见 [B-001](./B-001-strategic-map.md)。
