## 与练习模式的区别

练习模式的被毁流程见 [B-002](./B-002-practice-mode.md)。**已确认（行为约束）**：至少本次战役被毁可进入救援流程，不能直接将练习模式“玩家被毁后进入失败页”的分支复用为战役终局。

这不证明战役永不失败，也不证明所有战机被毁都会获得救援。应将玩家战机存活状态、救援过程、当前任务结果和战役进度分别研究，不能用一个被毁标志推导全部状态。

## 后续测量与责任

- 从一次可重复的战役任务开始，记录被毁前目标/基地状态、被毁后对象、救援船出现、运送目的地、到达后的页面和控制恢复；是否继续本关、重试或结算需明确观察。
- 多基地场景才可比较目的地距离，验证最近基地规则。基地全部失去、救援船被毁或护送失败的结果目前未知；不要求为了 P2 内容契约立即穷举这些实验。
- 状态顺序按一致/不一致验收；生成延迟、运送时间和距离容差待测量。当前没有计时或量化样本。
- U-031/P3 拥有真实任务失败/救援规则；U-022 与 U-028/P2 核实所选任务中救援对象/飞船的来源与引用。若它们属于必需闭包，不能静默删除或换成临时资源。
