# B-003 战役入口、僚机与任务结算流程

- **状态**：以下入口、选择和成功后页面顺序已确认（用户试玩）。P3-01/04 由代码与数据确认了成功结果的判定位置与所选任务的成功条件；用户那次成功运行走的是这条路径为高概率；“重开任务”的行为来自代码阅读（高概率），未经运行核对。运行时资源身份仍未确认。第一关的敌方模型集合由结构与代码证据确认，见 [executable](../formats/executable.md#player-target-modes-and-enemy-classification)，不由本页观察推出。
- **适用范围**：用户 2026-10-03 的新战役、第一关及进入下一关的流程。部分对象截图来自用户后续战役观察，不能全部当作第一关初始对象。
- **设置边界**：战役设置页有难度滑块；第一关统计截图显示难度为 19（2026-10-04 放大复核后更正，此前误记为 14）。代码确认统计页显示的难度就是选组输入的同一全局值，按 34/67 分界对应 group 0，因此该次第一关为 group 0 / slot 1（SCEN 3019），见 [scenario §4](../formats/scenario.md#4-scct-campaign-table-confirmed-structure-likely-meaning)。截图组之间设置是否改变、僚机索引和基准环境参数未完整记录。
- **证据目录**：下表截图均在 `local/StarRang/captures/`；只记录文件名与行为摘要，不复制任务文字、人物/目标名称、图像或音视频内容。

- **已确认（代码与数据）**：成功结果的判定位置、调试命令之外唯一的成功途径与所选任务（group 0 / slot 1，SCEN 3019）的成功条件记录在 [executable](../formats/executable.md#mission-result-success-path-and-campaign-restart-p3-0104)，此处不重复。
- **高概率（正常玩法路径）**：玩家消灭该任务安排的全部 16 架敌机，即到达成功。本次第一关统计样本的任务击杀总数为 16，两行非零分别为 12 和 4，与该任务按种类安排的敌方数量一致，而这些统计只计玩家的击杀；本次成功运行与这条路径相符。
- **观察限度**：本次运行没有记录最后一个事件、完成消息出现前玩家是否在 Warp、所选僚机与用时；统计页各行对应哪一种类没有追踪。因此对应关系标为高概率，不是逐步核对的已确认。要改为已确认，需要在私有基准运行中读取最后一架敌机被毁时的任务状态与结果。

## 重开任务（P3-01/04）

- **状态**：高概率（只读静态分析，未经运行核对）。代码事实与地址见 [executable](../formats/executable.md#mission-result-success-path-and-campaign-restart-p3-0104)；入口所在的回调表就是本页顺序 1 的战役设置页、飞行中按 Esc 打开的就是通往它的选项页，这两点同为高概率。
- **何时有效**：只在战役模式下、任务进行中（从出发前页面到结算之前）有效；其余时候按下不起作用。
- **恢复到哪里**：放弃当前任务实例，回到**同一关**的开头。世界中的全部对象被清除，然后重新走出发前流程：若是第一关，先再次播放战役介绍动画；出发前页面显示本关简报与僚机选择（预选上次的僚机），在任务中途重开时不显示任务总结；再播放出发动画；随后按同一难度组、同一关重新载入任务，生成队列从头开始，本关的击杀、得分等统计清零。
- **保留**：战役关卡编号、难度值（因而难度组不变）、僚机选择、已完成各关的战役统计与军衔晋升数据、高分榜。
- **清零或丢弃**：本次尝试的全部任务内状态，以及救援计数（其作用见 [executable](../formats/executable.md#mission-result-success-path-and-campaign-restart-p3-0104) 的结束方式表，由 P3-01/05 研究）。
- **不发生**：不进入成功或失败结算，不写入本关的统计行，也不进入高分榜。
- **未确认（边界情况）**：若在全部敌机清除之后、进入结算之前重开，按代码这次成功会被丢弃，但出发前页面仍会先显示本关的任务总结；这段时间内能否打开 Esc 菜单没有核对。
- **未核对**：重开时是否改写 `SRANGER.CFG` 等用户文件；按钮在页面上的位置与可用时的提示；出发前流程能否跳过。核对方法：在私有基准运行中进入所选任务，飞行一段时间并击毁至少一架敌机后，按 Esc 进入战役设置页选择重开任务，记录随后的页面与动画、重新出发后的统计与敌机数量，并比较运行前后的用户文件。
