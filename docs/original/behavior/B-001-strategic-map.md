## 原版行为

### 打开与关闭（已确认）

- 按 `m` 打开地图，再按 `m` 或 Esc 关闭。
- **Esc（2026-10-10 更正）：** 本页原记为“Esc 不能关闭地图”（2026-10-01 试玩观察）。用户于 2026-10-10 说明那次手动测试有误：原版中按 Esc 可以退出战略地图（已确认，用户更正）。代码与此一致：地图按键处理 `0x27118` 对 Esc 与 `m` 发出同一个关闭地图命令，调度器的关闭分支无条件（已确认，代码，[P3-05/02](../../plan/p3/05/subtasks/02-other-context-keys-research.md#完成证据)）。原观察作废。
- 打开地图时**游戏不暂停**：模拟继续运行，地图内容实时变化，并随任务进度更新。
- 打开地图时，**飞行按键不起作用**；飞船不响应操纵。
- 地图内外都可以按 `p` 暂停和继续。
- **打开与关闭的条件（已确认，代码，P3-09/01）：** 打开只检查战役标志（`0x33504` 即 `0x186882 == 1`）；不看当前视角、任务子状态、能量与是否已选跃迁目标。练习模式中 `m` 无反应、无提示。飞行视角、外部视角与基地内都能打开；关闭无条件，恢复打开前的视角（含外部视角的子模式），从基地打开的回到基地。见 [地图模式](../formats/executable.md#map-mode-and-its-commands-p3-0901)。
- **开关保留的状态（已确认，代码）：** 开关地图不改左显示屏页，通讯菜单在地图期间保持打开；从飞行开关地图不触发状态显示重绘（进出基地才触发）。关闭不清除跃迁目标、标记与 `w` 的资格；每次打开时数字标签关闭，但右键去抖计数不复位。
- **地图打开时的其他事件（已确认，代码）：** 玩家被毁时被毁视角取代地图（原读法“视角已是地图则不切换”有误）；救援直接回到驾驶舱前视；能量耗尽后的信标等待中地图照常可开可关；停靠倒计时中可开地图，停靠完成时进入基地；从基地打开的地图期间基地服务暂停，离港时回到驾驶舱前视。
- **同帧次序（已确认，代码）：** 每次轮询只处理一个按键，地图鼠标读取在按键之后；左键按住时关闭地图，该帧的选点在关闭之后生效；按 `w` 的同一帧中左键选点，在 Warp 开始之后改写目标。通讯菜单的物件列表达到 22（32）项时，`m`（`w`）会被菜单占用（切片能否达到未确认，P3-10）。

### 画面布局（已确认）

- 地图整屏显示在一个驾驶舱式边框内，占满 640×480 画面，不显示 3D 场景。
- 左侧是正方形主地图，带 8×8 网格。
- 右侧上半部分是信息小窗（当时所见为两项文字计数；行的规则见下文“放大窗口上方的信息小窗”）；右下部分是标有“放大窗口”的区域。
- 边框左右两侧各有 6 个带三字母标签的按钮，部分为高亮色。**这些按钮不能点击，只是装饰。**
- 布局固定，不随分辨率重新排版。

### 地图内容（已确认）

- **友方单位颜色（已确认，用户补充，2026-10-16）：** 主地图上的友方单位为绿点（包括基地与 Xpon；Xpon 是提供视野的静止飞行器）；右下角放大窗口中的友方单位为浅蓝色。[印刷手册](../../guides/original-evidence.md#印刷手册)写友方为浅蓝色，与放大窗口一致，不适用于主地图。
- 友方单位以绿色名称标签显示（逐个单位，不是编组；玩家、僚机与其他友方种类，不含 0x4000 种类，只限世界矩形内的单位）；另有玩家标记，以及一条从玩家指向**选取框（光标）**的连线，不是指向跃迁目标或所选单位（已确认，代码，P3-09/04 更正）。
- 每个友方单位周围有实心圆盘（玩家自己的颜色不同，画在最上层），可见的敌机周围画一圈自身范围的细圆环；地图上没有专门画在所选目标周围的范围。原记“所选目标周围有一个半透明圆形范围”高概率是某个友方圆盘（P3-09/03、/04）。
- 地图上可以看到大量单位。

### 战争迷雾与敌机可见性（基础规则已确认，U-025）

- 绿点周围的蓝色圆形区域表示已探索区域；多个范围重叠形成地图上的蓝色覆盖区域。
- 蓝色区域之外的黑色部分是战争迷雾。
- 敌机出现在蓝色区域内时，地图显示红色标记；位于黑色迷雾中时，不在地图上显示。
- **证据**：用户于 2026-10-01 针对 U-025 的补充试玩反馈；所附 `srangers_004.png` 展示了绿点、蓝色圆形覆盖区域、黑色迷雾与红色标记。敌机在迷雾中的隐藏行为依据试玩反馈确认，不能仅凭静态截图判定。
- **计算规则（已确认，代码，P3-09/03）：** 蓝色区域是当前所有友方地图单位（玩家、僚机、友方基地与其他非敌方机体）各自以机型记录 +0x0C 为半径的实心圆的并集，半径按每单位像素数换算后向零截断；黑色是每帧清空的背景。敌机显示为红色标记的条件是：来源记录 +0x7C 非零（始终显示；切片任务中全部为 0），或在地图打开时位于任一友方机体（含 Warp 中、停放中的友方，与是否画出圆盘无关）机型 +0x0C 的平面范围内（严格小于，只比较 x、y）；并且不在 Warp 中、不处于待移除状态、位于世界矩形内（含边界）。基地与 Xpon 的探测半径就是各自机型的 +0x0C，同一字段也给出圆盘半径。判定用精确的世界距离，圆盘用截断后的像素半径，所以刚被发现的敌机可能略在圆盘之外。目标、雷达与碰撞不读该可见标志；僚机 AI 读它选择目标（P3-08）。见 [地图接触点与覆盖](../formats/executable.md#map-contacts-coverage-and-fog-p3-0903)。
- **历史探索（已确认，代码与运行）：** 不保留。覆盖每帧由当前单位重新推导，没有任何累计的探索数据。“已探索”只描述画面含义。
- **运行佐证（已确认，运行，P3-09/09 预实验）：** 可见标志在地图中的运行样本与“任一友方集合成员机型 +0x0C 内（平面、严格）”的判定一致，离开范围的敌机下一次读数即不可见，玩家 Warp 离开与关图再开都没有保留的探索；基地作为来源、来源被毁尚无运行样本。统计见 [预实验运行观察](../formats/executable.md#runtime-observations-p3-0909-pilot)。

### 交互（已确认）

- 一个矩形选取框跟随鼠标移动。**鼠标光标被限制在主地图区域内**，不能移出。
- **鼠标的读取与按键（已确认，代码，P3-05/03；未经运行观察）：** 细节与依据见键位表的[战略地图鼠标](../input/key-map.md#战略地图鼠标代码确认p3-0503)。
  - 每次打开地图，光标都回到固定的起点（主地图左上象限内，不是中心），不沿用上次的位置。
  - 光标位置与按键只在地图读取时更新，两次读取至少相隔 8 个时钟单位（至多约 8 Hz）。
  - 左键在按下后的首次读取设定跃迁目标；按住时每次读取都重复（目标跟随光标，每次播放点击音效），松开时没有动作；两次读取之间的短按不会被看到。
  - 右键切换放大窗口中各单位旁的数字标签；每次打开地图时标签关闭。数字是该单位与玩家的三维距离（取整），玩家的战斗目标的数字另用颜色；按住右键时每 20 次地图调用切换一次，即 2 时钟单位/pass 下每 16 个 pass 一次（不是每 20 个 pass；同一 pass 中读取调用先于绘制调用，每次调用先判断再递减）；纯显示，不影响选择或其他规则（已确认，代码，P3-09/04、P3-13/06）。
  - 除选取框、跟随光标的标记与能耗文字外，不绘制其他鼠标指针。
- 右下角放大窗口实时显示选取框内区域的放大图标。
- 左键设置跃迁目标（时机见上）。关闭地图后，右侧目标窗口显示这个跃迁点目标及其距离（以米为单位）和接近速度（README 称其出现在友方目标模式中）。
- **选取框旁边显示跃迁能量消耗**，格式为“E: 百分比”。选取框离玩家越远，百分比越大（截图中观察到 1%、3%、15%）。**基准（已确认，代码，P3-09/05）：** 百分比是按距离分段计算的跃迁消耗占**当前能量**的比例，向零截断，至少为 1；颜色按显示值分为 ≥100、67–99 与其余三档。已存目标点旁也有同样的读数（用已存目标点，不用标记物体）。当前能量为 0 时该除法触发未屏蔽的浮点异常，后果未确认。
- 左侧飞船状态窗口的能量数值是**当前能量**，不是跃迁消耗。驾驶舱上方另有跃迁指示灯。
- **选中方框（P2-12/32 更正）：** 用户观察与 EXE 的绘制归属分开记录。
  - **用户观察（已确认，用户在 P2-12/15 补拍时的口述，2026-10-07）：** 在地图上左键点击选择单位后，被选的单位外出现方框；一次点击可以同时选中多个单位。口述没有说明方框出现在主地图还是放大窗口。
  - **绘制归属（已确认，EXE 与截图核对，P2-12/27）：** 方框是放大窗口中画在图标外的框，画给离左键目标点足够近的单位，所以一次点击可以框住多个单位。主地图的单位标记从不带方框；主地图上画的是与方框同色的选取框。判定规则、绘制路径与截图核对见 [hud](../formats/hud.md#sources-of-the-unidentified-elements-p2-1227)，左键目标点见 [executable](../formats/executable.md#strategic-map-projection)。
  - **用户所见方框的位置（已确认，用户判断，P2-12/30，2026-10-08）：** 用户确认 `srangers_106.png` 中点击后的方框在放大窗口里，并说明选取一个单位后它的外面会有框；与 EXE 一致。在用户所附的 C-10 截图中，27 找到的方框也都在放大窗口里（`srangers_106/107.png`）。
  - **判定（已确认，代码，P3-09/02、/04）：** 放大窗口中的单位与已存目标点在 x、y、z 三轴上各自相差都小于 1000 时画框，可同时框住任意多个单位（含玩家与战斗目标）。这只是绘制：选点不改变玩家的战斗目标，也不让这些单位成为其他操作的对象。
- **跃迁目标的标记（P2-12/30）：**
  - **用户观察（已确认，用户判断，2026-10-08）：** 地图上的虚线不是跃迁目标；设定跃迁目标后，放大窗口中目标的图标外有方框（用户在公开实机视频第 1 集 8:31、9:35、13:55 的地图帧中确认）。用户说明 `srangers_004.png` 与 `105.png` 中没有设定跃迁目标。
  - **主地图上的状态点标记（已确认，代码，P3-09/02）：** 地图绘制在已存的跃迁目标点上画一个小标记，能量消耗文字紧挨它。该点只由任务开始时的玩家实例化（清零）与左键选点写入，标记从首次选点起就一直显示，与是否执行过 Warp 无关；用户说 004 中“没有设定目标”高概率是选过点但没有 Warp。见 [hud](../formats/hud.md#slice-coverage-check-and-u-030-impact-p2-12)。
  - **选点与标记（已确认，代码，P3-09/02）：** 左键选点读取上一帧地图绘制生成的图标列表：主地图上 ±3 像素的正方形内最近的图标（并列取列表中靠前者，不含玩家自己和世界矩形外的图标），目标点的 z 取该图标记录的 z，未点中为 0；重合的图标在绘制时被错开，选点读的是错开后的位置。任务中的首次选点创建唯一的跃迁标记（消耗一次共享随机数），之后的选点只移动它；关闭地图、救援与 Warp 都不清除目标点与标记，目标点与“已选”标志只由新任务或重试清零（已确认）；标记一直保留到任务结束才移除为高概率（已排除全部伤害、停放、区域与消息路径，另有五个辅助调用的对象未逐一追踪）。首次选点之前按 `w` 没有任何反应。见 [选点与标记](../formats/executable.md#cursor-destination-and-marker-p3-0902)。
- **放大窗口上方的信息小窗（P2-12/32 更正）：**
  - **用户观察（已确认，用户在 P2-12/15 补拍时的口述，2026-10-07）：** 小窗显示单位的信息，用户描述为全部单位的信息。
  - **绘制归属（已确认，EXE 与截图核对，P2-12/27）：** 小窗是地图仪表右侧面板的上半部分，用已交付的字库 `font/hud/8x8-2` 按行写出单位的信息，行数以小窗能容纳的为限。见 [hud](../formats/hud.md#sources-of-the-unidentified-elements-p2-1227)。
  - **范围（已确认，EXE，P2-12/32）：** 小窗只取世界位置落在放大窗口范围内的单位：地图绘制 `0x49f8c` 为每个单位记下放大窗口范围判定 `0x4c5ec` 的结果，小窗 `0x4ba80` 只处理结果为真的单位（读自 27 的被忽略输出 `local/research/p2-12/u030/`；放大窗口范围见 [executable](../formats/executable.md#strategic-map-projection)）。放大窗口显示的是选取框内的区域（见上），所以小窗列出的高概率是选取框内的单位，而不是地图上的全部单位。
  - **用户判断（P2-12/30，2026-10-08）：** 用户看过 `srangers_104.png` 与 `106.png` 后认为不必另拍：两张中小窗列出的都是放大窗口中的单位（106 中只有两个基地），与上面的范围一致。“全部单位”因此是选取框覆盖范围内的全部单位。
  - **行与字段（已确认，代码，P3-09/04）：** 只列已进入地图图标列表、且严格位于放大窗口范围内的单位。友方种类（不含 0x4000 种类）每个单位占两行：种类词与名称；护盾、船体、能量各占机型上限的百分比。其他种类按种类各一行计数，以固定次序排列。单位行以小窗高度能容纳的行数为限，计数行不受此限，可能画到小窗之外。

### 跃迁规则（已确认，代码，P3-09/05、P3-09/06）

- **状态**：已确认（只读静态分析：代码）；P3-09/09 预实验已在运行中核对开始、拒绝、到达与扣费（见下文“运行观察”），中断分支仍未经运行核对。代码事实见 [跃迁消耗与开始](../formats/executable.md#warp-cost-and-warp-start-p3-0905) 与 [跃迁过程、完成与中断](../formats/executable.md#warp-progress-completion-and-interruptions-p3-0906)。
- **开始的条件**：按键能被读取（玩家存活）；在飞行或地图中（Warp 中与基地内没有 `w`）；地图不是从基地打开的；已经选过目标点；距上次 Warp 的间隔已到（等于时即可，而驾驶舱指示灯要严格超过才亮，因此有一个时刻会在指示灯未亮时被接受）；消耗不超过当前能量（等于时可以）。任何一项不满足都静默拒绝，没有声音或文字。零距离的目标也会被接受。开始时不扣能量，不锁定目标点（同帧之后的选点会改变到达点），也不触发状态显示重绘；左显示屏换到 Warp 页并保存原页，玩家目标被清除。
- **过程**：玩家被放进一条由随机数生成的私有“隧道”路径的起点，速度从 0 加速；进度按“速度 × 时间 ÷ 机型 +0xB8”分段推进，段数由距离与机型 +0xA8 决定（每段末尾的超出部分被丢弃）。玩家可以在隧道内转向，朝向被限制在隧道方向 30° 以内、位置限制在中心线 50 单位以内；越靠近中心线，“误差”增加得越多，碰到边缘时增加更多，误差按帧累计（与帧率有关）。Warp 页的三条为角度、误差与完成度。
- **到达**：玩家先放到目标点，按误差向所在扇区的一个角拉近，并按误差与难度组（`(组 + 1) × 5000`）随机向上或向下偏移；若 600 单位内有任何物体（包括玩家自己、跃迁标记、爆炸与碎片），改放到最近的那个物体上方 600 处，所以误差为 0 时落在目标点上方 600 处。然后随机取一个朝向。能量按出发点到到达点的距离扣除消耗 × (1 + 误差/2)，不低于 0；下一次 Warp 的间隔从到达时重新计算。到达点附近有敌机时播放到达音效。
- **运行观察（已确认，运行，P3-09/09 预实验；不是正式运行）：** 地图读数、到达偏移、能量扣除与下一次间隔在运行中都与上述规则相等，间隔不足与能量不足的 `w` 都被静默拒绝。不操纵时，路径一弯曲玩家就碰到隧道边缘，误差多半到 1，未见误差为 0；所选任务中变换因子达到 1 需要玩家位于世界矩形之外；地图读数能显示到哪一类颜色取决于当前能量与玩家位置。能量为 0 时打开地图，在基准 DOSBox-X 中读数显示为 1、游戏继续运行（其他 x87 实现是否不同未确认）；Warp 途中救援仍未观察到。统计见 [预实验运行观察](../formats/executable.md#runtime-observations-p3-0909-pilot)。
- **中断**：Warp 中没有取消键。玩家被毁时 Warp 被放弃（不到达、不扣费），而“在 Warp 中”标志一直保留到下一次完成的 Warp，期间活动区域的中心仍是目标点，AI 也不以玩家为目标；能量耗尽时 Warp 继续，若信标救援先到期则同样被放弃；停靠倒计时到期时停靠被拒绝；全部敌机清除后结算推迟到 Warp 结束之后；暂停后继续同一次 Warp。

## 对实现的影响

- 地图是一种**输入与显示模式**，不是暂停状态：GameRuntime 照常推进模拟；Core 不因地图打开而改变规则。
- 地图打开时，GameRuntime 不把飞行操纵输入送入 Core（输入快照中的操纵轴归零、飞行类命令忽略），但模拟照常运行。
- 暂停（`p`）在地图内外都走运行时控制通道（总计划 §5）。
- 光标：**保持 Pointer Lock，由游戏自己绘制光标**，并把光标限制在主地图区域内，与原版一致；起点与左键时机见[交互](#交互已确认)。原版中 Esc 也关闭地图；锁指针时 Esc 只退出锁定（总计划 §1.2），未锁指针时地图中 Esc 的项目绑定由 [P3-05 spec](../../plan/p3/05/spec.md#会话控制键) 规定。
- 战争迷雾决定玩家能看到什么，属于游戏规则（信息可见性），由 Core 计算并经 UI projection 提供，渲染层不能自行推导。
- 地图框架来自任务数据（P2-09 规范任务的 `mapFrame`），不硬编码世界范围或坐标轴方向以外的数值。
- 地图是固定布局的 640×480 画面，按总计划 §7.1 的飞行画面方式整体等比缩放，不做响应式布局。侧边按钮只作为装饰绘制，不需要交互。

## 验收容差

交互类行为按“与原版一致 / 不一致”判定：开关按键（`m` 与 Esc）、不暂停、选取框与放大窗口实时更新、迷雾与单位显示规则。敌机在蓝色区域内显示红色标记、在黑色迷雾中不显示，按显示 / 隐藏判定；精确边界判定待确认。迷雾范围在参数确认后，按地图像素位置对照截图，容差另定。
