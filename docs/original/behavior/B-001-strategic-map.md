# B-001 战略地图

- **状态**：交互方式、战争迷雾的基础显示与敌机可见性规则已确认（试玩 + 截图）；迷雾范围参数、历史探索保留规则与跃迁消耗公式未确认
- **适用范围**：战役任务中的飞行状态；HI 分辨率模式（640×480）
- **证据**：用户试玩观察（2026-10-01，三轮），以及同日针对 U-025 的补充试玩反馈与所附 `srangers_004.png`；截图 `local/StarRang/captures/srangers_000.png`、`srangers_001.png`、`srangers_004.png`（地图）、`srangers_002.png`（驾驶舱）

## 原版行为

### 打开与关闭（已确认）

- 按 `m` 打开地图，再按 `m` 关闭；Esc 不能关闭地图。
- 打开地图时**游戏不暂停**：模拟继续运行，地图内容实时变化，并随任务进度更新。
- 打开地图时，**飞行按键不起作用**；飞船不响应操纵。
- 地图内外都可以按 `p` 暂停和继续。

### 画面布局（已确认）

- 地图整屏显示在一个驾驶舱式边框内，占满 640×480 画面，不显示 3D 场景。
- 左侧是正方形主地图，带 8×8 网格。
- 右侧上半部分显示两项文字计数；右下部分是标有“放大窗口”的区域。
- 边框左右两侧各有 6 个带三字母标签的按钮，部分为高亮色。**这些按钮不能点击，只是装饰。**
- 布局固定，不随分辨率重新排版。

### 地图内容（已确认）

- 地图上的绿点代表己方单位：基地或 Xpon。Xpon 是提供视野的静止飞行器。
- 友方编组以绿色标签显示；另有玩家标记，以及从玩家指向所选目标的连线；所选目标周围有一个半透明圆形范围。
- 地图上可以看到大量单位。

### 战争迷雾与敌机可见性（基础规则已确认，U-025）

- 绿点周围的蓝色圆形区域表示已探索区域；多个范围重叠形成地图上的蓝色覆盖区域。
- 蓝色区域之外的黑色部分是战争迷雾。
- 敌机出现在蓝色区域内时，地图显示红色标记；位于黑色迷雾中时，不在地图上显示。
- **证据**：用户于 2026-10-01 针对 U-025 的补充试玩反馈；所附 `srangers_004.png` 展示了绿点、蓝色圆形覆盖区域、黑色迷雾与红色标记。敌机在迷雾中的隐藏行为依据试玩反馈确认，不能仅凭静态截图判定。
- **未确认**：基地与 Xpon 的探测半径及其是否相同、范围边界判定、视野来源消失后已探索区域是否保留。“已探索”描述画面含义，不表示已经确认历史探索会永久保留。

### 交互（已确认）

- 一个矩形选取框跟随鼠标移动。**鼠标光标被限制在主地图区域内**，不能移出。
- 右下角放大窗口实时显示选取框内区域的放大图标。
- 左键点击设置跃迁目标。关闭地图后，右侧目标窗口显示这个跃迁点目标及其距离（以米为单位）和接近速度（README 称其出现在友方目标模式中）。
- **选取框旁边显示跃迁能量消耗**，格式为“E: 百分比”。选取框离玩家越远，百分比越大（截图中观察到 1%、3%、15%）。百分比相对什么基准（如能量上限）未确认（U-026）。
- 左侧飞船状态窗口的能量数值是**当前能量**，不是跃迁消耗。驾驶舱上方另有跃迁指示灯。
- **选中标记（已确认，用户观察，P2-12 补拍）：** 在主地图中左键点击后，被选中的单位外出现黄色方框；一次点击可以同时选中多个单位。选中范围由什么决定（选取框覆盖的单位，或点击点附近的图标）未确认；代码中左键路径按点击点 3 像素内的最近图标取值（[executable](../formats/executable.md#strategic-map-projection)），与多选的关系也未确认。
- **放大窗口上方的小窗口（已确认，用户观察，P2-12 补拍）：** 显示各单位的信息。所列字段与范围（全部单位或选取框内的单位）未确认。

### 地图框架与坐标轴（高概率，P2-09）

- **P2-12 更新：** 本节的高概率结论已由运行时读数确认，见[地图框架运行时核实](#地图框架运行时核实已确认p2-12)。本节保留 P2-09 当时的依据。
- **已确认（代码）：** 主地图区域内的鼠标位置按世界矩形换算为世界坐标的 x 与 y，选取框与放大窗口使用这一换算，z 为 0。左键放置的跃迁标记使用同样的 x 与 y；在一定的玩家状态下，z 取最近地图图标记录的值（未点中图标时为 0），属于运行时状态。世界矩形是任务头部规定的扇区网格，以原点为中心（[executable](../formats/executable.md#strategic-map-projection)、[scenario §2](../formats/scenario.md#2-scen-header-confirmed-on-all-52-entries)）。
- **高概率（代码推断与截图对照）：** 主地图显示整个世界扇区网格；地图向右为 +x，向上为 −y，竖直方向为 z。
  - **方向依据：** 像素换算比例的写入位置未找到；方向由“地图左上角对应世界最小角”推出。
  - **范围依据：** 截图中网格每边的格数等于任务的扇区数，与“一格对应一个扇区”一致。
  - **截图对照：** 取第一关地图截图 `srangers_059.png`，按所选任务的生成矩形预测敌方编组、基地与玩家应位于地图的哪一半。敌方标记只出现在预测的一半。对照只判断所在的一半与网格格数，不记录坐标或像素数值。
- **高概率：** 在目的地选取路径上，跃迁目的地按同一框架换算，未发现跃迁专用的静态空间数据（目的地表、网格或范围）。跃迁执行过程（耗能、移动、到达、误差）未追踪，仍见 U-026。

### 地图框架运行时核实（已确认，P2-12）

- **已确认（运行时读数）：** 在所选任务的地图状态中，用户配合在主地图内左键点击三次，调试器每次在左键路径（`0x4c310`）暂停。每次运行都重新核验本进程的 CODE/DATA 对应、目标页可读、重复读数稳定与任务身份。读出的地图矩形、世界矩形、两轴换算比例与网格，在实际存储精度下与候选 `mapFrame` 一致：
  - 主地图显示整个世界扇区网格，范围以原点为中心；
  - 地图向右为 +x，向上为 −y（屏幕行号随世界 y 增大）；
  - 两轴尺度相同（主地图为正方形），每个扇区占相同的像素数；
  - 单位：地图矩形与原点为屏幕像素；世界坐标、世界矩形与放大窗口边界为运行时单位（内容模型中的 `scen-runtime`）；两组换算比例分别为每运行时单位的像素数与每像素的运行时单位。候选 `mapFrame` 使用参考单位（`scen-reference`），两种单位之比与内容模型的换算一致；
  - 放大窗口的夹取在四个方向都到达世界边界。
- **代码依据：** 换算比例由 `0x49e74` 写入；世界矩形不存储，由 `0x3a41c` 按网格计算（[executable](../formats/executable.md#strategic-map-projection)）。
- 文档不记录字段数值；读数与报告只在被忽略的 `local/research/p2-12/map-frame/`。

## 待确认

- 战争迷雾的剩余计算细节（U-025）：基地与 Xpon 的探测半径、范围边界判定、历史探索是否保留。后续可按地图网格测量各类单位的蓝色范围，观察敌机跨越边界时的标记变化，并对比视野来源消失前后的蓝色区域。
- 跃迁能量消耗的计算公式：与距离的关系、百分比的基准（U-026）。可以在地图上选取不同距离的点，记录百分比与网格距离，拟合公式。

## 对实现的影响

- 地图是一种**输入与显示模式**，不是暂停状态：GameRuntime 照常推进模拟；Core 不因地图打开而改变规则。
- 地图打开时，GameRuntime 不把飞行操纵输入送入 Core（输入快照中的操纵轴归零、飞行类命令忽略），但模拟照常运行。
- 暂停（`p`）在地图内外都走运行时控制通道（总计划 §5）。
- 光标：**保持 Pointer Lock，由游戏自己绘制光标**，并把光标限制在主地图区域内，与原版一致。Esc 不参与地图开关；如果玩家按 Esc 退出了 Pointer Lock，按总计划 §1.2 的方式处理。
- 战争迷雾决定玩家能看到什么，属于游戏规则（信息可见性），由 Core 计算并经 UI projection 提供，渲染层不能自行推导。
- 地图框架来自任务数据（P2-09 规范任务的 `mapFrame`），不硬编码世界范围或坐标轴方向以外的数值。
- 地图是固定布局的 640×480 画面，按总计划 §7.1 的飞行画面方式整体等比缩放，不做响应式布局。侧边按钮只作为装饰绘制，不需要交互。

## 验收容差

交互类行为按“与原版一致 / 不一致”判定：开关按键、不暂停、选取框与放大窗口实时更新、迷雾与单位显示规则。敌机在蓝色区域内显示红色标记、在黑色迷雾中不显示，按显示 / 隐藏判定；精确边界判定待确认。迷雾范围在参数确认后，按地图像素位置对照截图，容差另定。
