#### 场景与输入

- **操作者：** agent 独自运行（[agent 独自运行](../../guides/runtime-measurement.md#agent-独自运行)）。全部游戏输入都是配方声明、由工具在暂停点写入并逐条记录的[模拟器内输入](../../guides/runtime-measurement.md#模拟器内输入)；没有宿主层输入，也不用 Computer Use。确认文件由只写应答文件的本地脚本按 `status.json` 的 `expects` 写入。
- **进入路线**（P3-06/22 已证实）：标题页（页面 0x10）Enter、战役选项页（9）Enter、简报页（0xF）Esc，保留僚机选择值 1。私有副本中没有摇杆页；过场完整播放（约 1.5 分钟）。
- **按键：** 在飞行键盘轮询 `0x262c3`（到期判断之后、INT 21h 0Bh 之前）写入 BIOS 键盘缓冲，同一次轮询读到并交给键处理 `0x264a0`（[输入轮询](../formats/executable.md#input-polling-p3-0201)）。待发的油门在同一回调末尾投递，本帧消息循环应用，本帧运动即使用新的指令速度。
- **摇杆刺激：** 原版没有键盘操纵，转向样本以摇杆刺激驱动（与检查点 A 修订的 R-04 方式一致）。在设备读取 `0x57dab`（驱动返回之后、变化比较之前，ESI 指向设备状态）把俯仰（ESI+4）、偏航（ESI+0xC）或横滚（ESI+0x14）写为 ±128，原版把它当作新的设备值，本帧消息循环经整数路径应用。
  - **保持：** 下一次设备读取时，驱动在零掩码下返回 0；在同一暂停点把上次读数副本（`0x1b2474`、`0x1b247c`、`0x1b2484`）写为 0，比较不再发现变化，已应用的速率与标志保持，不再投递消息。游戏状态与物理摇杆持续偏转相同；副本只被这一比较读取（`0x57d70`）。
  - **松开：** 把副本写为非零，下一次比较发现变化，驱动的 0 清除该轴的启用标志。
  - 只用真实摇杆能产生的组合：俯仰与偏航、俯仰与横滚可以同时偏转；偏航与横滚互斥（X 轴只去其一，按住 Ctrl 或 2 号键时为横滚）。数值只用 0 与 ±128（数字摇杆满偏），Medium 表首末项为 ∓1。偏航与横滚同时非零、非满偏的轴值只由 Node 合成测试覆盖。
  - 每次运行记录驱动、摇杆模式、灵敏度与校准：报告 `gameConfig` 中的 `JOYSTICK` 行，以及每段读取的 `0x1761e4`、`0x1761e8`、`0x1b249c` 与轴掩码 `0x1b23fc`。
- **速度辅助：** 难度组 0 开局开启，并在首次可操纵更新时自动选择最近的敌方模式目标。除 R-04d 段以外，各段在首次可操纵更新的那一次轮询（与自动选择同一回调，在辅助调用之后）用 Ctrl+Enter 关闭它，并以读数核对开关从 1 变为 0、未曾匹配。更晚关闭不可靠：预实验中首次运动的长步长把玩家送到锚定的开局敌机近旁，辅助在下一帧即匹配（[预实验](#预实验)）。
- **灵敏度与驱动：** 保持基准的 Medium、Flight 模式与驱动 0；每段读取 `0x1b249c`、`0x1761e8`、`0x1761e4` 与轴掩码 `0x1b23fc` 核对。F11 只在试键段使用。
- **禁止：** 配方以外的任何输入；除试键段外不切换视角，不打开菜单、地图或通讯，不暂停，不 Warp，不发射武器。

- **同帧配对：** 运动前与运动后的帧计数相同，对象身份由同一句柄证实（玩家状态 +0x8C；非玩家为玩家目标句柄的两端读数）。
  - 对玩家，运动后到下一帧运动前之间，位姿、速度与速度比只会被碰撞冲量（下一帧才生效）、Warp、救援与移动块重建改变（代码，自动驾驶关闭时），预实验核对两者相等（[预实验](#预实验)）；检查点 B 不采用以下一帧的运动前代替上一帧的运动后：R-04a 只用同一帧的前后读数，这一相等只作配对核对（[R-04a 的配对](../../plan/p3/06/spec.md#r-04a-条件化单步)）。
  - 对非玩家飞行器，AI 在两帧之间还会重建姿态（`0x5e200`），只用同一帧的运动前后。
- **回调中的暂停**（轮询、设备读取、自动选择到期）读到的是上一帧运动之后的状态。从这类暂停 N 到 M 的窗口包含帧 N 至 M−1 的运动：帧数为帧计数差，积分时间为 (样本_M − 步长_M) − (样本_N − 步长_N) 个单位。在 N 处施加了输入的窗口，起点状态还要加上本帧消息循环的应用；分析只以未施加输入的暂停作为连续窗口的起点。
- **R-05a 的时刻：** “实例化完成、尚未运动”取实例化暂停；“首次活动与首次运动”取控制块之后的第一对运动前后；“首次可操纵更新之后”取状态 7 回调、自动选择后与其后的下一次运动前（目标已写入）。相对时间以实例化帧样本 S_B 为原点，玩家 +0x18 交叉核对（[initial flight state](../formats/executable.md#initial-flight-state-p3-0605)）。实例化与首次运动之间不施加任何键。

#### 条件化单步与不中断窗口

- **条件化单步（R-04a、R-04b）：** 逐帧在运动前后暂停。调试器停住时模拟器时间与游戏计数都不前进（[B-006](./B-006-simulation-timing.md#观测量)），读数与刺激不进入任何步长；预实验另比较了逐帧停止与稀疏停止下的步长分布。
- **不中断窗口（R-04c）：** 只在自动选择到期与施加输入的轮询、设备暂停处停，窗口内没有断点。窗口从未施加输入的暂停开始，在下一读数暂停结束。保持偏转用上次读数副本，不需要在窗口内暂停。
  - 窗口只取飞行上下文（两端视角模式相同且为飞行视角）。项目在地图（视角模式 8）与基地（6）中把有效手动轴置零，是 spec 批准的有意差异（原版在这两种模式中不读设备，已应用的转向继续）：跨入地图或基地的窗口单独列出这一差异，不计为一致，也不据此放宽其他窗口。本方案的各段不进入地图与基地。
- **长时段（R-05b）：** 在自动选择到期暂停以 `skip` 应答跳过若干次，再在需要读数的那一次确认。跳过的停止不读字段、不施加输入，只用于让游戏连续运行；这些段不作计时窗口。
- 运行顺序为每次运行先完成条件化单步段，再做窗口段，两类样本不合并统计。

#### 参考钟与时间原点

- 判据只用游戏自身的样本、帧计数与步长，不用宿主或模拟器时长。依赖帧分布的结论都限定于实测 cycles（[B-006 的 T-5](./B-006-simulation-timing.md#对后续的含义t-5)，U-021）。
- **时间原点：** R-05a 与计时类对照用实例化相对时间 τ = 样本 − S_B；任务经过时间（样本 − 原点）只用于生成时刻。原版的原始计数从程序启动的随机值开始，绝对样本不跨运行比较。
- **到期：** 键盘轮询、设备读取与自动选择在样本严格超过到期时刻时触发，速度辅助在样本不小于到期时刻时触发，各自从触发时的样本重新计时（[时基](../formats/executable.md#simulation-time-base-p3-0106)）；每次的超出量由帧步长决定。
- **定时旋转的到期**取决于绝对样本秒的 f32 舍入（[numbers](../formats/executable.md#numbers-on-the-movement-path-p3-0601)），不逐位比较。

#### 误差来源

以下只列来源；各项的量化与判据由检查点 B 定稿（P3-06/08），见 spec 的[检查点 B 定稿的判据](../../plan/p3/06/spec.md#检查点-b-定稿的判据)；预实验的估计见[预实验](#预实验)。

- **舍入：** 每个 f32 写回点的双重舍入 D → F；舍入方向（就近或向零，U-009）。独立计算对两种方向分别求值。
- **三角函数：** FSIN/FCOS 的扩展精度结果；基准模拟器在本机上可能以宿主双精度求值（未确认）。只在 f32 舍入边界附近影响结果，比较须标出这类分量，不计为规则差异。
- **非交换旋转与行漂移：** 三次旋转按俯仰、偏航、横滚依次作用于已旋转的行；运动路径不重新正交化，行长度缓慢漂移。
- **显式欧拉：** 位置用更新前的速度；冲量位移用衰减前的大小。
- **步长：** 原版每帧步长可变（2、4 单位等），项目固定 2 单位/tick。持续运动的差异来自不同步长下的欧拉积分、到达帧的位置与旋转角的累积。
- **输入对齐：** 原版在轮询与设备读取的到期帧应用输入，到期在严格超过后的第一帧触发，并从触发时重新计时，超出量逐次累积；项目每 tick 消费。窗口须能区分这一延迟与累计误差。
- **反复到期：** 辅助匹配、键盘轮询与设备读取的间隔都包含帧步长造成的超出量。
- **定时旋转与冲量的到期**依赖绝对样本秒的 f32 舍入。
- **读数分辨率：** f32 的末位单位随量级变化（位置在万级时约 0.004 单位）；时钟单位 1/64 秒；读数本身位精确，重复读取须一致。
- **cycles 与负荷：** 帧率与步长分布依赖 cycles 与负荷（B-006）；结论只适用于实测配置。

#### 有效运行与重做规则

- 工具报告 `complete`：必需样本全部合格、身份检查通过、刺激全部施加并回读一致、原文件保护与进程回收通过；模式为测量，cycles 为 40000，配方指纹与方案相同。`skip` 只用于 R-05b 的长时段暂停。
- 每段开始时：速度辅助已关闭（R-04d 段除外）、灵敏度 Medium、驱动 0、Flight 模式、轴掩码 0、锁定与扰动为 0、没有冲量与定时旋转；运行中被毁、救援、碰撞冲量或定时旋转出现时，受影响的样本标出并按方案排除，救援使运行不合格。
- 失败、取消或无效的运行保留目录，在结果表中列为“排除”并写明原因，用同一配方的下一编号重做；不合并不同运行的样本，不为求通过而重做。
- 预实验运行（`pilot-*`）与正式运行分开编号，不计入正式样本。
