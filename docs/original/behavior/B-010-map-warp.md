#### 参考钟与时间隔离

- **只用游戏时钟：** 判据只用样本、步长与游戏写入的时间字段，不用真实秒。调试器停住时，游戏计数与模拟器时间都不前进（[B-006](./B-006-simulation-timing.md#观测量)）。
- **暂停的影响：** 暂停拉长被停的帧，改变步长序列（[计时](../../guides/runtime-measurement.md#计时游戏时钟与参考钟)）；判据按每帧记录的步长合成，所以逐帧段可以用于链的核对。步长分布与差异 3 的量只取稀疏暂停。
- **诊断用的时间：** 每个暂停的 `stop.json` 中的模拟器时间与宿主时间只用于诊断（停顿开销、与 B-006 的一致性），不进入判据。Warp 的秒数（09：L = 10 时 10.3–10.4 秒模拟器时间）只是诊断。
- **隔离：** 连续比较窗口两端读视角、主流程状态与子状态，窗口内有游戏暂停、菜单、通讯、被毁、救援或停靠的作废。游戏暂停 `p` 的样本另作离散核对：恢复后首帧的步长不含暂停时长（误差在一次回调的相位内）。
- **锚：** Warp 以开始的 pass（键盘轮询读到 `w` 的 pass）为锚，地图以读取为锚，可见性以判定翻转前后的 pass 为锚；不按任务原点的绝对时刻（原版的原点含过场用时）。

#### 比较链的读法

spec 的判据要求窗口的 S 与每帧的步长都取自同一次运行的记录：

- **逐帧合成：** Φ 用逐帧暂停读到的 `0x186424`。完整窗口从开始的 pass 起每帧都有暂停；缺一帧的窗口作废。
- **截止链节：** d = 生效样本 − 锚 − P₂；满速段的锚为上一次平移的样本，生效样本为本次平移的样本，h 取平移帧的步长。只有读到的速度与机型 +0xB8 按位相等的段适用（spec 的逐类表）。
- **帧链节：** 完成的 d = 完成 pass 的样本 − 最后一次帧尾的样本 − 2。
- **S 中的随机结果：** 隧道路径的控制点取开始时的读数与每次平移后新增的点；到达的号取 `0x2c075` 的 EAX，姿态取最终三行（须为 64 个启动旋转之一）。这些结果不要求与新版相同。
- **可见判定：** 每个敌机的判定由同一暂停读到的友方成员位置与机型 +0x0C 按严格平面比较重算；标志与位置须取自同一次揭示之后、下一次运动之前，能量阶段的暂停不合格。

#### 覆盖与样本

- 至少 2 次 `complete` 的合格运行，合计满足 spec 的[采样覆盖下限](../../plan/p3/09/spec.md#对照方法与判据)，以及 [D-02](../../plan/p3/09/spec.md#d-02-连续行为判据) 的逐类最少样本、区分情形与采样覆盖的补充。预算要求更多样本时，不在下限处停止。
- **Warp：** 3 个不同的 L（f = 0.5 与两个 f ∈ (0.5, 1)），至少 2 个完整逐帧窗口来自 2 次独立运行，其中至少 1 个直线段无摇杆输入；每个窗口至少 3 次进度读数。f = 1 在世界矩形内不可达、不是覆盖要求，上限分支由代码与 Node 核对，取得时照常核对。
- **到达：** 至少 5 次，其中至少 1 次吸附、至少 1 次 0 < s < 1（09 约为 1/19 与 3/18，可能需要更多次 Warp）。s = 0 不是覆盖要求，正式运行不以它为目标（以开环配方输入预计难以做到，未尝试），其取值由代码与 Node 核对，出现时照常核对。
- **地图期间推进：** 2 个窗口来自 2 次独立运行，各跨至少 2 次地图读取，玩家直线匀速、各轴速率为 0。
- **可见边界：** 至少 3 次跨越，进入与离开各至少 1 次，来自至少 2 次独立运行，每次跨越前后逐 pass 读数。

#### 判据

判据以 spec 的 [D-02 连续行为判据](../../plan/p3/09/spec.md#d-02-连续行为判据)为准，本页不另立。要点：

- 新版的值等于按已确认规则在 2 单位步长下合成的值，原版的值等于同一规则按原版记录的步长合成的值，两者都精确成立，没有残余容差；分支由规则从原始输入推出，不取自被测运行。
- 跨版本的结论只来自配对窗口（除步长外输入相同）；差值由双方的步长解释，作为已批准差异 3 的量披露。路径抽取与敌机运动不可能相同的量只做两边各自的核对。
- 已批准的差异按 spec 的配对表单列，不判为不一致。
- 窗口按事先写定的规则机械选取，并列出每个排除的原因。
- 每类须出现区分情形；单次转移层的连续数值按 spec 的允许误差，边界样本不计入。
- 只有全部样本都满足才判为“一致”；任一样本不满足即为“不一致”，不放宽判据，也不为求通过而重做。

#### 有效运行与重做规则

- 工具报告 `complete`：必需样本全部合格，身份检查通过，原文件保护与进程回收通过。模式为测量，cycles 为 40000，配方指纹与 24 的本地方案相同，没有 `skip` 应答。
