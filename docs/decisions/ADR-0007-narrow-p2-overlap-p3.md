# ADR-0007：P2 收窄为玩法所需资源，P2 与 P3 可重叠

## 背景

原 P2 要求所有导入格式、全部资源、视频与音乐都完成后才能进入 P3，会严重推迟第一个可玩版本。

## 决定

- P2 只做 P3 用得到的资源：CCD/IMG 导入、`.NOB`、切片所需的模型/贴图/HUD/音效、一个任务的数据。
- 其余内容、视频与音乐移到 P4；其他导入格式与缓存管理移到 P5。
- P1 完成后，P3 可以先用标记过的临时资源开工；退出条件不变。

细节见总计划 §12。
