# ADR-0008：默认 MIT 许可证与依赖许可证政策

## 决定

- 项目源码默认采用 MIT，在首次公开仓库前最终确认。许可证不覆盖原版内容。
- 依赖许可证政策：宽松许可证直接允许；LGPL 只能作为独立加载、可替换的模块；GPL/AGPL 不进入网站产物；只在本机使用的研究工具不受限制。
- CI 检查依赖许可证，构建时生成第三方许可声明。

细节见总计划 §9.2。

## 考虑过的其他方案

- MPL-2.0 或 GPL：希望衍生版本保持开源时适用。作为唯一作者，以后仍可更换。
