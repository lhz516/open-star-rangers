# ADR-0009：窗口自适应：等比缩放为默认，宽屏为可选

## 决定

- Classic 飞行画面以原版比例（预期 4:3）整体等比缩放，多余部分留黑边；3D 按窗口实际像素渲染，可选“原版像素”模式。
- 可选宽屏（默认关闭）：4:3 到 16:9 之间水平视野加宽，只用于全屏与外部视角，并标注会改变视野；Core 的判定使用固定的原版逻辑视野。
- 非飞行界面采用响应式布局。

细节见总计划 §7.1。
