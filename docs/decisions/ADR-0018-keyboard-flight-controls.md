# ADR-0018：飞行先用键盘，允许补充项目操纵键

## 背景

[总计划 §1.2](../plan/master-plan.md#12-首版交付范围)原先同时要求首版不开发手柄/摇杆，并要求横滚等操纵能用“原版的键盘或鼠标操作”完成。[P3-05 spec](../plan/p3/05/spec.md#执行前提)的审阅将这一前提与原版证据的冲突列为 blocker。

**已确认（代码）：** P3-06 的研究表明原版没有键盘俯仰、偏航或横滚，鼠标飞行也已排除。事实归[原版键位表](../original/input/key-map.md)与其引用的 executable 记录；本决策核对的是 `p3-06-flight-motion-spec` 提交 `fb6ea0bd58b8eca5ca773cded26ad91d3d3a32ae` 中同路径的“飞行操纵（代码确认，U-011）”一节。这些 P3-06 增量尚未集成到本工作树，不能把当前路径上的旧记录当成已更新。

P3-06 已在该提交的 `src/core/contracts/tick-input.ts`、`src/core/systems/flight-control.ts` 及同目录测试中提供设备无关的三轴契约和数字摇杆语义。它决定 Core 怎样消费操纵值，不选择物理键，也不依赖浏览器 Gamepad 设备。P3-05 可以直接将键盘意图适配到此契约，无需先做其他设备。

## 决定

- **先交付键盘飞行操纵。** 首版不实现 Gamepad、硬件摇杆、鼠标飞行、触控或其他新增飞行输入源，不以这些设备及其映射、校准或测试阻塞键盘工作。已有菜单与战略地图的鼠标操作保持不变。
- **保留原版已有的键位；为原版没有键盘绑定的操纵补充项目键。** 俯仰、偏航、横滚必须能用键盘完成，新增绑定须明确标为项目选择，不冒充原版键位，也不占用已确认的原版快捷键。它补充 [ADR-0004](./ADR-0004-keyboard-mouse-original-keys.md)，不取代其键鼠首发、按 `KeyboardEvent.code` 识别和浏览器冲突处理政策。
- **复用设备无关的轴契约。** 键盘适配器产生连续轴意图，由既有 Runtime/Session 送入 Core；“数字摇杆”只是操纵值的语义，不表示接入或调用 Gamepad API。Core 保留既有 −1…1 模拟轴，不为暂不支持的设备增设适配器。
- **本决策只解决输入范围和原版绑定缺失的前提。** 具体键位、Ctrl 横滚方式、重复节奏、清键与浏览器能力由 P3-05 契约确定；运动、单位、灵敏度和数值对照仍归 P3-06 的已定契约。不据此批准 I/J/K/L 等候选键或改动游戏规则。
- **原版对照不豁免。** 原版缺少键盘操纵时，按已核实的等价原版设备输入路径比较运动规则，不能要求不存在的原版键盘绑定，也不能把模拟器内刺激当成物理键盘或浏览器快捷键拦截的证据。

## 考虑过的其他方案

- 先实现手柄/摇杆再做键盘：违反当前“先做键盘”的范围决定，并引入不必要的设备前提。
- 继续寻找不存在的原版键盘操纵后才开工：与已确认的代码证据冲突，无法解除输入任务的阻塞。
- 把项目操纵键直接称为原版键位：混淆原版事实与兼容适配，失去可核对的差异记录。

## 后果

- 修正总计划 §1.2 与 §13 的相关表述，P3-05 不再因“只能使用原版键鼠操纵”而阻塞；无需改写 ADR-0004 的历史结论。
- P3-05 仍需核实候选键与原版菜单/快捷键的冲突，并在实际执行工作树中集成 P3-06 的契约和代码。它的其他研究门槛、共享契约同步与完整审批不因本决定而完成。
- P3-06 的三轴实现及其运动验收方向不变；其原版采集、容差和最终对齐仍按原任务执行，不视为已通过。
- 不新增存储、内容版本或依赖；未来新增输入设备须另行定范围，不由预留轴接口自动获得实现授权。

## 决定来源

用户于 **2026-10-10** 在请求核对 P3-06 会话与工作树、解除 P3-05 blocker 后明确决定：“我们可以先做键盘，不做游戏手柄或其他输入”。

本记录将该决定落实为键盘优先和项目操纵键的窄范围例外；“其他输入”限定为此次讨论的新增飞行输入源，不删除既有菜单/地图鼠标功能。此决定不等于批准 P3-05 的完整 spec、启动实现、提交或合并其他工作树。
