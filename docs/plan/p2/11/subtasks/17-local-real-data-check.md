- **脚本：** 被忽略的 `local/research/p2-11/scene-check.ts`，输出 `scene-check.json` 与 `.log` 只在 `local/`。
  - **共享流程：** 23 的作业持有者与伪造缓存移到同目录的 `pipeline.ts`，23 的 `import-check.ts` 改为引用它，重跑仍为 `PASS`。

  - **断言：**
    - **覆盖：** 条目逐一等于独立读取清单得到的全部模型、图像、调色板、布局、字库与效果 data Asset。三种效果角色都在。玩家、敌机与基地模型各有一个非空部件列表成功绘制。恰有两个布局。
