# 19 — 用户的真实界面核对

**契约来源：** [spec](../spec.md) 的 AC-21，以及验证策略的“实机与原版对照”。
**依赖：** 14, 18。
**执行方式：** 需用户：在真实机器上用本地生产预览与 Chrome 导入自己的基准 CCD/IMG，并确认导入、缓存恢复、查看与试听各项。
**执行状态：** 仅由 [goal tracker](../goal.md#子任务跟踪) 维护。

## 工作范围

- 由用户在真实机器上手工完成，agent 不代替：用本地生产预览（带拟定 CSP）与 Chrome，按 18 的本地导入指南，经真实界面导入自己的基准 CCD/IMG。
- 用户确认：
  - 识别出版本，状态依次出现“完整资源可查看”“已保存在本浏览器”“任务可载入 Core”；
  - 刷新后从缓存恢复成功，任务再次可载入；
  - 查看器中，玩家、敌机、基地模型，三种效果，每类图像、调色板、两个布局、全部字库都至少打开一项，没有错误；
  - 开火、导弹、爆炸、Warp 四个角色都能听到，停止按钮有效，返回菜单后声音停止；
  - 页面显示的作业、提交与恢复耗时。
- agent 的工作：准备清单与运行命令，记录用户提供的结论；用户未完成前本子任务保持 pending 或 blocked，执行记录写明等待用户。
- 若 16 在本子任务之后才完成，生产 `ConverterVersion` 会改变：需要用户重新导入，并再次确认导入与查看两项。

## 不包含
