# 08 — 前视来源与地图调色板研究（R1、R2）

**契约来源：** [spec](../spec.md) 的 S-05 中 R1、R2；[研究与入选门槛](../spec.md#研究与入选门槛)（参考画面、像素比较、置信度、透明规则单独取证、R1/R2 的结论要求）；[风险与恢复](../spec.md#风险与恢复)中“地图调色板无法从封包取得”；技术决定 1、5；AC-10。
**依赖：** 02、03。
**执行状态：** 仅由 [goal tracker](../goal.md#子任务跟踪) 维护。

## 工作范围

- **R1 前视来源：** 用 03 的容器读取比较 CCKD 10097 与 10103 的 slot 0（元素数、坐标与解码后的图像）。相同则选 10103；不同则按 spec 的像素比较规则与本地 F1 飞行截图比较选择；无法区分时本子任务 blocked（AC-10）。
- **R2 地图调色板：** 确定地图边框（CCKD 10103 slot 2）实际使用的调色板：
  - 存放的条目、条目类型与格式；须是生产覆盖文件中某个 IMFAT 条目、`palette` 允许的类型，格式为 DATA 的 6 位 VGA 整条目、图像记录的嵌入 BGR，或 CCKD 分组目录项 +0x04 指向的同格式调色板（2026-10-05 执行期修订，见 [goal 执行记录](../goal.md#执行记录)）之一；
  - 元素 +44 与调色板切换的关系；
  - 证据类型：EXE 中的使用路径（只读 Ghidra 分析），或候选调色板下的地图边框合成（经 02 的合成函数）与本地地图截图（B-001 列出的截图）的逐像素比较，置信度不低于高概率。
  - 不满足格式条件（例如只在 EXE 中或运行时推导）时本子任务 blocked，按 spec 风险与恢复修订后再继续；不以 DATA 或截图推出的颜色代替。
- **前视与地图边框元素的透明：** raw 元素“不透明”与“颜色键 k”的区分按 spec 的透明规则单独取证；RLE 元素的透明来自编码。结论供 12 的生产声明使用。
- **记录：** 写入 [cockpit](../../../../original/formats/cockpit.md) 与 [unknowns](../../../../original/unknowns.md) 的 U-029：R1、R2 的结论、证据类型、置信度、比较计数（截图文件名、比较像素数、一致数、不一致像素的分类）以及 +44 的关系。
- **方法：** 脚本与输出在被忽略的 `local/research/p2-07/`，经共享读取器与 02 的合成函数；只读 EXE 分析的地址与结论写入 cockpit，反编译输出不提交。

## 完成证据

2026-10-05：

- **方法：**
  - **脚本：** 都在被忽略的 `local/research/p2-07/`，在工作树根目录用 `node --preserve-symlinks --preserve-symlinks-main` 运行：`cockpit-palette.ts`（R1 比较与候选调色板）、`map-palette-search.ts`（由截图反推地图边框各索引的颜色，并在全部覆盖文件中搜索）、`map-palette-pointer.ts`（找出指向该调色板的指针字段）、`group-palette-compare.ts`（在分组调色板与 DATA 下合成后比较）、`front-mismatch.ts`（前视不一致区域与 index-0 像素）、`instrument-records.ts`（仪表记录矩形与不一致区域）。
  - **合成：** 读取经共享读取器，合成经 02 的 `composeLayout`。
  - **EXE：** 用已有的本地反编译导出，只读分析 `0x49848`、`0x3d1c0`、`0x49b2c`、`0x49c98`、`0x59608`、`0x59774`；文档只记地址与作用。
- **R1（高概率）：**
  - 10097 与 10103 的 slot 0 元素数、坐标与标志相同，图像不同，10097 另有自己的调色板。
  - 与 F1 截图 `srangers_002.png` 比较：10103 在 DATA 下一致 111,440/132,505；10097 在自身调色板下为 51,503，在 DATA 下为 16,066。选定 10103。
  - 10103 的 21,065 个不一致像素分为 17 个区域，全部落在该 slot 的 10 个仪表记录矩形内；`0x49b2c` 每帧在 +44 = 0 的元素之后绘制这些记录，因此每个区域都有运行时叠画的依据。
- **R2（已确认）：** 地图调色板是 CCKD 分组目录项 +0x04 指向的 768 字节 6 位 VGA 调色板（与 DATA 同格式）。生产来源为 10103 `groups/2/palette`；10101 slot 2 指向相同的调色板。
  - **EXE：** `0x49848` 选中分组时把该指针交给 `0x3d1c0` 载入，为 0 时用默认调色板。
  - **截图：** 在该调色板下，地图边框覆盖的 124,701 个不透明像素在 4 张地图截图（`srangers_000/001/004/059.png`）中全部一致。
  - **候选排除：** 边框使用的 216 个索引在 4 张截图中各只有一种颜色；在全部覆盖文件中搜索只找到这两个目标。7 个 `MAIN/` 封包的 56 种 DATA 或嵌入调色板都不能重现边框（最好的一种一致 4%）。
  - +0x08 在有调色板时为 768，是全部实例的观察不变量，含义为高概率的字节数。
- **+44 与 +48（已确认，EXE）：**
  - +44 是绘制遍：`0x49c98` 先画 +44 = 0 的元素，仪表记录之后再画 +44 = 1 的元素；地图边框为 1。它不切换调色板。
  - +48 为 1 时逐帧重绘，为 0 时只在整体重绘时绘制。
- **透明（已确认，EXE）：** raw 元素经 `0x59608` 逐行整体复制，每个像素都写入（含索引 0），所以前视与地图边框的 raw 元素都不透明；带颜色键的 `0x59774` 不用于元素；RLE 元素的透明来自编码。截图方面，F1 中不在仪表区域内的面板 index-0 像素都显示默认调色板的第 0 色，与不透明绘制一致。
