# 09 — 切片画面覆盖表与 HUD/地图图像族研究（R3、R4、R6）

**契约来源：** [spec](../spec.md) 的 S-05 中 R3（覆盖表与入选部分）、R4、R6；[研究与入选门槛](../spec.md#研究与入选门槛)（透明规则单独取证、切片画面覆盖表、图像族与入选规则）；[生产 Asset 与来源](../spec.md#生产-asset-与来源)的候选族；技术决定 5、7；AC-11。
**依赖：** 03、06、10。
**执行状态：** 仅由 [goal tracker](../goal.md#子任务跟踪) 维护。

## 工作范围

- **切片画面覆盖表：** 在 [hud](../../../../original/formats/hud.md) 或 [cockpit](../../../../original/formats/cockpit.md) 中为参考画面建立覆盖表，行包括 B-001 与 cockpit 记录的可见元素（驾驶舱面板、状态 MFD、仪表、雷达与目标提示、Warp 指示灯、各处文字、地图边框、地图单位标记、放大窗口图标、选取框与光标、网格、迷雾、范围圆、目标连线）。每行归入封包位图（写明图像族）、字库文字（引用 10 的结论）、代码绘制或未识别，并附证据。归为封包位图之前，在 `SR.NOB` 全部可解码的图像记录中检索（TEX、BITM、MFDD、CCKD 元素、05 记录的 TABL 图像列表）。
- **候选族判定：** 对状态 MFD 两个列表、10479、10481、10461、11401 的各区间，以及执行期修订加入的 BITM 10467，按 spec 规则：默认入选，只有不低于高概率的“切片不使用”证据才排除；入选族记录用途证据与比较计数、调色板绑定、透明规则（按单独取证规则）与行序及其证据、置信度。
- **R4：** 玩家飞船状态 MFD 是 MFDD 10473 还是 10475，以及两个列表的透明规则。
- **R6：** TABL 10165 的图像是否出现在参考画面中（1 倍与 2 倍检索），记录有界检查结果；出现时本子任务 blocked，修订 spec 的范围与预算后再继续。
- **候选之外的封包位图族：** 覆盖表若归类到候选族之外的封包位图族，本子任务 blocked，先修订 spec。
- **记录：** U-029、U-030 随之更新，未解决部分写明转交 P3 或 P4。入选族未达交付条件时，本子任务 blocked 并记录恢复条件（例如需要哪种状态的截图），不把缺口自动转给 P3。
- **方法：** 脚本与输出在 `local/research/p2-07/`，经共享读取器（03、06）与 P2-05 的 `expandImage`；只读 EXE 分析只记地址与结论。

## 完成证据

- **结论位置：** [hud 的绘制路径](../../../../original/formats/hud.md#hud-and-map-drawing-paths-confirmed-exe)与[覆盖表与图像族](../../../../original/formats/hud.md#slice-screen-coverage-and-hud-image-families-r3-r4-r6)；cockpit §2 的 MFDD 透明与 10475；unknowns 的 U-029、U-030。
- **EXE（只读）：** 仪表与地图绘制函数只经运行时建立的表调用，分析项目中没有反汇编。本地 Ghidra 脚本（`local/research/p2-07/ghidra/`）在内存中反汇编，不保存项目。脚本查找条目 ID、句柄地址与全部 blit 调用，并在指令层核对颜色键参数。结论：
  - HUD 组按模式与玩家机型载入（`0x4ca80`）；
  - 状态显示屏背景不透明、叠加图颜色键 0（`0x4d50c`、`0x4d0e0`）；
  - 10467 页面背景与 10479 仪表条（`0x4d800`）；
  - 10461 与 11401 由战略地图以颜色键 0 绘制（`0x49f8c`、`0x4abe4`）。
- **全量检索（不过滤）：** 231 个可解码记录、880 种读法，没有不可解码的记录。24 种读法没有不透明像素；56 种单色读法匹配不唯一。多色的精确位置只有 CCKD 前视元素 1–3、地图边框、10461 两色记录（4 个圆环标记内的 7 处，不唯一）与 11401 记录 17。`full-search-all.ts`。
