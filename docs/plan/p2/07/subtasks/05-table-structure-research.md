# 05 — TABL 图像列表结构研究

**契约来源：** [spec](../spec.md) 的 S-05 中 R3 的结构部分；[研究与入选门槛](../spec.md#研究与入选门槛)、[容器子资源](../spec.md#容器子资源)中 `records/<i>` 一行；技术决定 3；AC-11 中“入选 TABL 的图像列表结构”一项。
**依赖：** 无。
**执行状态：** 仅由 [goal tracker](../goal.md#子任务跟踪) 维护。

## 工作范围

- **对象：** 候选 TABL 条目 10479、10481、10461、11401（[hud §2](../../../../original/formats/hud.md#2-tabl-entries-in-srnob-contents-likely) 记为图像记录列表），以及同一 `SR.NOB` 中结构相同的其他 TABL 条目（例如 10483、10165），用于确定结构的适用范围。
- **要确定的结构：** 列表头部（记录数与记录指针或偏移的存放方式）、记录是否就是 36 字节图像记录、指针是否经重定位、记录之间是否有其他字段、条目尾部是否有其他数据。结论须在全部同类实例上逐一成立才可记为已确认；有例外时写明例外并缩小适用范围。
- **11401 的区间：** 按记录尺寸与在参考画面中的用途，记录 R3 的三个区间（机型图标、地图点与其他符号）的起止序号，序号为完整列表内的序号，与 spec 的命名规则一致。用途置信度按 spec 门槛标注；区间划分不确定时如实记录，由 09 判定入选。
- **方法：** 本地脚本放在被忽略的 `local/research/p2-07/`，经共享的源读取器（`openVerifiedSource` 或 nob-check 的读取链与 `readImageRecordHeader`）读取，不手写第二套封包读取。只读 EXE 分析可用于确认列表的读取方式。
- **记录：** 结构写入 [hud](../../../../original/formats/hud.md) 的 TABL 一节（结构、适用条目、置信度、证据类型与命令），U-030 的相关描述随之更新。只写结构、计数与判定，不写原版字节或反编译输出。
