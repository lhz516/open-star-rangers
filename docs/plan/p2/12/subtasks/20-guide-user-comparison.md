# 20 — 本地导入指南：用户对照步骤与安全记录模板

**契约来源：** [spec](../spec.md) 的 S-13、AC-23 的指南部分；为 21、23 的用户会话提供操作说明。
**依赖：** 无。
**执行方式：** 自动。
**执行状态：** 仅由 [goal tracker](../goal.md#子任务跟踪) 维护。

## 工作范围

- 在 [local-import.md](../../../../guides/local-import.md) 新增“原版本地对照（P2-12）”一节，与既有“用户实机核对”分开：
  - **会话准备：** 本地生产预览（带拟定 CSP）与 Chrome；记录日期、Chrome 完整版本、OS、候选提交；经真实界面导入，同源刷新后恢复；记录页面显示的作业、保存与恢复耗时。
  - **模型与效果（V-1、V-2）：** 可复现的视角与缩放；用左右不对称的几何或贴图特征判断翻转与镜像；颜色须结合来源映射与可比区域，不以同色相通过；明暗差异只在有独立依据时归因原版光照；效果的接缝面单独判断。
  - **二维显示：** 在查看器中确认两个布局、HUD 图像、字库与调色板的实际显示。
  - **试听（A-1）：** 按 14 的清单逐个播放，与对应 WAV 比较三项（同一声音、音高与速度、无符号/字节序/声道噪声），完整播放一次并验证停止；每个角色至少一次直接对照基准 DOSBox-X 中的原版；真人听到，不以控制器状态代替。
  - **任务诊断：** 导入后与刷新恢复后各确认一次“任务可载入 Core”与结构摘要一致。
  - **补拍：** 指向[基准环境](../../../../guides/baseline-environment.md#运行原版)与 13 的清单；新文件不覆盖旧文件。
  - **安全记录模板：** 对照项 ID、Asset ID、截图文件名、判定分类（一致、差异已修正、差异待修复、差异已归因、无法判定）与理由；不记录像素值、颜色值、原版文字或声音，不录音，截图只留在 `local/`。
- 更新 `updated:`；既有内容不变，只在“查看器操作与限制”的呈现限制一句中指向新节（呈现结论由 22 更新）。
