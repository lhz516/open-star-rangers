# 16 — 布局与透明对照（V-3）

**契约来源：** [spec](../spec.md) 的 S-08、[原版本地对照](../spec.md#原版本地对照)的 V-3；AC-16 的 agent 部分（用户的浏览器确认在 21）。
**依赖：** 12, 15。
**执行方式：** 自动。
**执行状态：** 仅由 [goal tracker](../goal.md#子任务跟踪) 维护。

## 工作范围

- 被忽略的本地脚本（计划新增 `local/research/p2-12/layouts/`）：
  - 经候选的生产作业取得前视驾驶舱与地图边框布局，用生产 [composeLayout](../../../../../src/content/graphics/compose-layout.ts) 合成 640×480 画面。
  - **独立的比较区域与透明掩码：** 先按原版绘制路径（[cockpit](../../../../original/formats/cockpit.md#group-palette-and-drawing-confirmed) 的元素矩形、分组调色板、绘制遍、逐帧重绘的仪表矩形）确定，不由被测结果的不透明像素反推；静态覆盖区域必须非空。
  - 与每张参考截图（原始分辨率；前视至少 2 张场景不同，地图边框按 13 的清单）逐像素比较：排除区域之外不一致为 0；每个排除区域链接依据与置信度。
  - **透明：** 在不同背景的截图中，或以独立绘制路径证据确认透明处；不以“两帧颜色相同”推断不透明；截图不足时回到 15 补证。
  - 确认地图边框使用的调色板就是生产的地图调色板。
- 证据只记截图文件名、比较像素数、不一致数与排除区域数；agent 不查看图像。

## 验收标准

- [x] AC-16（agent）：两个布局在独立定义的非空静态区域内，坐标、颜色、叠放与掩码满足 V-3，排除区域之外不一致为 0；每个排除区域有依据与置信度。

  - **被测画面：** 复用 [P2-11 `pipeline.ts`](../../11/subtasks/23-local-real-data-import.md#完成证据) 的 `jobOwner()` 运行生产作业，`takeGroups()` 后经查看器的 `viewerCatalog`/`resolveEntry`（内部调用生产 `composeLayout`）取得两个 640×480 画面。直接调用 `composeLayout` 的结果与查看器画面逐字节相同。

    - 透明：在元素矩形内，但没有元素写入；
    - 未覆盖：在所有元素矩形之外。
