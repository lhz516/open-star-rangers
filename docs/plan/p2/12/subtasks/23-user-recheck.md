# 23 — 用户复核受修正影响的对照项

**契约来源：** [spec](../spec.md) 的 S-11、[候选身份](../spec.md#候选身份)中的“候选变化”；AC-14、AC-15、AC-21 的复核部分。
**依赖：** 22。
**执行方式：** 需用户：在新候选的本地生产预览中重新查看 22 列出的受影响模型或效果，确认修正后的外观。
**执行状态：** 仅由 [goal tracker](../goal.md#子任务跟踪) 维护。

- 22 有修正时：用户在新候选上只重做受影响的对照项（不必重复全部会话），按 20 的指南记录判定；记录新候选提交与 Chrome 版本。
