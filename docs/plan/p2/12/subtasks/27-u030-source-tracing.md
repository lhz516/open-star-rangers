# 27 — 修复：U-030 未识别 HUD 元素的来源追踪

**执行状态：** 仅由 [goal tracker](../goal.md#子任务跟踪) 维护。

## 工作范围

- 对 [24](./24-original-backfill.md#完成证据) 在 [hud 的 U-030 影响判断](../../../../original/formats/hud.md#unidentified-elements-and-the-u-030-impact)中列出的每个未识别元素（状态显示屏文字后的标记、`srangers_068` 左显示屏内容、能量页面条纹、Warp 点状条、雷达接触点、地图圆环标记、选中单位方框与信息小窗），给出有依据的来源结论：
  - **代码绘制：** 指出绘制函数地址与它不读取图形资源的依据；
  - **已交付图形：** 指出切片中的 Asset 或记录，以及绘制路径；
  - **切片外或缺少的图形：** 指出条目 ID 与绘制路径。
- 按 24 记录的恢复检查进行：解码 SNIP 10487 的结构（只记结构、计数与判定），在左显示屏的本地截图中检索它的帧；追踪 `0x4d0e0`（标记）、`0x4c674`（雷达）以及 `0x49f8c`、`0x4abe4`、`0x4afc0`–`0x4b360`（地图圆环、方框、标签）。
- 判定路由：证实是代码绘制，或由已交付图形绘制的元素，记为 P3 的动态 HUD 绘制；证实切片缺少必需图形的元素，记为 P2-07 的资源缺口（本项不修复，相应 AC 保持 blocked，并写明恢复条件）。仍无法定论的元素写明已排除的范围与剩余候选。
- 结果写入唯一权威位置（hud 与 U-030），带置信度与候选适用性；格式文档用英文。
