# 17 — HUD、字库、调色板与贴图覆盖（V-4）

**契约来源：** [spec](../spec.md) 的 S-08、[原版本地对照](../spec.md#原版本地对照)的 V-4 与 V-1 中“本地脚本核对模型/材质/贴图引用与调色板映射”；AC-17 的 agent 部分（用户确认在 21）。
**依赖：** 12, 15。
**执行方式：** 自动。
**执行状态：** 仅由 [goal tracker](../goal.md#子任务跟踪) 维护。

## 工作范围

- 被忽略的本地脚本（计划新增 `local/research/p2-12/hud/`）建立覆盖表：候选中每个图像、字库、调色板 Asset 及每个模型与效果贴图，到原版消费位置的对应。
  - **直接对照：** 在已确认的绘制位置（[hud 绘制路径](../../../../original/formats/hud.md#hud-and-map-drawing-paths-confirmed-exe)：左显示屏页面、放大窗口图标、地图单位标记等）逐像素比较，按其调色板与颜色键透明；不一致为 0。
  - **排除任意匹配：** 单色、全透明或被遮挡的读数不能以全屏任意匹配证明身份。
  - **等价证据链：** 未出现在参考画面中的项，须有同源字节或转换规则等价，并有已对照通过的代表项；单纯“未截到”不是通过理由，须补拍（15）或写明既有范围依据。
  - **字库：** 已匹配的文字段逐像素一致，裁剪、字距与字符映射分别判断（[hud §1.2](../../../../original/formats/hud.md#12-fonts-used-on-the-reference-screens-r7)）；未匹配段逐一列出原因；纯运行时文字布局与未使用字形的规则保持 P3 边界。
  - **调色板：** 每个调色板 Asset 被一个已通过的对照项使用，否则列出。
  - **贴图：** 核对模型与效果的材质引用、贴图来源与调色板映射（最近色规则见 [textures §3](../../../../original/formats/textures.md#nearest-colour-metric-and-tie-rule-confirmed)）；可见外观的判定来自 21 的 V-1、V-2，最终覆盖在 26 汇总。
- **U-030 影响：** 对覆盖表中未识别的元素（雷达接触点、地图红色圆环标记、状态显示屏括号状标记），记录是否可能缺少切片必需图形的证据，供 24 判断；不能仅因未找到来源就归 P3。
- 证据只记 Asset ID、文件名、计数与判定；agent 不查看图像。

## 不包含
