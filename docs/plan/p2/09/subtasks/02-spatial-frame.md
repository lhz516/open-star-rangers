# 02 — 地图/Warp 空间框架研究

**契约来源：** [spec](../spec.md) 的 S-02、AC-02；[空间框架的研究结论](../spec.md#空间框架的研究结论)与[研究门槛与阻塞](../spec.md#研究门槛与阻塞)。
**依赖：** 01。
**执行状态：** 仅由 [goal tracker](../goal.md#子任务跟踪) 维护。

## 工作范围

- **坐标轴约定：** 结合 01 对段 6 与重新缩放的结论，确定任务位置中哪两个轴构成战略地图平面、哪个轴为竖直方向，以及方向（正负）。
- **地图框架：** 确定主地图显示的世界区域的来源与形状：
  - 只读静态分析地图绘制与地图选取相关代码（Ghidra `-noanalysis -readOnly`），定位从世界坐标到地图像素的投影所用的参数及其来源（任务数据、封包条目、主程序数据或运行时状态）；
  - 必要时，在本地把所选任务的对象位置按候选投影与既有地图截图（如 [B-001](../../../../original/behavior/B-001-strategic-map.md) 记录的第一关地图截图）对照，只记录方法、判据与结论。
- **Warp：** 确认 Warp 是否使用任务数据之外的静态空间数据（例如固定的目的地网格或范围）。耗能、过程与误差规则不在本任务内。
- **结论：** 按 spec 的四种结论之一记录：
  - 格式事实写入 `docs/original/formats/` 的相应文档，行为事实写入 [B-001](../../../../original/behavior/B-001-strategic-map.md)；
  - 必要时在 [unknowns](../../../../original/unknowns.md) 新增 U 项；
  - 结论 1 时注明参数位于封包条目还是非封包文件（决定 07 是否适用）；结论 2 时注明 SCEN 中的结构位置（供 05 解析）。
- **研究门槛：** 结论 4，或实际投影不是轴对齐正方形区域，或发现 Warp 专用静态数据时，本子任务在 goal 中标为 blocked，恢复条件为 spec 修订经审阅并由用户重新批准。
- **与 spec 修订的关系：** 01 触发研究门槛后，spec 已按 01、02 的合并研究结果修订一次，记录结论 2（[空间框架的研究结论](../spec.md#空间框架的研究结论)）。本子任务负责把该结论的事实、置信度与证据写入 `docs/original/`；若记录时发现与 spec 所述不符，按研究门槛处理。
