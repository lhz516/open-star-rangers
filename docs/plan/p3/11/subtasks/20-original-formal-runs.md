**契约来源：** [spec](../spec.md) 的 S-11、AC-15；[失败链运行](../spec.md#失败链运行)；07 定稿的 D-02。

**执行方式：** 自动。
**执行状态：** 仅由 [goal tracker](../goal.md#子任务跟踪) 维护。

## 工作范围

- 按 D-02 的配方族、预算与停止条件，只为 06 缺口表中无法闭合的必需缺口集中取证：
  - **失败链（首选一次运行）：** 所选任务、难度 19、无僚机；同一次尝试中损失→救援→损失→救援→第三次损失→失败；任务构建时核实身份；按事件锚读取损失入口、计数、视角、逃生舱到期、恢复前后字段（移动块、武器、资源、来源记录、限频、候选基地与次序）、过场行号与失败处理入口；区分 `0x67b98` 内部与外层 `0x32e14` 的读数。
  - **其他缺口：** D-02 判定为必需运行量、且无法由复用证据闭合的成功链或分支锚点，尽量合并进同一次运行。
- agent 用[模拟器内输入](../../../../guides/runtime-measurement.md#模拟器内输入)独自完成；不改写生命、位置、RNG、主/子状态或救援计数，不用受损注入、调试命令或作弊。单一会话、文件保护与自有进程清理。
- 样本不合格与行为不一致分别报告；只在 D-02 允许的条件下重做。预算用完仍缺证据时记为 blocked，写明尝试与恢复条件；确有合规途径无法完成的具体操作，才请用户做最小操作。
