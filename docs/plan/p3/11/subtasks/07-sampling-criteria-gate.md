# 07 — D-02 证据复用、采样与判据关卡

**契约来源：** [spec](../spec.md) 的 AC-01、AC-15；[实施关卡](../spec.md#实施关卡) D-02；[判据](../spec.md#判据)、[失败链运行](../spec.md#失败链运行)、[逐分支证据与缺口](../spec.md#逐分支证据与缺口)。
**依赖：** 04, 06。
**执行方式：** 需用户：批准 D-02 的定稿。采样判据与预算的批准须来自用户的明确回答，agent 起草推荐方案与被排除方案后提问。
**执行状态：** 仅由 [goal tracker](../goal.md#子任务跟踪) 维护。

## 工作范围

- 依 04 的事实与 06 的审计、缺口表与预实验，在本任务 spec 写入“D-02 定稿”小节：
  - 每个观测量的单位、分辨率、窗口、事件锚、样本数及其依据；精确判据的依据，或由分辨率与误差预算导出的容差；
  - 复用证据的资格与适用范围；必需运行量与可只用代码核对的部分；
  - 失败链与其他补采的配方族、启动次数、游戏/宿主时间与停止预算、重做条件；
  - 两层（单次转移、默认步长连续）的配对与报告规则；
  - 不使用无依据的百分比、“一个 tick”或零误差。
- 在 B-003、B-005 中写入原版一侧的测量方法，引用本次批准记录。
- 时机：在 20 的正式采样之前，且在任何新版的对应连续结果（19）出现之前。

## 不包含
