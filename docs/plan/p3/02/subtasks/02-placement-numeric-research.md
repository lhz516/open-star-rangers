**交给 06 的独立推导**（只由代码推出；测试期望不得用被测实现计算）。记号：每次 rand 取 D = {0, …, 32767} 中一个值；C = 32769 ÷ 2^30（即 f32(1/32767)）；R 为 f32 舍入，R_n 为就近（平局取偶），R_z 为向零。原版所有调用来自同一个 LCG，相邻值是其状态的确定函数，联合分布未分析；按 spec 的“不复现原版序列”，06 把每次调用建模为 D 上独立均匀的值，下面的组合计数都是这一模型下的计数。坐标绝对值小于 2^22 时，换算乘积与矩形、全世界缺省、锚点、段 5 成员的中间值在 double 中精确，每个坐标只舍入一次；世界边界处理与姿态归一化逐步舍入，单独给出（6、7）。

1. **换算：** q = R(15000 ÷ s)，s = 8000 时 q = 15/8。f32 位置 p' = R(p × q)；i32 字段 v' = trunc(v × q)，q = 15/8 时为 trunc(15v ÷ 8)。区间：v ≥ 0 时 v' ∈ (v·q − 1, v·q]，v < 0 时 v' ∈ [v·q, v·q + 1)；p' 与 p·q 之差在 R_n 下不超过半个 ulp，在 R_z 下小于一个 ulp 且朝向零。换算对象：带 `object` 来源的记录恰好一次；只有 `group-template`/`group-member` 来源的记录与 `wingman-option` 记录不换算；布局偏移不换算、不交换轴（载入变换已在内容层）。世界半宽 X = 7500 × n，n 为扇区数，等于 halfExtent（参考单位）× 15000 ÷ s。
2. **矩形（`0x6883c`）：** 先抽 r_x 再抽 r_y。x = R(N ÷ 2^30)，N = x0 × 2^30 + |x1 − x0| × r_x × 32769（整数，测试可用 BigInt 求精确值后再舍入）；y 同理；z = +0。任何 r 的结果都是精确值的 R。r = 0 得 x0（精确）；r = 32767 的精确值比上端少 δ = |x1 − x0| × 2^−30。δ 小于上端下方 f32 间距时：R_n 在 δ 也小于该间距一半时得上端，R_z 对正上端得其前一个 f32、对负上端得上端本身；上端为 0 时两种舍入都得 −δ（可精确表示）。精确值随 r 严格递增，舍入后单调不减；原像计数用 D 的 32,768 个值穷举（跨度小而离原点远时会有多个 r 落到同一结果）；|x1 − x0| = 0 时只有一个值。跨度从 x0 起，与 x0、x1 的大小顺序无关。
3. **全世界缺省（`0x68c98`）：** 先 r_x 再 r_y。W = 15000 × n，h = W ÷ 2；x = R((W × r_x × 32769 − h × 2^30) ÷ 2^30)，y 同理，z = +0。r = 0 得 −h；r = 32767 的精确值为 h − W × 2^−30，其 R 按 2 的规则：W × 2^−30 小于 h 下方间距的一半时（全部出货世界成立），R_n 得 h，R_z 得 h 的前一个 f32。
4. **锚点（`0x68708`）：** 六次抽取，次序为 x 符号、x 大小、y 符号、y 大小、z 符号、z 大小。符号：偶数 +1、奇数 −1，各 16,384 个原像；大小 m = 400 + (r mod 200)：m = 400–567 各 164 个原像，m = 568–599 各 163 个（168 × 164 + 32 × 163 = 32,768）。偏移 o = s × m 在两次抽取的 2^30 个组合中的原像为 16,384 × count(m)；o ∈ [−599, −400] ∪ [400, 599]，不取 0。坐标 x = R(p_x + o)，和在 double 中精确。锚定对象：锚点记录种类的种类表中，按分配次序第一个来源记录为该锚点记录的对象，不论状态，读其当时位置；不存在或锚点记录种类为 0 时走 3，抽取两次。
5. **选择优先级：** +0x40 非零（网格，创建时拒绝）> +0x48 非空（锚点）> 位置三个分量去掉符号位后不全为零（存储位置，逐位复制，±0 视为零，不抽取）> +0x44 非空（矩形）> +0x4C 非空（路径，内容不能表达）> 全世界缺省。
6. **世界边界（每条路线之后一次）：** 若 −X + 200 ≤ x ≤ X − 200 且 y 同样成立（闭区间），不变；否则 L = √(x² + y²)，dx = R((x × (1 ÷ L)) × −300)，dy 同理，x' = R(x + dx)，y' = R(y + dy)，z 不变，不夹取、不再检查。R_n 下与 JavaScript 的 `Math.fround(x + Math.fround(x * (1 / Math.sqrt(x * x + y * y)) * -300))` 逐位相同（双精度、同一运算次序）；R_z 下每步向零，结果与 R_n 结果相差至多一个 f32 ulp。n ≥ 3 时全世界缺省点移动后必在内缩矩形内。
7. **初始姿态：** 用最终 x、y。s_x = x ≥ 0（含 −0）时 +1，否则 −1，s_y 同理；第三行（前进方向）f = (s_x × c, s_y × c, 0)，c 为位模式 0x3F3504F3 的 f32（两种舍入相同）；第二行 (0, 0, 1)；第一行 (−f_y, f_x, 0)，其 z 可为 −0。
8. **段 5：** 成员 i = 0 … k − 1，L 为布局数。i mod L = 0 时对模板执行 5–7，得锚点 A 与姿态 Q（含模板自己的路线与边界处理）；成员 i 的位置 = R(A + l)，l = layout[i mod L]，逐轴计算，不换算、不做边界处理、不加固定高度；姿态取 Q。同一周期内成员按固定偏移完全相关；不同周期与不同请求独立抽取。模板 +0x58、+0x5C 非零时在每个成员实例化前复制到成员的运行记录。对象 +0x80 = R(l − layout[0])（P3-08 使用）。锚点或实例化失败时，余下成员不建，段 5 +20 不增。
9. **抽取次序：** 每个请求的放置抽取先于该对象在 `0x67938` 内的抽取（名称、`0x3060c`、`0x68050` 的初始目标点、+0xC8 计时器，归 Q-04/Q-05/Q-07）。段 5 请求为：锚点 → 成员 0 的实例化 → 本周期其余成员 → 下一个锚点。
10. **舍入方向：** 启动时 R_n；渲染器首次光栅化后一直为 R_z。重试、后续任务及任务首个渲染帧之后的放置为 R_z（高概率）；启动后第一个任务的开局放置在此前菜单未渲染 3D 时为 R_n（未确认）。R-02 的支持集对两种舍入都推导；06 按协调者决定（[goal 执行记录](../goal.md#执行记录)）对每次 f32 写回用 R_z，double 中间运算仍为就近。
