# 09 — 真实内容本地核对

**契约来源：** [spec](../spec.md) 的 S-06、S-07、S-09；AC-13；[对照方法与判据](../spec.md#对照方法与判据)的 R-02 调度行与独立性要求。
**依赖：** 07。
**执行方式：** 自动。
**执行状态：** 仅由 [goal tracker](../goal.md#子任务跟踪) 维护。

## 工作范围

- 在被忽略的 `local/research/p3-02/real-content/` 写本地核对脚本：按 [tools/logic-check.ts](../../../../../tools/logic-check.ts) 的做法，用生产导入作业转换开发者本地的 CloneCD 文件组，经 `validatePackage` 取得资源包与 `ContentIdentity`，解码三份逻辑 Asset，再用 07 的创建入口建立世界（难度 19；僚机 null，以及至少一个名单索引，可覆盖全部 5 个）。
- 逐 tick 运行到排程队列耗尽（另加余量），统计累计实例化：按种类的数量、来源（声明或编组与成员位置）与生效 tick/时钟。
- 期望来自 03 的独立实例化清单与 `docs/original/` 记录，不复用被测 Core 的排程或放置 helper：玩家 1；敌方类 16（种类 `0x80` 12、`0x100` 4）；种类 `0x20000` 4；其余按数据推出；带僚机时恰好一个所选名单项，无僚机时没有种类位 1 的对象。累计计数与最终存活数分开。
- 输出只含计数、来源编号、时刻、判定与身份（内容身份、应用候选提交），不含名称、坐标或 payload；输出与脚本都留在 `local/`。
- 不一致时：记录差异，判断是实现缺陷还是研究缺口，由协调者新增修复子任务，本项不放宽判据。
