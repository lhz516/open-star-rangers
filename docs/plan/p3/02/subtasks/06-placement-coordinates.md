# 06 — 放置服务、坐标换算与原版随机映射

**契约来源：** [spec](../spec.md) 的 S-02（数值与随机数）、S-06（放置部分）；AC-06；[数值表示](../spec.md#数值表示)、[随机数](../spec.md#随机数)、[任务实例化](../spec.md#任务实例化)的放置行、[对照方法与判据](../spec.md#对照方法与判据)的 R-02 放置行、技术决定 3、11。

**执行方式：** 自动。
**执行状态：** 仅由 [goal tracker](../goal.md#子任务跟踪) 维护。

## 工作范围

- **坐标换算（按 02 的 Q-03、Q-11）：** 参考单位乘以“运行时比例 ÷ `referenceScale`”；带 `object` 来源的记录只换算一次，仅从段 5 可达的记录与 SCCT 僚机记录按 Q-03 的结论处理；生成矩形按 i32 规则换算；编组布局偏移不再换算或交换轴；取整与存储精度在 Q-03/Q-11 确认的边界上独立实现。f32 写回一律向零舍入，双精度中间运算按 JS 就近舍入（见 [goal 执行记录](../goal.md#执行记录)的 Q-11 舍入方向决定）。
- **世界矩形：** 由已核验的 `mapFrame` 与比例推出；只接受本切片的地图轴与中心（其他取值由 07 在创建时拒绝），不把任意旋转的地图框架当作世界坐标。
- **原版随机映射（按 02 的 Q-02）：** 从世界 RNG 的 uint32 输出构造与原版 `rand()` 取值域等价的有限整数域，再按原版的取模或缩放得到结果；每轴抽取的次数与次序符合原版。不复现原版序列，不改 [rng.ts](../../../../../src/core/determinism/rng.ts) 的契约。
- **放置例程：** 锚点偏移（锚定对象不存在时改用全世界缺省）、矩形内均匀、全世界缺省、存储位置；按 `0x68398` 的优先级选择（零向量判定忽略符号）；放置结果与世界矩形比较后的处理按 Q-02。网格与固定高度路径不实现。放置服务对外提供给 07 的实例化与 P3-11 的救援放置。
- **测试（期望不得由被测实现计算）：**
  - 每个随机映射：按 02 的独立推导，覆盖有限域到输出的映射、支持集端点的包含性、各结果的原像计数、轴之间与成员之间的关联；可枚举的域穷举，否则覆盖每个分段或取模边界。
  - 舍入：在 Q-03/Q-11 确认的转换边界上测试。
  - 选择优先级、锚点缺失回退、存储位置与世界矩形边界。
  - 不使用卡方检验或按种子挑选结果。

## 完成证据

2026-10-09，worker 06。新增 `src/core/rules/` 的四个模块及相邻测试，期望一律来自 [02 的独立推导](./02-placement-numeric-research.md#完成证据)（下称“推导”第 n 项）与协调者的 Q-11 决定，不调用被测实现生成期望。

**实现：**

- [float32.ts](../../../../../src/core/rules/float32.ts)：`toFloat32TowardZero`（f32 向零舍入，保留 ±0，溢出得最大有限值）与 `isFiniteFloat32`。按 Q-11 决定，每次 f32 写回都用它；double 中间运算保持 JS 就近舍入，模块说明写明与原版逐步向零至多相差一个 f32 ulp。
- [coordinates.ts](../../../../../src/core/rules/coordinates.ts)（Q-03，推导第 1 项）：
  - `runtimeFrame` 由 `coordinates` 与 `mapFrame` 得到 q = R_z(15000 ÷ s) 与扇区数 n = 2 × halfExtent ÷ s；只接受切片的地图框架（`+x`、`-y`、中心为原点、n 为 1–559 的整数），其他取值以 `CoreInputError`（`<path>.mapFrame.*`、`<path>.coordinates.referenceScale`）拒绝，供 07 在创建时调用。世界矩形 ±7500n 与缺省范围 15000n 都由 n 推出。
  - `runtimePosition`：带 `object` 来源的声明换算一次 R_z(p × q)，不论是否同时被编组引用；只有 `group-template`/`group-member` 或 `wingman-option` 来源的位置按原版不换算，只校验。
  - `runtimeRegion`：每个 i32 值 trunc(v × q)（向零），并要求每轴从 x0（y0）起跨 |x1 − x0| 的整个支持集在范围内（反向矩形也覆盖）。
  - `runtimeVector`：布局偏移等运行时单位向量只校验，不换算、不交换轴。
  - 定义域：输入为 f32 值，运行时坐标绝对值 < 2^22，i32 输入 < 2^29，n ≤ 559。在此范围内换算与随机放置的中间值在 double 中精确，每个坐标只舍入一次。
- [original-random.ts](../../../../../src/core/rules/original-random.ts)（Q-02，推导第 2–4 项）：`randOfUint32` 取世界 RNG uint32 输出的高 15 位，D = {0, …, 32767} 的每个值恰有 2^17 个原像；`RandStream` 每个 rand 值消耗一次 `nextRandom`，不改 [rng.ts](../../../../../src/core/determinism/rng.ts)。`rectangleCoordinate`、`worldCoordinate`（输入世界宽度 W = 15000n）与 `anchorOffset` 按原版的缩放与取模实现，取值域外的 rand 为 `CoreFaultError`。
- [placement.ts](../../../../../src/core/rules/placement.ts)（推导第 4–9 项）：
  - `placeRecord(record, world, rand)` 按 `0x68398` 的优先级选择路线：网格（非零即内部故障，先于任何抽取）> 锚点 > 存储位置（去掉符号位后不全为零，逐位复制）> 矩形 > 全世界缺省。锚点路线的目标为空时改用全世界缺省，抽取两次。
  - 每条路线之后做一次世界边界处理（内缩 200 的闭矩形，之外沿 x/y 朝原点移动 300 一次，不夹取、不再检查，z 不变），再求初始姿态（按最终 x、y 的符号，−0 视为正，c 的位模式为 0x3F3504F3）。
  - 抽取次序：锚点为 x 符号、x 大小、y 符号、y 大小、z 符号、z 大小；矩形与全世界缺省先 x 后 y；存储位置不抽取。
  - `memberPosition(A, l)` 逐轴 R_z(A + l)，不换算、不做边界处理；姿态由调用者取本周期锚点的姿态。
  - 锚定对象的查找（锚点记录种类表中按分配次序第一个、不论状态的对象；种类 0 时没有）由调用者完成，经 `PlacementRecord.anchor.target` 传入，接口注释写明该规则。`0x68398` 中世界检查之后的扇区资源测试不抽取，留给实例化（07）。

**测试**（`src/core/rules/*.test.ts`，[derivation.test-support.ts](../../../../../src/core/rules/derivation.test-support.ts) 用 BigInt 有理数逐位舍入，不用 `Math.fround`、typed array 或被测代码）：

- **rand 映射：** 32,768 个输出的原像区间端点逐一核对（每个恰 2^17 个）；`RandStream` 每值一步 RNG。
- **矩形映射：** 7 组端点（跨原点、上端为 0、负上端、反向、远离原点的小跨度、反向且到达定义域边缘、零跨度）对 D 穷举，与 BigInt 精确值的 R_z 逐位相等。端点：r = 0 得 x0；r = 32767 时正上端得其前一个 f32，负上端得上端本身，上端 0 得 −15000 × 2^−30（负值而非 0），反向时从 x0 向上。原像计数：跨度大时 32,768 个结果互不相同且严格递增；4,000,000–4,000,001 得 4 个结果，各 8,192 个原像，分界 r = 8191/8192、16383/16384、24575/24576 由手算给出。
- **全世界缺省：** n = 1、3、6、14、559 对 D 穷举，结果与 BigInt 一致且一一对应；r = 0 得 −h，r = 32767 得 h 的前一个 f32（n = 6、14、559 手算）。
- **锚点偏移：** 符号的奇偶各 16,384 个原像；大小 400–567 各 164 个、568–599 各 163 个（推导表）；符号与大小分别由各自抽取决定，所以偏移 o 的原像为 16,384 × count(|o|)，从不为 0。
- **放置：**
  - 优先级各分支：锚点优先于存储位置与矩形；锚点缺失走全世界缺省；存储位置优先于矩形，−0 保留；全为 ±0 时走矩形；无任何字段时走全世界缺省；网格先于抽取拒绝。
  - 抽取次数与次序用脚本化 rand 源核对；用 `RandStream` 核对 RNG 步数。
  - 世界边界：±44800 的边界本身不动，超出一个 f32 间距即移动；65536 → 65236 精确，y 为 +0；200000 → 199700 仍在外，不夹取；对角点逐位等于按推导式与参考 R_z 的结果，与就近舍入式相差不超过一个 ulp。
  - 切片式边带矩形：参考 x 20000–24000 换算为 37500–45000，最大不动的 r = floor(7300 × 2^30 ÷ (7500 × 32769)) = 31893，31894 与 32767 被移动。
  - n = 3 时每轴对 D 穷举（另一轴取 0、16384、32767），结果都在内缩矩形内（推导第 6 项）。
  - 四个象限与 −0 的姿态；成员位置的向零舍入边界与固定偏移相关，成员超出内缩矩形也不移动。
- **换算：**
  - q 的舍入：s = 11000 时向零比就近小一个 ulp，由 BigInt 核对；s = 7000 两者相同。
  - 位置：(1 + 2^−23) × 1.875 向零得 1.875 + 2^−23（就近为 + 2^−22）；`object` 与别名来源换算一次，模板、成员与僚机来源不换算。
  - 矩形：trunc 向零（−1.875 → −1；q = 0.5 时 −0.5 → 整数 0）。
  - 各类拒绝的路径与原因，诊断不含输入值。
- 不使用卡方检验或按种子挑选结果；分布由映射与原像计数核对。

**Simplify：** 采纳：`WorldFrame` 只保留扇区数（世界矩形与缺省范围都由它推出），`worldCoordinate` 改为接收世界宽度，消除 `original-random` 对 `coordinates` 的反向依赖；边带常量改为模块私有；test-support 内部函数不导出；大规模穷举改为整批比较或汇总不符项，`src/core/rules` 测试由约 1.9 s 降到约 0.6 s。未采纳：复用 content 层 test-support 的 `floatBits`，因为它跨层，且同样使用 typed array，参考实现有意用 DataView 与 BigInt，与被测代码的机制不同。
