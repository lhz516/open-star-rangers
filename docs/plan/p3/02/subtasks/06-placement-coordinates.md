# 06 — 放置服务、坐标换算与原版随机映射

**契约来源：** [spec](../spec.md) 的 S-02（数值与随机数）、S-06（放置部分）；AC-06；[数值表示](../spec.md#数值表示)、[随机数](../spec.md#随机数)、[任务实例化](../spec.md#任务实例化)的放置行、[对照方法与判据](../spec.md#对照方法与判据)的 R-02 放置行、技术决定 3、11。
**依赖：** 02, 04。
**执行方式：** 自动。
**执行状态：** 仅由 [goal tracker](../goal.md#子任务跟踪) 维护。

## 工作范围

- **坐标换算（按 02 的 Q-03、Q-11）：** 参考单位乘以“运行时比例 ÷ `referenceScale`”；带 `object` 来源的记录只换算一次，仅从段 5 可达的记录与 SCCT 僚机记录按 Q-03 的结论处理；生成矩形按 i32 规则换算；编组布局偏移不再换算或交换轴；取整与存储精度在 Q-03/Q-11 确认的边界上独立实现。f32 写回一律向零舍入，双精度中间运算按 JS 就近舍入（见 [goal 执行记录](../goal.md#执行记录)的 Q-11 舍入方向决定）。
- **世界矩形：** 由已核验的 `mapFrame` 与比例推出；只接受本切片的地图轴与中心（其他取值由 07 在创建时拒绝），不把任意旋转的地图框架当作世界坐标。
- **原版随机映射（按 02 的 Q-02）：** 从世界 RNG 的 uint32 输出构造与原版 `rand()` 取值域等价的有限整数域，再按原版的取模或缩放得到结果；每轴抽取的次数与次序符合原版。不复现原版序列，不改 [rng.ts](../../../../../src/core/determinism/rng.ts) 的契约。
- **放置例程：** 锚点偏移（锚定对象不存在时改用全世界缺省）、矩形内均匀、全世界缺省、存储位置；按 `0x68398` 的优先级选择（零向量判定忽略符号）；放置结果与世界矩形比较后的处理按 Q-02。网格与固定高度路径不实现。放置服务对外提供给 07 的实例化与 P3-11 的救援放置。
- **测试（期望不得由被测实现计算）：**
  - 每个随机映射：按 02 的独立推导，覆盖有限域到输出的映射、支持集端点的包含性、各结果的原像计数、轴之间与成员之间的关联；可枚举的域穷举，否则覆盖每个分段或取模边界。
  - 舍入：在 Q-03/Q-11 确认的转换边界上测试。
  - 选择优先级、锚点缺失回退、存储位置与世界矩形边界。
  - 不使用卡方检验或按种子挑选结果。
