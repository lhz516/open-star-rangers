# P3-15：原版对照汇总

本表落实 [spec](./spec.md) 的 S-07 与 AC-08（[08](./subtasks/08-comparison-summary.md)）。它按 [P3-01 的规则对照目录](../01/spec.md#规则对照目录)与[表现对照目录](../01/spec.md#表现对照目录)逐项汇总 P3-02 至 P3-14 记录的对照结论，判定方式见 [P3-01 的对照方式与判定](../01/spec.md#对照方式与判定)。本表只汇总并链接，不新增测量，不改变容差，也不改写任何结论。P3 是否退出由 P3-16 判定。

## 读法

- **照录原结论。** “原结论”一栏照录责任任务的判定用语。引号内为原文；没有引号的是对原文计数与分类的摘要，用语不变。“一致”只在该任务写定的判据与覆盖范围内成立。未确认、缺证、阻塞（blocked）、无法判定、未运行对照、限定结论、外观证据缺口与经批准差异都保持原分类，不记为一致。
- **两类结论分开。** “原版事实置信度”记录原版事实的研究结论（已确认 / 高概率 / 未确认）及其来源；“原结论”记录新版实现的对照结论。两者不能互相替代（[P3-01](../01/spec.md#对照方式与判定)）。
- **基准与适用条件。** 各行写明原版版本与配置、所用运行和新版候选。下文的“基准 A”指：manifest `manifest-b9bfecb3bf772fbf`，EXE SHA-256 `c1e0f456…`（全值见 [B-007](../../../original/behavior/B-007-mission-instantiation.md#原版版本与配置)），DOSBox-X 私有副本，`fixed 40000` cycles，新战役第一关 SCEN 3019（组 0 / 槽 1），原始难度 19。各任务的僚机选择值、媒体设置与运行名在各行写明。
- **U-021。** 基准 cycles 仍未冻结（[unknowns](../../../original/unknowns.md) 的 U-021 为“进行中”）。凡运行时得到的结论都只适用于 `fixed 40000`。冻结值不同时，须按责任 spec 的 U-021 条款在冻结配置下重新满足样本；冻结为 40000 时无须重测。P3-11 的原版样本同样在 `fixed 40000` 下取得，见 [R-20 至 R-22](#r-20-至-r-22p3-11)。
- **不在本表的内容。** P3-15 的 01、04、07 尚未完成，本表不预先写入它们的闭环级结果，由 11 核对是否需要补引用。P3-03 只负责数据导入，不拥有 R/V 项。
