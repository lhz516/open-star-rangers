# 06 — 本机实机物理残余项

**契约来源：** [spec](../spec.md) 的 S-04；AC-05 中 Computer Use 无法覆盖的部分（[P3-05 AC-18](../../05/spec.md#验收标准) 的物理 Fn、持续按住与系统路径）。
**依赖：** 05。
**执行方式：** 需用户：在本机 macOS Chrome 用物理键盘/指针执行 05 列出的残余项（物理 Fn 途径、持续按住与释放、系统级组合），agent 无法产生这些物理输入。
**执行状态：** 仅由 [goal tracker](../goal.md#子任务跟踪) 维护。

- 协调者按 05 的残余清单准备最小操作步骤（合成任务包、指定基线、每步预期观察），用户逐项操作；协调者同时读取 UI、开发日志、全屏/锁定状态并记录。
- 每项记录输入路径（物理键）、原生结果、应用动作与能力状态；无法有效执行的项写明原因，AC-05 对应部分保持未完成，不转为合成通过。

## 完成证据

**2026-10-30，用户物理操作、协调者观察。** 被测代码为 main `0458ada4`（会话开始时 HEAD `ea6f630e` 只多文档）；macOS，Chrome 156.0.8078.74，隔离临时配置文件，开发服务器 `127.0.0.1:5115`，与 05 相同的合成任务（经正式导入页导入）。所有被测输入由用户在物理键盘与鼠标上产生；协调者只经 CDP `Runtime.evaluate`（`userGesture: false`）读取按键/鼠标/全屏/锁定/可见性监听、开发事件日志与 `data-tick`，并经开发面板导出录制以读出逐 tick 的轴与开火电平。私有原始记录在 `local/research/p3-15/real-device-physical/`（`steps.log`、`session-2026-10-30.md`、`exports/`）。用户在各步之间切换到其他应用作答，每次切走都使运行因页面隐藏而暂停，需按 `p` 继续；第 2 步中还有若干额外按键。下表只计入能按时间归因的窗口。
