### 路线与工具使用的发现

- **页面 0xF 选无僚机（已确认，运行时与代码）：** w-01 在简报的第一个读键点读取章节表；按 `0x367e4`（以章节首元素判别僚机章节）与前翻函数 `0x372bc`（跳过表项字 0 非零的章节）推得需要三次 Enter。e-01、e-03 表明：页面循环在按钮按下后倒数若干轮才调用回调（`0x34435`），期间读到的键被读出丢弃（`0x3728c`），相邻读键点上的键因此丢失。e-04 在每次 Enter 之后先停在读键成功点 `0x371ca`、再停在回调调用点，`d` 之后等待 15 轮，选择值成功变为 0（守卫与每个暂停点的身份核对）。正式运行用同一路线。
- **B 的进入：** 截在 Warp 结束的视角切换处时玩家继续飞离，基地在第 13 次调用时以模式 2 移除（b-01）。P3-07/41 的地图点击只适用于一种启动布局（b-02 至 b-04 都处于另一种）；只读侦察 ms-01 读出另一布局下基地 500 的位置（地图变换相同）。Warp 停在离目标点数千单位处，油门归零后玩家静止在活动半径内（b-06），但不会靠近基地；自动驾驶段把玩家带到基地附近（b-08），但敌机在到达后数分钟才来，读数窗口开始得太早；只读侦察 wyc-02 得出另一布局的目标循环；b-09 在两种布局下都走自动驾驶段，并先在开火点等待第一发。

### 各类观测量与误差预算草案（交 11）

共同事实：

- **时钟与参考钟：** 停止处调试器读到的模拟器时间与游戏样本之比在三次完整运行中为 15.62–15.68 毫秒/单位（1/64 秒 = 15.625），即 fixed 40000 下游戏时钟跟随模拟器时间；帧长随场景在约 15.7 毫秒到 230 毫秒以上之间（e-04 空场景约 1.0 单位/帧，w-01 2.06–2.13，w2-01 交战 2.43–2.53，b-09 基地附近交战约 14.9）。停止帧步长在僚机与敌机运行中为 0、2、4，在基地附近为 2–18。结果只适用于 cycles 40000（U-021）。
- **暂停的影响（未确认）：** 逐更新停止、逐帧停止与每秒一次的稀疏停止分布在运行的不同时段、不同场景，没有状态相同的对照窗口，暂停对帧长的影响在本预实验中与场景混在一起、未能估计。因此不从停止序列推断步长分布或速率；时间链按下述逐链接规则核对，每个链接使用它自己那一帧记录的步长，步长分布本身只在所用暂停安排的条件下成立。
- **运行间离散：** 同一配方在不同启动状态下给出不同的过程（w-01 与 w2-01 的共同前 20 次更新不同）；控制器超出量的分布相近（超出 2 单位以上的链接 12/130 与 11/130）。独立样本应来自不同启动状态或输入时机，P3-07 的“启动状态与刺激相同则逐值重复”仍适用。

记号：s 为处理调用所在帧的样本，D 为该调用前的期限，st 为该帧步长，o = s − D。严格比较（s > D）的第一个合格检查为 s − st ≤ D < s；非严格（s ≥ D）为 s − st < D ≤ s。固定 2 单位步长下 o_fixed = 2（D 与样本同奇偶）或 1（异奇偶）。每链接的漂移 δ = o − o_fixed，0 ≤ δ ≤ st − 2；累计漂移是 δ 之和，不是 o 之和。
