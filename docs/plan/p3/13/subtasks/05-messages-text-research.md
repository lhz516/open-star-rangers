**绘制、首次显示、滚动与移除（已确认，代码）。**

- **记录：** 文字副本、颜色、模式、长度、宽度、首次显示样本（0 = 未显示）、到期。类型 8 只登记全局回调与绘制回调；全部 CCKD 的类型 8 记录 +0x18 均为 0，所以在视角 1、6、8、0xC–0x12 且有玩家时每次渲染都绘制，没有节流。
- **过期 `0x4e964`：** 只看队首：未显示且样本 > 到期（u32 严格）时移除并置清除标志，每帧至多一项；它在绘制之前。等候中的项不过期，成为队首后才可能过期；绘制例程不检查到期，所以过期删掉一个陈旧队首后，同帧绘制会立即开始下一项，哪怕它也已陈旧（积压的陈旧项大约隔一项显示一项）。
- **绘制 `0x4e6c0`（参数：视角模式、目录 +0x0C 常重绘标志、矩形）：**
  1. 清除标志为真且视角 ≠ 8：以颜色 0 填满整个矩形（含端点），非常重绘时送屏；标志清零。
  2. 无队首则返回。首次绘制把队首的开始样本记为本次样本，这就是“首次逻辑显示”。
  3. 字体：显示模式 2（LO）用 fonts/2，否则 fonts/0。行 y = trunc((y0 + y1 − h) / 2)，W = x1 − x0 − 1。
  4. 偏移：模式 0 为 0；模式 1 为 W − ((dt × 48 mod 2³²) >> 6)；其他模式为 × 120；dt = 样本 − 开始（u32）。每 tick 2 单位时，模式 1 交替移动 1、2 像素，模式 2 每 tick 约 3.75 像素。
  5. 宽度 + 偏移 ≤ 0（有符号），或模式 0 且开始 + 0x80 ≤ 样本：释放并移除、置清除标志，**本次不画**；因此由绘制移除后，下一项最早在下一个 tick 首次显示；由丢队首或过期移除时，下一项可在同一 tick 显示。
  6. 只画整字：首字 = 偏移 ≥ 0 时 0，否则 ⌈−偏移 / 步进⌉；第 i 字在 x0 + 偏移 + i × 步进；末字界 = min(长度, trunc((W − 偏移 − 1) / 步进))；所以左侧没有半字，最右像素 ≤ x1 − 3。
  7. 视角 ≠ 8：先以颜色 0 填 (x0, y)–(x1 − 1, y + h)，画字，非常重绘时只送这条带。视角 8：填 (x0, y0)–(x1 − 1, y1 − 1)，画字后以颜色 8 画外框（宽 x1 − x0 − 1、高 y1 − y0 − 1），即 Q-09 中未追踪的 ps +0x28 = 8 分支；该视角每帧整屏重画，所以不做第 1 步的填充。

**字体（Q-12；已确认，代码）。** `0x5acac` 把头部字节 0–1 存为记录 +0 的字，+4 步进 = 单元宽，+8 高度，+0xC 大写标志，+0x10 字形；`0x49694` 把 fonts/1 的步进设为 6 并置大写标志（fonts/2 另设高度 6）。`0x59fc8` 每字：有标志时只把 0x61–0x7A 减 0x20（`0x75572`），然后直接取字形 = 数据 + 码 × 8（高度 > 8 时 16），画前 h 行、8 列，置位处写颜色，坐标按 16 位截取，不裁剪，前进一个步进。没有字符映射：原版对任何字节都画同号字形（两张 8×8 表 256 个字形中 160/159 个未映射的非空）。记录 +0 不被绘制例程读取，字体记录的其余读者只读 +4/+8：头部 +1 字节**不影响绘制**（绘制例程已确认；没有其他读者为高概率）。HI 中消息行用 fonts/0（不大写），通讯面板与 DIAG 用 fonts/1。项目处理：fonts/1 先大写再 `glyphFor`；映射外的码是内容契约错误（`unmapped-character`），不替换；切片可达文字已全部在映射内，项目文字须在装配时按同一映射校验。

**格式化（Q-12；已确认，代码）。** `0x74a3f` 调用 Watcom 风格的 `__prtf`：普通字节原样输出，`%%` 输出一个 `%`，`%s` 原样复制字节，`%d` 经 `0x74b67`（十进制，负数前置 `-`）。`%.0f` 经启动时安装的 `0x9ce64` → `0xa4d57` → `0x13e776`：取绝对值并记符号，按二进制指数估计十进制位数，位数 = 精度 + 估计值（上限 16，进位时二次计算），只有两者不同时才按 10 的幂缩放（`%.0f` 在切片范围内不缩放），再由 `0xa4a50` 以**就近舍入、平分取偶**把 f64 化为整数。所以 `%.0f` 输出符号与 round-half-even(|x|)（0.5 → 0、1.5 → 2、2.5 → 2）；负值在数字舍成 0 时仍输出 `-`（按指令推演，未执行，高概率）。切片中 `%.0f` 的实参（距离、百分比）都非负；切片格式串除精度 0 外没有宽度或精度（基地内部的 `%15s` 不在切片）。
