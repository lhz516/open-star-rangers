**图元与裁剪（已确认，代码）。** 直线：Bresenham，两端点含，2|dx| > 2|dy| 才走 x 主轴（相等走 y 主轴），初始误差 2|次| − |主|，误差 ≥ 0 时步进次轴，不裁剪。填充圆盘与圆环：中点算法（d = 1 − r，增量 3 与 5 − 2r）；圆盘逐行画四组跨度后补中心行，圆环八向描点后补四个轴点，均不裁剪；圆盘的裁剪版按**含端点**的盒子 [主图 x, 主图 x + s] × [主图 y, 主图 y + s] 截跨度（比主地图末像素多一列/行，随后被外框线覆盖），完全落在其内时用不裁剪版；敌方圆环不裁剪。记录绘制只在右/下按区域尺寸收缩，左/上不裁剪，左上角对齐像素，颜色键 0；方框在图标之后画，(w′+1)×(h′+1)，覆盖图标的首行首列。外框线画在 x、x + w、y、y + h（右/下比半开矩形多一像素）。按随附数据（s 为偶数、框架元素位置），主地图与放大窗口的下边线落在类型 10 记录矩形下一行，该行不被框架元素覆盖，截图外框对照证实可见（已确认，代码、本地数据与截图）。指针框：宽 = chop(放大范围 x × 每单位像素 x)，高同理，半宽/半高向零截断，以光标像素为中心；各边只在未越出 [主图起点, 主图起点 + s] 时画，端点钳到同一含端点范围；它在外框之后画，可以覆盖外框线。文字（`0x59f90`）不裁剪：信息行越右侧的部分被信息外框右线与遍 1 框架元素盖住；靠右的标签文字可画进信息/放大窗口并保持可见。连线：玩家在界时直连光标；玩家不在界时先按 x 再按 y 以 f32 斜率把玩家端裁到含端点的主地图盒（斜率及其倒数无条件计算，玩家与光标同列或同行时触发未屏蔽的 x87 除零，后果未确认；玩家可飞出世界矩形，可达）。

**标签与威胁闪烁（已确认，代码）。** 每个在界、种类在 `0x6887f` 内的图标项：图标行在主地图下半时文字在图标上方（y − 字高 − 6），否则在下方（y + 6），文字 x 等于图标像素 x；两条 0x10 引线：(x−4, ym)–(x−步进, ym) 与 (x, 图标 y)–(x−步进, ym)，ym = 文字 y + 字高/2。颜色：对象 +0x17C ≠ 0 时按**当帧时钟样本第 5 位**在 0xA/0xF 间闪（周期 64 单位，相位取绝对时钟），否则种类 1/2 为 0xF，其他 0x10。只读 +0x17C 是否非 0。

**代价文字（已确认，代码）。** 光标：p = chop((c ÷ E) × 100.0)，显示 max(p, 1)；位置为确认光标 + (2, 2)，若局部 x > s − 6 × 步进则改到左侧（− 6 × 步进 − 2），若局部 y > s − 字高则改到上方（− 字高 − 2）；颜色 ≥ 100 为 0xA、67–99 为 0xF、其余 0x8。目的地：目的地像素 + (3, 3)，不翻转，其余档为 0xD。两者都只在玩家有图标项时画。信息小窗行颜色：单位两行与 0x4000 计数行 0x13，其他计数行 0xA；行位置 (x + 4, y + 4 + 字高 × k)，计数行可越过容量画进放大窗口区域，再被标题、放大图标与外框覆盖（本地数据：越界行仍在类型 10 矩形内）。列表种类（`0x6c87f` 去掉 0x4000）的护盾/船体/能量容量在全部 21 个 CINF 中均为正（693 个，0 个为零），信息行的无保护除法在随附数据下不会除零（已确认，本地数据）。

**放大窗口错开 `0x4b56c`（已确认，代码；更正 P3-09/04 的“同主地图做法”）。** 以各图标记录的宽高定步长 (W + 2, H + 2) 与以放大像素为中心、半宽/半高截断的盒子（接触即重叠）；第 0 项不动，第 i 项与任一 j 重叠时按自身计数从当前位置移动，累计偏移依次为 (+sx,+sy)、(−sx,+sy)、(−sx,−sy)、(+sx,−sy)、(+sx,0)、(0,+sy)、(−sx,0)、(0,−sy)、回原位并结束该项；移出 [0, 放大宽] × [0, 放大高] 时立即试下一步，计数用尽则恢复原位；每次移动后从 j = 0 重扫；每项超过 10000 次比较即停。projection 给未错开像素，此算法属 P3-13 绘制（MW-11）。

**右键双调用（Q-11；已确认，代码；节奏为按 2 单位/pass 的运算级推演）。** `0x2b9bc` 一次调用内**先测试后递减**：右键位为 1、计数 ≤ 0（有符号）且点在主地图 → 开关取反、计数 := 20；然后每次调用只要计数 > 0 就减 1，所以翻转的那次调用留下 19。同一 pass 中读取调用（派发器消息循环处理 0x1000）**先于**绘制调用（帧渲染 `0x49f8c` 的按钮 0 调用），两次都递减。读取门：`0x1747dc` 置位且样本 > 到期（无符号），到期 := 样本 + 6；开图的 `m` 在按键时把到期设为当时样本，所以开图 pass 没有读取，首读在下一 pass，此后每 4 pass 一次（2 单位/pass）。推演（`out/right-cadence.txt`）：
- 从计数 0 一直按住：第 1、17、33… pass 翻转，即每 16 pass（32 单位）一次，不是 20 tick；朴素 20 tick 近似给出 1、21、41…。
- 计数 1→0：读取调用进入时计数为 1 不翻转、减到 0，同 pass 的绘制调用按钮为 0 不翻转，下一次读取才可翻转。开图时带入计数 c 并按住，首次翻转在开图后第 1 + 4⌈(c − 1)/5⌉ pass（即第 ⌈(c − 1)/5⌉ + 1 次读取；c ≤ 1 时为首读）；若把绘制排在读取之前，c ≡ 2 (mod 5) 时会早 4 pass，可区分。
- 短按：只要在某次读取时为按下且该读取进入时计数 ≤ 0 就翻转一次；整个按下落在两次读取之间则不被读到；相邻两次读取都读到按下也只翻转一次（第二次进入时计数为 15）。
- 开图保留计数：开图只清开关（`0x49e3c`），不清计数；计数只在任务建立 `0x2b814` 清 0（含重试，已确认）；救援只重新初始化玩家、不重建任务，计数保留（高概率，依现有救援记录，未逐一追踪 `0x67b98` 的调用）；地图关闭期间没有调用、计数不变。
- 关图 pass：`m`/Esc 的关图消息先于同 pass 的读取被处理，读取仍在关图后执行，可翻转（不可见，下次开图清掉）并把计数置 20 → 19 带到下次开图。
- 输入失效与恢复：原版每次读取取当前按钮电平（函数 03h），没有失焦概念。项目按已批准 spec 在暂停、隐藏、失焦、解锁、离开无锁回退区与离图时清按住电平；电平清掉后读取视为未按，绘制调用照常递减，计数在暂停（无 tick）时不变；恢复资格后只有新的按下在之后的读取中翻转，不补读、不复用旧按下。
