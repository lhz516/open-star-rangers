# 06 — 地图画面与右键节奏研究

**契约来源：** [spec](../spec.md#战略地图画面) 的 S-10/S-11/S-13，Q-11，AC-16/17/21。
**依赖：** 无。
**执行方式：** 自动。
**执行状态：** 仅由 [goal tracker](../goal.md#子任务跟踪) 维护。

## 工作范围

- 核对图元/网格/标题、圆盘与圆环、标记和错开、信息行越界、标签威胁闪烁、指针与代价文字的完整次序。
- 精确核对右键采样调用与按钮 0 绘制调用的递减/测试先后，计数 1→0、按住、短按和开图保留计数；避免 20 tick 近似。
- 几何含端点到连续范围、输入容器偏移、局部光标与 Core 确认读数边界逐项列明。
- 零能量沿 MW-12 的 null 分支给项目提示，不复现 x87 异常值。

## 不包含

不改地图可见性/代价/选点规则，不新增点击装饰按钮或 Core 右键命令。
