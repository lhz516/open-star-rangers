# 09 — 原版预实验

**契约来源：** [spec](../spec.md) 的 S-11、AC-17；[对照方法与判据](../spec.md#对照方法与判据)；[实施关卡](../spec.md#实施关卡) D-02 的定稿依据。
**依赖：** 02, 04, 05。
**执行方式：** 自动。原版证据由执行的 agent 按[原版证据获取](../../../../guides/original-evidence.md)自行取得。飞行、地图选点与停靠先尝试以模拟器内的按键、修饰位与设备输入配方完成；只有当前合规途径无法满足某个具体操作时，记录已尝试的途径与准确障碍，再请用户做最小操作。
**执行状态：** 仅由 [goal tracker](../goal.md#子任务跟踪) 维护。

## 工作范围

- 只用原版数据做预实验，为 D-02 形成每类行为的误差预算：所选任务中接近基地、打开菜单、停靠请求到入港、基地内服务、离港的帧步长分布、输入取样边界、读数分辨率与运行间离散；记录媒体设置（入港/离港过场与通讯媒体）及其隔离方式。
- 规划导航：依本次运行的对象位置规划路线，注入基地键前确认视角 6、子状态 5 与玩家活动 3；不沿用其他运行的坐标，不重用 P3-05/34 已耗尽的尝试授权。本项自己的测量方案写明尝试预算与恢复条件。
- 记录各采样项的可达性：哪些分支在预算内触发，哪些没有；“没有触发”不写成“不可达”。
- 能力不足时按 [tools/baseline/](../../../../../tools/baseline/) 的既有契约增量扩展，并补合成测试；同步[运行时测量](../../../../guides/runtime-measurement.md)。
- 预实验运行不计入 AC-17 的合格运行。
