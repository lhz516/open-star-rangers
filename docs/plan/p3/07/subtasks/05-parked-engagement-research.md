- **`0x30150` 的全部规则（已确认，代码）：**
  - 不交战抽取：按自身种类的类别抽一次 rand % 100，种类 2 小于 80、`0x87c` 与 `0x81400` 类小于 90、`0x78000` 类小于 95 时不交战；种类 1、0x80、0x100、0x200、0x2000、0x4000 不抽取、总是交战（切片的两种敌机属于后者）。
  - 目标：有编队长（+0x7C）时读编队长的 +0xC4 与目标引用，否则读自身；+0xC4 为 0 或 ≥ 6 取 +0x90，1–4 取 +0x8C，5 不交战。门禁依次为引用有效、目标 +0xD0 > 0、目标 +0xCC = 0（不在 Warp）、按种类掩码的阵营门禁；不检查目标的活动、状态与种类，因此活动对象（含玩家）也可成为目标；目标的被毁标志只在施加伤害前检查。
  - 距离：目标与自身位置的 L1 距离减去目标的形状半径，乘 3.0 再乘 0.25，存为 f32；距离始终是浮点，与射程按 f32 严格比较，不做整数转换。
  - 导弹选择：自身 +0xE0（SCEN 记录 +0x74 的副本）≥ 0 时，在类型为导弹、弹药非零、射程大于距离的挂点中抽 rand % 个数选一个；否则不选。
  - 伤害求和：按挂点顺序遍历全部挂点状态，不看列表、开火类型、损伤等级、炮的弹药、射界、冷却或充能。射程内的炮按 floor(elapsed × 炮 +0x14 ÷ 64) 计次数，再除以除数（有符号整除），不足 1 计 1，每次加炮 +0x1C；选中的导弹加导弹 +0x5C，目标种类恰为 2 时须再抽 rand % 100 < 20 才加，弹药总是减 1。
