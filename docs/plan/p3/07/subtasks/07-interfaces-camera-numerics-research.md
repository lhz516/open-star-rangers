- **每 tick 的事件与请求上界（供 P3-06 检查点 A 的共享容量预算；按代码路径推出的上界估计，不是实测）：** 记号（都是本 tick 开始时或本 tick 内的计数）：K 为命令数；Ca 为活动（+2 = 1）且状态 ≥ 7 的机体数，Ct 为全部机体数（含停放与停靠）；A 为 Ca 中种类 2、0x80、0x100、0x200 的机体数；M 为 Ca 的全部挂点数（含不在列表中的自动挂点，CINF 中每机最多 18）；L 为最长的“同时开火”链（全部 CINF 中为 4）；P、Ms、F、X 为现存的弹丸、导弹、判别值 3 碎片与爆炸数；N 为全部对象数；Dc 为本 tick 被毁的机体数（≤ Ct）；Dm 为本 tick 起爆的导弹数（≤ Ms）；Fe 为本 tick 到期或被击落而爆炸的碎片数（≤ F）；Ea 为本 tick 触发 AI 区域伤害 `0x6313c` 的对象数（≤ Ca，P3-08）；Fh 为本 tick 进行来源交接的第 0 部件碎片数（≤ F，可来自更早被毁的机体）；Xe 为本 tick 有事件 `0x10` 到期的爆炸数（≤ X，每个至多 3 个事件）；Pk 为本 tick 交战的停放对象数，nᵢ 为多目标停放对象 i 的候选数（≤ Ct）；q 为一个被毁机体的第 1 列表部件数（数据中 ≤ 8）。
