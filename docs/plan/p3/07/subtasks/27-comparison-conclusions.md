# 27 — 对照结论

**契约来源：** [spec](../spec.md) 的 S-11、AC-16（对照部分）；[对照方法与判据](../spec.md#对照方法与判据)（R-10 一行按 [spec 审批](../spec.md#审批)的修订）、技术决定 11；10 获批的 D-02 判据；P3-02 spec 的 [CR-11](../../02/spec.md#cr-11-表现层的归属与已批准的差异d-01)（归表现层的部分与已批准的差异）。
**依赖：** 24, 26, 37。
**执行方式：** 自动。
**执行状态：** 仅由 [goal tracker](../goal.md#子任务跟踪) 维护。

## 工作范围

- **工具来自 [37](./37-comparison-tooling.md)：** 37 已建好单次转移工具、独立的 Φ 脚本与新版连续运行。本项在 26 的全部合格样本上运行这些工具并给出结论；工具需要修正时记录修正与原因，不改判据。
- **单次转移核对：** 对 26 的每个合格前后态，用私有诊断调用 Core 的内部规则函数，独立核对 R-06 至 R-10 的分支、算术与次序。
  - 不新增生产快照恢复或任意步长 API，不把原版随机输出导入 Core。
  - 随机转移按代码推导的支持集与条件概率核对；原版样本符合只作交叉核对。
- **连续行为核对：** 用真实内容（做法同 25），以默认 2 单位/tick 的正式 `World.step` 从初始内容连续运行，不逐步用原版状态校正。对射击节奏、射程与寿命、导弹锁定与追踪、伤害与耗尽时间、充能、判别值 3 碎片与爆炸的时间链，按 D-02 判据比较；同时核对阶段次序、命中与失效、死亡与移除等离散结果。
- **R-10 的范围：** 只判定 Core 的部分（被毁分支、爆炸的生命周期、判别值 3 碎片）。EXPL 选择、额外爆炸、判别值 1、2 碎片与闪光归表现层（CR-11），其原版观察留在 B 文档交 P3-12、P3-14，本项不作判定；CR-11 列出的已批准差异按差异记录，不判为不一致。
- **判定：**
  - 只有全部样本都满足判据才判为“一致”；任一样本不满足即为“不一致”，记录差异，由协调者新增修复或研究子任务。不放宽判据。
  - 未测分支与 U-021 的前提逐项列出，不被静态检查或种子测试豁免。
  - 无制导导弹的引信间隔以 H5 记录的读数为准（冲突 29）；读数缺失时相应样本记为阻塞，不择一取值。
- **身份：** 结论绑定原版配置（cycles、设置、基准哈希）与新版候选（提交与 `src/` 的树）及内容身份。
