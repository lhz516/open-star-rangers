**执行状态：** 仅由 [goal tracker](../goal.md#子任务跟踪) 维护。

## 工作范围

- **爆炸：** `0x23ac8` 的状态写入（被毁对象进入状态 4）、大小类别、玩家的延迟计时；`0x23fdc` 的额外爆炸；`0x32dec`（非玩家被毁的分支）；`0x23808` 在消息循环与运动之后直接创建爆炸时，新对象的首次更新、首次运动与移除时刻。
- **EXPL：** `0x23520` 在任务构建时选出的子集及其与其他构建期抽取的相对次序；`0x2409c` 的每次选择（列表类别、按相机距离选列表的分支、抽取）；所选 ANIM 的帧数与爆炸对象、被毁对象移除时刻的关系；**判定该选择是否影响规则生命周期**（决定 Core 拥有还是表现层拥有，D-01）。
- **碎片：**
  - `0x24d78`、`0x24ec4`、`0x25124` 的三种模式与判别值；`0x25124` 使用的源模型第 1 列表部件数与部件标志、种类 1/2 的部件跳过、`0x249dc` 的 DEBRIS 记录映射与空引用（例如玩家部件 0）；
  - 碎片的初始运动、旋转、耐久（+0xD0 与 DEBRIS +0x5C）、到期（`0x24ac4`，逃生舱 0x140、僚机部件 0 的 0x780 等）与 `0x256e4` 的到期处理；`0x24a6c` 的作用；
  - 事件 `0x10`（`0x23838`）的模式 1/2 碎片：除绘制外是否参与碰撞、受击、遍历次序或预算；屏幕内门禁 `0x2443c` 的输入（相机位置的来源交 07）。
- **Q-12（本项部分）：** 上述路径的数值、开方与随机映射。
- 事实写入 `local/research/p3-07/destruction/findings.md`：英文，按目标文档与节（executable、craft、textures、mesh）写成可直接并入的草稿，带置信度与证据，只记地址、结构与行为，不含原版内容或反编译输出；受影响 U 项的状态变化一并列出。由 07 统一写入 `docs/original/`；本项不改跟踪的原版文档，使 01 至 06 可以并行。
- 完成证据给出交 08 的摘要：爆炸与碎片实体的状态与表现选择器字段、EXPL 归属的结论、直接创建的时序例外、模型部件元数据的输入需求、判别值 1/2 归 Core 还是表现层的建议。
