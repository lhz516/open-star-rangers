# 25 — 真实内容本地核对

**契约来源：** [spec](../spec.md) 的 S-02、S-04、S-05、S-10（真实内容部分）、AC-14；[对照方法与判据](../spec.md#对照方法与判据)的独立性要求；P3-02 spec 的 [CR-01](../../02/spec.md#cr-01-世界创建输入与静态规则数据d-01)（规则输入）。
**依赖：** 24。
**执行方式：** 自动。
**执行状态：** 仅由 [goal tracker](../goal.md#子任务跟踪) 维护。

## 工作范围

- **脚本：** 在被忽略的 `local/research/p3-07/real-content/` 写本地核对脚本，按 [P3-02 的真实内容核对](../../02/subtasks/09-real-content-check.md)的做法：
  - 用生产导入作业转换本地 CloneCD 文件组，经 `validatePackage` 取得资源包与 `ContentIdentity`；
  - 解码三份逻辑 Asset 与七项规则输入（P3-06 的 `craftInfo` 与 CR-01 的六项，含 34 加入的 `aiPrograms`），用正式 `createWorld` 建世界；
  - `local` 是指向主仓库的符号链接，因此脚本从当前工作目录动态载入被测代码。
- **运行：** 用已记录的种子与有界的脚本命令（选目标、开火、发射导弹，以及 P3-06 已集成的运动命令）连续运行正式 World。不回写位置或血量，不代入原版逐步前态。带与不带僚机各至少一次。
- **核对：**
  - 玩家主炮与导弹产生真实的运动与命中；至少摧毁一架敌机；爆炸与判别值 3 碎片正常产生和到期（额外爆炸与判别值 1、2 碎片归表现层，Core 的运行中没有这些对象）；
  - 武器引用与独立读出的可用挂点一致：用内容读取器读机型记录，不用 Core 的挂点 helper；
  - 不出现预算故障、NaN 或拒绝。
- **输出：** 只含计数、判定、时刻与身份：内容身份、候选提交与 `src/` 的树，以及种子与动作记录。不含名称、坐标或 payload；输出与脚本都留在 `local/`。
- **不一致或不可达时：** 记录差异，判断是实现缺陷、研究缺口还是 P3-06 接口的问题，由协调者新增修复子任务。脚本命令无法让玩家接近敌机时，记为 blocked 并写明原因，不传送对象。
