# 09 — 原版预实验（D-02 证据）

**契约来源：** [spec](../spec.md) 的 S-11、AC-16；[实施关卡](../spec.md#实施关卡) D-02；[对照方法与判据](../spec.md#对照方法与判据)。
**依赖：** 02, 03, 04, 06。
**执行方式：** 需用户：在 DOSBox-X 的私有副本中只用键盘按操作手册进入所选任务，射击、发射导弹、以不同速度飞行、被击中并摧毁敌机（每次约 10–20 分钟）。原因：P3-01、P3-02 实测本机 Computer Use 无法向 DOSBox-X 送达按键或移动游戏内光标；agent 负责方案、配方、启动、读数、应答、分析与记录。执行时若该限制已解除，协调者改为自动。
**执行状态：** 仅由 [goal tracker](../goal.md#子任务跟踪) 维护。

## 工作范围

- 只用原版数据建立连续行为的误差预算：对射击节奏、弹丸射程与寿命、导弹锁定与追踪、伤害与能量（护盾与充能恢复、速度消耗）、毁伤时间链各类别，测量帧步长分布、输入取样边界、读数分辨率与运行间离散。
- 依 02、03、04、06 确认的函数与字段编写配方（断点与类型化读数），按[运行时测量指南](../../../../guides/runtime-measurement.md)核对身份、断点、重复读数、文件保护与进程回收，记录 cycles 与游戏设置。
- 工具能力不足时按其既有契约增量扩展 `tools/baseline/`，补合成测试并同步指南。
- 预实验不接触新版的连续行为对照；预实验运行不计入 AC-16 的合格运行。
- 读数与报告只存放在 `local/research/p3-07/pilot/`；完成证据只写统计量、误差来源与每类的误差预算建议（交 10）。若发现会影响算法选择的事实，在完成证据中写明并报告协调者。

## 不包含

- 判据的定稿与批准（10）；正式验收采样（26）；新版的对照（27）。
- 不注入游戏输入：工具与指南都不允许用 shell 或其他自动化向 DOSBox-X 发送按键。
