# 25 — 真实内容候选核对与试听准备

**契约来源：** [spec](../spec.md#对照方法与判据) 的 S-05、S-07、S-10、AC-06、AC-09、AC-15。
**依赖：** 22, 24。
**执行方式：** 自动。
**执行状态：** 仅由 [goal tracker](../goal.md#子任务跟踪) 维护。

## 工作范围

- 以当前候选、本地合法导入的完整包和记录的内容身份，在隔离私有环境核对实际 Asset 绑定、输出参数与适用旧样本等价。
- 由 agent 通过正常游戏流程准备生产可达的声音/模式场景；保留结构化触发身份、参数和参考关系，不用改世界的调试注入冒充可达。
- 对每一关系分别给出离散/可量化结论与“待人耳”的判断项，为 26 提供已定位的原版参考和当前候选片段/操作。
- 候选变化会影响样本或输出链时重新确认适用性；不得把 P2 等价结论自动继承到新混音。

## 不包含

- 不进行人耳判定，不修改应用来迁就参考；实现差异交回责任项/新增修复任务。
- 不将原版内容导入公共 E2E、提交或上传服务。

## 关键文件与契约

- 现有 [本地导入指南](../../../../guides/local-import.md)、[audio](../../../../original/formats/audio.md)，22 的正式候选与 24 参考。
- 私有核对工具仅计划新增于本项 local 目录，不形成产品入口。

## 写入范围

- `local/research/p3-14/25-candidate/**`：私有候选核对、合法动作和试听准备材料。

## 验收标准

- [ ] 所有生产可达声音关系有候选/内容身份、触发、参考适用性和离散核对结果。
- [ ] 既有等价证据的复用理由明确；新增输出未被旧证据冒充。
- [ ] 26 可直接比较已准备的项目，用户无需代做静态研究或无目标试玩。

## 验证方法

- 私有原版内容按[证据指南](../../../../guides/original-evidence.md)操作；公开合成浏览器检查按 [browser-testing](../../../../../.agents/skills/browser-testing/SKILL.md)，两类证据严格隔离。
- 核对采样/参数、源进度与合法动作，无证据的路径保持待补，不用只调用 start 作为成功。
