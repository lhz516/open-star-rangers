# 24 — 复用与补齐原版音频参考

**契约来源：** [spec](../spec.md#对照方法与判据) 的 S-01、S-10、AC-01、AC-15。
**依赖：** 05。
**执行方式：** 自动。
**执行状态：** 仅由 [goal tracker](../goal.md#子任务跟踪) 维护。

## 工作范围

- 按 05 的 V-06 基线审计现有 P2 试听、样本等价、私有录音和其他任务原版运行的覆盖，能复用的标明准确适用条件。
- 对新增提示、空间/引擎参数、重复/竞争或模式声音缺少参考的部分，准备最小有界观测，交协调者集中运行；不要求重测全部核心样本。
- 补齐私有参考的来源身份、设备配置、触发和观察区间。能量化的样本/时序由 agent 核对；人耳判定留 26。
- 新事实补入 audio/unknowns。若新证据推翻已定公式/合同，按 spec 关卡返回修订，不放宽判据。

## 不包含

- 不预设“只允许运行一次”，不把公开视频或新版录音作为本地原版参考，不让用户承担可自动完成的操作。

## 关键文件与契约

2026-10-28。原版事实与置信度只写在 [audio 的运行时参考](../../../../original/formats/audio.md#runtime-references-p3-1424)（及其更正的各处）与 [unknowns](../../../../original/unknowns.md) 的 U-004、U-027；本文只记覆盖、运行与检查。私有方案（首次运行前写定）、配方生成器、运行目录（报告、读数、录音）、分析脚本、计算结果与运行记录（偏差与作废原因）在被忽略的 `local/research/p3-14/24-references/`。

### 复用审计

P2-08/10、P2-12/14/21/28 只覆盖 12 个核心 Asset 在开始参数下的采样同一性与音高（现场试听，无录音），沿用于矩阵中原有的范围；P3-07/09/10/11/12/13 的私有运行没有录音、没有读声部表、`0x46ecc` 或 `0x4edf4`，只复用为路线与配方助手（P3-07 a41 开局与地图点击、P3-10 停靠路线与地图转向、P3-11 F 族到玩家被毁的前缀）。因此 05 的每个必需 R 项都需新运行。

### 工具扩展（写入范围扩展，协调者 2026-10-28 批准）

`tools/baseline` 新增配方键 `emulator.audioCapture: "multitrack"`：只把私有配置中唯一的游戏启动行换成 `cd main`、`dx-capture /M srangers.exe`、`cd ..`，记入 `environment.emulator.changes` 与指纹；无此键的配方不变。录音为 AVI，每个混音通道一条 48 kHz 立体声 PCM 音轨，按模拟器时间产生（录音位置 = `emulatedMs` × 48，实测相差不到 1 毫秒）。说明见[运行时测量指南的录音](../../../../guides/runtime-measurement.md#录音)。
