# 24 — 复用与补齐原版音频参考

**契约来源：** [spec](../spec.md#对照方法与判据) 的 S-01、S-10、AC-01、AC-15。
**依赖：** 05。
**执行方式：** 自动。
**执行状态：** 仅由 [goal tracker](../goal.md#子任务跟踪) 维护。

## 工作范围

- 按 05 的 V-06 基线审计现有 P2 试听、样本等价、私有录音和其他任务原版运行的覆盖，能复用的标明准确适用条件。
- 对新增提示、空间/引擎参数、重复/竞争或模式声音缺少参考的部分，准备最小有界观测，交协调者集中运行；不要求重测全部核心样本。
- 补齐私有参考的来源身份、设备配置、触发和观察区间。能量化的样本/时序由 agent 核对；人耳判定留 26。
- 新事实补入 audio/unknowns。若新证据推翻已定公式/合同，按 spec 关卡返回修订，不放宽判据。

## 不包含

- 不预设“只允许运行一次”，不把公开视频或新版录音作为本地原版参考，不让用户承担可自动完成的操作。

## 关键文件与契约

- 现有 [P2 试听与等价记录](../../../../original/formats/audio.md#viewer-playback-path-p2-12)、[测量指南](../../../../guides/runtime-measurement.md)和 tools/baseline。
- 计划新增私有配方、录音与安全元数据；05 已要求的规则前置证据不能等到本项才补。

## 写入范围

- `local/research/p3-14/24-references/**`：私有参考、测量配方和日志。
- `docs/original/formats/audio.md`：新的参考事实与置信度。
- `docs/original/unknowns.md`：受影响的音效未知项。

## 验收标准

- [ ] 覆盖矩阵逐项有适用原版参考，或明确仍不能判断的原因；缺必要参考不得 completed。
- [ ] 补证只针对缺口并复用合格运行，原版操作/材料有版本、配置和安全定位。
- [ ] 公开文档无波形、转储或原版文字，未伪造人耳结论。

## 验证方法

- 按[原版证据指南](../../../../guides/original-evidence.md)由 agent 准备和取得证据；基准环境同一时间仅协调者操作，输入遵守测量配方边界。
- 真实秒/帧测量遵守 B-006/U-021 与已定稿判据；工具不足或权限缺失如实受阻，不使用代理证据过关。
