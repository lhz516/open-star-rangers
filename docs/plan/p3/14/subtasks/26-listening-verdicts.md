# 26 — 有原版基准的人耳判定

**契约来源：** [spec](../spec.md#对照方法与判据) 的 S-10、AC-15。
**依赖：** 25。
**执行方式：** 需用户：对已准备的原版参考和当前候选作听觉判断，agent 无法替代人的感知。
**执行状态：** 仅由 [goal tracker](../goal.md#子任务跟踪) 维护。

## 工作范围

- 由 agent 提供 25 已定位的参考与候选，开发者仅判断一致、不一致或无法判定。
- 覆盖生产可达的机型/槽位、EXPL 及竞争、引擎/空间输出、按 ID 提示、锁定和双警告、Warp 到达重复与暂停/恢复。
- 逐条绑定候选、内容身份、原版参考、观察条件与感知结论；与离散结论分别保留。
- 不一致回责任项修复再复核；无法判定不通过。接受具体差异需要单独明确批准，本项不代替阶段退出决定。

## 不包含

- 不把“按推荐回答”当成人耳判断，不要求用户重新收集可自动取得的证据，不修改功能代码。

## 关键文件与契约

- 25 的私有核对/试听材料和 24 的原版参考；事实仍链接 [audio](../../../../original/formats/audio.md)。
- 判定表写在本项完成证据，只有结构化描述，不粘贴原版内容。

## 写入范围

无。

## 验收标准

- [x] 每个必需感知项都有开发者真实判断及参考/候选身份。
- [x] 不一致已修复并复核，或有针对该项的明确差异批准；无法判定的必需项未被标为完成。
- [x] 人耳结果、原版置信度和自动化结论未混为一谈。

## 验证方法

- 对照 25 的矩阵逐项完成，只使用适用的原版参考；agent 负责操作和记录，用户负责感知。
- 本项仅记录证据，检查引用/元数据即可；无新的构建或 DOSBox 重跑要求。

- **结果：** 27 个有原版参考的项全部判为一致。`enemy-fire` 首次判为无法判定，原因是两段片段的开火密度不同（原版约 2 s 3 发，候选约每 0.25 s 一发、两个挂点各一声部）；开火节奏属战斗规则而非音效，V-06 只比较单发音高与随距离的相对响度。开发者按此复听后判为一致，与 25 的量化结论（两边起始速率都遵循 11025×(1+r/800)，从不使用存储的 17000 Hz）相符。
- **10177 到爆炸的间隔：** 25 交来的量化差异（原版约 180–280 ms，候选 37–80 ms）在试听前已向开发者特别指出；`kill` 与 `kill-2` 均判为一致，即该差异在感知上被接受，不需另行批准或修复。原版那一帧为何推进 20–42 单位仍未确定，只作为原版事实的开放问题记在 25，不影响本项判定。
- **无原版参考的 5 项**（`base-fire`、`wingman-missile`、`blast-v2`、`blast-v3`、`enemy2-hit`）：开发者对候选单独试听可接受；按 25 与 goal 的选项 (b)，这些仍是经批准的证据缺口，结论依据为采样同一性与离散结论，不计为“感知一致”。
- **分层：** 原版事实的置信度只在 [audio](../../../../original/formats/audio.md#flight-sound-presentation-p3-14)；离散与量化结论只在 [25](./25-private-candidate-comparison.md#逐关系的离散量化结果)；本表只记人耳判定，三者未合并。
