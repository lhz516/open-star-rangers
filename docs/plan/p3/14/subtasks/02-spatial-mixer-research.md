# 02 — 位置、引擎与混音参数研究

**契约来源：** [spec](../spec.md#研究项) 的 S-01、S-03、S-05、AC-01、AC-06，A-04、A-05、A-09。
**依赖：** 无。
**执行方式：** 自动。
**执行状态：** 仅由 [goal tracker](../goal.md#子任务跟踪) 维护。

## 工作范围

- 核实非玩家声源的距离、投影/声像、速率计算及读取时间点；记录真实输入、单位、钳位、零距离和不可投影分支。
- 核实玩家引擎读取的速度/机型字段、阈值与公式，不以相邻位置差或当前最高速度擅自替代。
- 核对对应版本 Miles 参数与参考设备输出关系、主音量、有限重复的源采样进度；API 转发不能证明混音曲线。
- 私有报告给 05：常量和原生依据、可复用旧参考、仍需设备输出证据的缺口及可量化观测量。

## 不包含

- 不写后备混音公式、任意误差百分比或泛用 Miles 模拟器；不改声音 payload。

## 关键文件与契约

- 现有 [audio](../../../../original/formats/audio.md)、[相机读取者](../../../../original/formats/executable.md#c1-the-3d-camera-and-its-readers--confirmed-code)。
- 现有 [sound-payload.ts](../../../../../src/content/sound-payload.ts) 的 frames、sampleRate、repeat/plays 只用于规范输出边界核对。

## 写入范围

- `local/research/p3-14/02-mixing/**`：私有研究脚本、公式核对和参考缺口清单。

## 验收标准

- [ ] A-04/A-05/A-09 的数值类型、单位、更新点与边界可复核。
- [ ] 区分采样率、播放速率、时钟单位及设备混音；没有把未经确认的 44100 Hz 限制当成事实。
- [ ] 未确认的必要曲线/参数明确列为缺口，无默认算法冒充保真。

## 验证方法

- 按[证据指南](../../../../guides/original-evidence.md)做只读原生/数据核对；需要原版输出时交协调者按明确观测目标集中取证。
- 先从原版证据形成误差预算再比较新版，不将新版结果用于倒推容差。私有输出不提交。
