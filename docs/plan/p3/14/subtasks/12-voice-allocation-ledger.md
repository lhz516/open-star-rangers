# 12 — 发声分配与句柄账本

**契约来源：** [spec](../spec.md#发声类别) 的 S-04、AC-04、AC-05。
**依赖：** 10。
**执行方式：** 自动。
**执行状态：** 仅由 [goal tracker](../goal.md#子任务跟踪) 维护。

## 工作范围

- 实现 05/06 定稿的类别容量、回收、抢占和拒绝策略，不用猜测的原版配额。
- 句柄绑定 ownerId/runId、来源命名空间/ID、槽或提示类别；只在 started 后占用新配额。
- 区分自然结束、被抢占、主动 stop、隐藏失效和宿主失败；旧回调、查询和重复回收不污染新句柄。

## 完成证据

- **实现（2026-10-17）：** [voices.ts](../../../../../src/app/flight-audio/voices.ts) 的 `createVoiceLedger({ controller, ownerId, runId })` 是一次运行的发声池：8 个记录、[A-03](../../../../original/formats/audio.md#voice-pool-and-classes-a-03) 的类别与上限 (1,2)(2,1)(3,1)(4,2)(5,2)；每次请求先回收至多一个已结束的最低记录（暂停的不算），类别未满取最低空闲记录，满时不抢占则拒绝（`refused`/`voice-limit`，不是故障），抢占则取该类别最低记录（已自然结束但未回收的也照取，不再切断）。只有控制器 `started` 才占记录并发句柄；控制器拒绝（`failed` + 平台码，如 `unknown-sound`、`invalid-parameters`、`audio-suspended`）与策略拒绝分开，抢占后启动失败时被抢占者保持释放。`query`/`stop`/`stopAll` 对应 `0x53b54`/`0x53dbc`/`0x53978`。结束原因 `natural`/`preempted`/`stopped`/`interrupted`（隐藏、浏览器挂起或中断）/`failed`（宿主故障或控制器释放）在控制器通知时记录，所以隐藏后又故障、共享控制器挤出结束历史都不改原因。句柄为冻结的 `{ ownerId, runId, serial }`，按身份只属于本账本；被新声音占用的记录、已释放的账本与别的运行都无法经旧句柄触及。账本只存来源、类别与原因，不存 PCM、文字或日志；在控制器订阅回调中重入调用账本抛错（装配错误，不吞成无声）。
- **类别槽漂移边缘的处理：** 原版类别槽在声音结束后不清，抢占可能取到空闲记录（A-03 边缘）。按 A-03 自身的规则（最低空闲记录分配、抢占取最低匹配槽、回收/停止/全停同时减计数），从计数一致的状态出发，一个类别满额时其槽最低的记录必然被占用，所以漂移不会出现；每个账本从空状态开始，因此以“占用记录数”作计数、抢占取该类别最低占用记录，与原版规则逐步等价。证据：测试中独立的 `OriginalPool` 模型带类别槽并在漂移时抛错，40 个种子 × 300 步的混合序列逐步比对记录、回收、抢占与计数全部一致；另有 2 万条随机序列的离线模拟（不入库）未出现漂移。原版中漂移需要其他途径（例如模式切换的重新初始化）造成计数失配，本项目不复现那些途径。
- **验证：** `pnpm exec vitest run src/app/flight-audio/voices.test.ts` 18 项通过：常量（上限和 = 8 = 池 ≤ `AUDIO_VOICE_LIMIT`）；按记录次序填满、预算 + 1 不建句柄或宿主声部；按记录而非新旧抢占、class 4 中警告音不抢占；惰性回收（一次一个、拒绝时也回收）与抢占已结束的占用者；自然结束/查询/stop/迟到回调只回收一次、记录复用后旧句柄失效；`stopAll`；隐藏 → `interrupted`、关闭 → `failed`；坏引用/坏参数与策略拒绝分开；参数更新；暂停不回收；跨运行的句柄；连续击杀（命中被首个爆炸抢占、下一击杀抢占前一爆炸、爆炸重放被拒、额外爆炸抢占主爆炸、主爆炸在额外爆炸结束后重放），期望按 A-03 手工推导；与 `OriginalPool` 的随机比对。变异检查：抢占取最高记录或回收取最高记录时各有 3 项失败。`pnpm check` 通过（342 个测试文件、10101 项）。
- **Rubber-duck：** 两项采纳：控制器同步通知导致的重入（改为账本操作互斥，重入抛错并有测试）；按观察时状态推断释放原因且依赖 256 项结束历史（改为订阅控制器、在通知时记录原因，并测试“隐藏后又故障”与历史被挤出）。审阅确认在串行操作下省去类别槽的等价论证成立。
- **Simplify：** 采纳：`#release` 默认原因、`stop` 先观察结束、计数改为单次遍历、结束状态常量化、测试 fixture 去除未用的错误数组。未采纳：去掉互斥（rubber-duck 要求）、把释放原因并入平台 `VoiceEnd`（平台归 10/11，超出写入范围）、去掉操作前的结束观察（作为订阅之外的兜底，开销为 8 次查找）。
- **文档影响：** 写入范围内无其他文档。建议协调者处理：在 audio A-03 的漂移边缘一条补记“按分配、回收、停止与全停规则从计数一致的状态不可达（高概率，代码规则推理 + 模拟）”；app 分册中 flight-audio 账本的说明归 27。
