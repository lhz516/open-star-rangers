## 工作范围

- **误差推导：** 依据 01、02 的运算次序、M-10 的存储与精度结论，以及 07 的预实验数据，独立推导每个连续观测量的误差预算：
  - R-04a 条件化单步：f32 写回、x87 与 JS 的运算差异、三角函数结果的差异；
  - R-04b 操纵与命令中的有单位量；
  - R-04c 固定步长持续运动：输入对齐、反复到期的累计偏移、非交换旋转次序、位置积分与舍入；覆盖单轴与原版键盘支持的组合操纵；
  - R-04d 的计时容差；R-05a、R-05b 中的有单位量。
- **定稿：** 为每个观测量写明单位、误差公式或数值、适用输入域、样本与窗口数及理由，写入本 spec 的[对照方法与判据](../spec.md#对照方法与判据)，并同步 B-008 的判据一节。
- **独立性：** 不调用、不参考 Core 候选实现的输出推导容差；推导脚本与中间结果留在 `local/research/p3-06/criteria/`。
- **定稿与记录：** 按推荐答案定稿，写明推荐理由与被排除的方案；在本 spec 审批节与 B-008 的“判据批准”中记录日期、范围与“依用户 2026-10-09 的预先授权”。定稿提交后才进入 17。
