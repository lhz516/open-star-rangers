2026-10-10，worker 01。结论全文（英文，含地址、公式记法、置信度与入档目标）在被忽略的 `local/research/p3-06/motion/findings.md`；本节只作摘要，不含常量值、反编译输出或读数。

**方法：**

- 只读 Ghidra（`-noanalysis -readOnly`），项目私有副本 `local/research/p3-06/motion/ghidra/`；内存中建立的函数与调用约定随会话丢弃。
- 函数覆盖：在内存中按原始 E8 调用目标、指向 Watcom 序言的 32 位指针与 RET/JMP 之后的空隙补建函数，从 1,811 个增至 2,381 个。
- 读写者清单：对全部函数做 p-code 扫描，覆盖 `[[n]+8]+偏移` 与一层参数传递（`BlockScan`、`ParamScan`），位姿写入者另扫 `[[n]+0x48…0x74]`（`ObjScan`）。
- 公式：以符号 x87 追踪器 `x87sym.py` 逐条读原生指令得出；FSUB/FSUBR/FSUBP/FSUBRP 的操作数次序用操作码字节核对。
- 数据类别：本地 CRAFT.NOB 的分类计数与数量级（`craft-fields.ts`、`craft-index.ts`、`craft-mag.ts`，只输出类别、计数与 2 的幂上界）。
- 独立计算：`ref_step.py` 用精确有理数，在每个写回点显式舍入（双精度、f32、扩展精度三角函数，就近与截断两种方向），不调用候选实现；自测通过（零步长恒等、可精确表示的直线飞行、长步长到达不越过、行向量漂移、两种舍入方向的差异）。

**M-01（已确认，代码；可达性另注）：**

- **阶段与筛选：** `0x221fc` 每帧在消息循环之后运行一次，按实时种类遍历（种类位升序，玩家在先）。筛选为活动值非零（含停靠 3 与 2）且状态为 4 或 7 及以上。按移动块 +4 的模式分派：0 → `0x222f0`，3 → `0x22600`，1/2 为弹丸与碎片（P3-07），4 不移动。模式 0、3 中各对象独立积分，不读其他对象。
- **模式：**
  - 飞行器只用模式 0 与 3。模式 0 由 `0x2c3b0`（实例化与恢复活动）、导弹生成、种类 0x4000、救援与 Warp 完成写入。
  - 模式 3 只由 Warp 开始 `0x2be00` 写入，其唯一调用者是派发器的 0x400 命令；该命令只由玩家的按键上下文投递为高概率。模式 3 在切片中只经玩家 Warp 可达，触发归 P3-09。
  - 被毁源（状态 4）保留模式 0 的移动块并继续按其最后的角速率与速度运动。
- **模式 0 的次序：**
  1. 冲量位移（用本帧衰减前的幅度）与幅度衰减；衰减后小于 0 时清除标志。
  2. 沿第三行的前进位移，用本帧更新前的速度（显式欧拉）。
  3. 未到达时，以机型 +0xBC（加速）或 +0xC0（减速）趋向指令速度；以未写回的双精度值判定越过并按位复制目标、置到达标志；随后更新速度比。
  4. 转向因子：机型 +0xC8 非零时为步长，否则为速度比 × 步长。
  5. 依次绕第一、第二、第三行旋转。每轴先看定时旋转（可叠加稳定角速率，之后衰减，样本时间超过到期时刻才清除），否则用稳定角速率。
  - **+0xC4 的作用：** 第三行旋转没有定时分量时，把第二行的稳定转向按速度比耦合进第三行旋转。
  - **无最高速度钳制：** 积分从不读实体最高速度（+0x78）。`0x21d88` 降低目标后，当前速度可以暂时高于最高速度，按 +0xC0 下降（答复协调者转来的问题）。
- **模式 3：** 不平移、无冲量、只有加速分支；速度比为速度 ÷ 目标且不检查正值；旋转与模式 0 相同。
- **旋转例程：** `0x228cc`、`0x22a50`、`0x22990` 分别旋转第 2–3、1–3、1–2 行。角度为 f32；FCOS、FSIN 的扩展精度结果各写回一次 f32；每个分量按旧值做一次双精度和、一次 f32 写回。移动路径上没有行向量重新正交化，长期会漂移。轴与正负号的命名归 02（M-02）。
- **零步长与长步长：**
  - 零步长时除有符号零外逐位不变，不会到达，定时旋转不会到期。
  - 长步长没有钳制：位移用旧速度与旧冲量；速度在越过目标时钳到目标；定时旋转整帧用衰减前的角速率。写入后第一帧的步长超过写入者留出的余量时，角速率可能在到期前越过零（由代码推得，未观察）。
- **位姿：** 积分直接改实体位姿，没有逐帧副本或写回。`0x21794` 是移动块（重）建时应用参数记录的例程，不是帧内步骤。其他位姿写入者及其归属见 findings §8。
- **写入者与可达性：**
  - 冲量与定时旋转的写入者是导弹爆炸 `0x2b628`（经 `0x2b408`）与两处碰撞响应 `0x29eb8`、`0x2a12c`，都归 P3-07。三者均按种子随机数各抽 6 次，并只在各自写入的到期时刻晚于当时样本时启用该轴。
  - 切片中玩家携带导弹，敌方类型与玩家不在排除掩码内，碰撞随时可能发生，因此均为可达（高概率，未经运行观察）。
  - 机炮命中不写这些字段。
  - 扰动（+0x88 起）与锁定（+0x5C）只由操纵例程读取，不进入积分，交 02（M-02）。

**逐个连续量（写回边界、支持域、独立计算方法）：**

| 连续量 | 写回边界 | 支持域 |
|---|---|---|
| 位置（冲量与前进各一次） | 分量 f32(双精度积)，再 f32(双精度和) | 有限 f32；可越过世界范围，直至世界退出规则（M-07）处理，无钳制 |
| 速度 | f32(双精度和)；到达时按位取目标 | 介于原速度与目标之间；积分不限正负 |
| 速度比 | f32(双精度商) | 模式 0 要求参考最高速度为正；模式 3 要求目标非零 |
| 转向因子 | 步长按位复制，或 f32(双精度积) | 步长为 1/32 秒的整数倍；生产步长 1/32 秒 |
| 角度 | f32(双精度积)；叠加时先 f32(双精度和) | 由机型转向率与操纵输入（M-02）或 P3-07 写入者决定 |
| sin、cos | 扩展精度结果写回 f32 | 有限 f32 角度 |
| 方向行 | 每分量 f32(双精度和) | 近单位长度，无重新正交化 |
| 冲量幅度、定时角速率 | f32(双精度差) | 由 P3-07 写入者决定 |
| 到期判定 | 有序比较 f32 样本秒与到期时刻 | 时钟小于 2^24 单位时样本秒是精确值 |

- **独立计算方法（全部连续量）：** 按 findings §3–§5 的次序，以精确有理数在上表各写回点显式舍入；sin、cos 取高精度数学值，依次舍入到 64 位与 24 位有效位，就近与截断各算一次；期望值不由候选实现生成。
- **评估器的适用域：** f32 结果必须有限（有断言），不表示有符号零；三角函数不是 FSIN、FCOS 的逐位模型，落在 f32 舍入边界附近的结果要标出，不能计为规则差异。

**M-10（静态，已确认，代码）：**

- **存储与精度：** 移动路径上的连续量都以 f32 存储，标志为 i32，模式为 u8。算术按启动时设定的 53 位精度控制舍入；两个 f32 的乘积在双精度中精确，因此常见的是双精度和或商之后再写回 f32 的双重舍入。
- **三角函数：** 移动路径上只有三个旋转例程使用 FSIN、FCOS，参数是调用者压栈的 f32 角度。积分与旋转例程中没有 FSQRT、FPATAN 或查表。
- **浮点转整数：** 积分与旋转例程中没有。仅移动块重建（`0x218e8`）由速度比换算油门时，经 `0x74518` 向零截断。
- **舍入方向：** 静态无法判定。仍沿用运行时观察到的就近舍入及其未解原因，各 f32 写回点即受影响位置，由 17 的读数判定（U-009）。
- **常量与表的分类：**
  - 冲量衰减常数、玩家建块时的单位矩阵与默认油门、由速度比求油门的系数：代码规则。
  - 油门表：启动时由模块初始化例程 `0x568b0` 计算的 129 项线性表，属代码规则，不需导入；按油门取值的含义归 03（M-04）。
  - 冲量与定时旋转写入者的常数归 P3-07。
- **方向表（答复协调者转来的问题）：** `0x568b0` 还在启动时生成 19 × 19 的方向表（`0x1b1310`，不在映像中），唯一读者 `0x56b8c` 抽 2 次随机数返回一个随机方向。它不在模式 0/3 积分路径上；调用者包括操纵 `0x21fd8`（02、P3-08 须计入抽取次序）与世界退出 `0x2f314`（04）。分类为代码规则。
