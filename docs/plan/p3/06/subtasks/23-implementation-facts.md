  - **10：**
    - **方向表与 `0x56b8c`：** 外层循环为方位角，内层为极角；第 19 × 方位下标 + 极角下标项为 (cos a·sin b, sin a·sin b, cos b)，分量都非负。第一次抽取选项，第二次选符号八分体，并记下八分体 0–7 的取反次序。取反用 FCHS，所以 +0 分量变为 −0；其余分量按位复制。写入数值一节方向表下的“Layout”“`0x56b8c`”两条。另注明：乘积的舍入取决于初始化器运行时的精度控制，它与运行库 FPU 初始化的先后未追踪。
    - **油门表：** 每步先存负项，再以 f32 累加和的位复制存正项，所以中项为 +0。写入油门表条目。
    - **`0x68050` 搜索：** 评分为 F(D(D(δy·F(δy) + δz·F(δz)) + δx·F(δx)))。最优值的初值是负的哨兵值（`0x680f4` 的立即数）；最优值仍为负，或分数严格更小时才替换。主体自身参与评分，也计入 n。随机选择再遍历一次，过滤条件相同。写入初始飞行状态 `0x68050` 第 2 步下的“Search details”“Threshold”。
    - **阈值比较：** f32 分数与 f32 阈值严格比较，等于不算更远。阈值为 F(D(t × F(t)))，t 为运行时比例 × `0x1725d0`，在栈上保持未舍入。rubber-duck 指出我初稿写成 F(D(h × h))，已按原生指令更正。Core 使用 F(F(t)²)；在代码固定的运行时比例下 t 可精确表示为 f32，两式相同，因此不影响实现。
    - **偏移清零：** 只在掩码非零的路径上清零，零掩码时不写 +0xB8–+0xC0。另核对：对象分配器 `0x520d4` 与池分配器 `0x566dc` 都不写 +0xB8–+0xC0 与 +0xAC–+0xB4，复用的槽保留旧值。新池块 `0x56620` 是否清零未核对，已在文档中注明。玩家一条补上“偏移不写”。
    - **`0x218e8`：** 先清空参数记录，再复制位置与姿态；没有旧块时就此返回，所以记录保持油门 0 与模式 0，与请求的模式无关。有旧块时写入模式；模式 0 时刷新 +0x70/+0x74，并取 chop(D(ratio × `0x17004c`))。写入运动阶段关于块构建的段落。
  - **12：**
