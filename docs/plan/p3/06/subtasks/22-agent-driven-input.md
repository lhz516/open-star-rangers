# 22 — 原版运行的模拟器内输入（解除 07、17 对用户键盘的依赖）

**契约来源：** [spec](../spec.md) 的 S-09、AC-10；[对照方法与判据](../spec.md#对照方法与判据)中“操作者：agent 先核对可用方法并准备配方；仅在已记录的本机输入限制仍存在时，请用户完成进入路线和最小按键操作”，以及“所需能力缺失时先有界扩展并用合成测试核实”。
**依赖：** 02、03。
**执行方式：** 自动。
**执行状态：** 仅由 [goal tracker](../goal.md#子任务跟踪) 维护。

## 背景

协调者在执行中新增本项（2026-10-10，依用户对新增解除阻塞子任务的预先授权，不需审阅）。07、17 原定由用户在键盘上操作，因为本机 Computer Use 无法向 DOSBox-X 送达按键（[运行时测量指南](../../../../guides/runtime-measurement.md#角色单一会话与本机限制)），而用户在执行期间不可用。02、03 的结论改变了所需输入的性质：

- 原版只经 DOS INT 21h 字符输入与 BIOS 换档标志读键（02，已确认，代码），不读端口 0x60/0x64，也没有键盘中断钩子。按键因此是字符事件，没有“按住”的语义。
- 原版没有键盘操纵；俯仰、偏航与横滚只来自游戏端口摇杆，且只在设备值变化时应用（02）。转向样本本来就需要模拟的摇杆。
- 本机的 DOSBox-X 2026.08.31 自带 `AUTOTYPE`（在模拟时间中依次送出按键）与调试器的内存写入命令（`SM`/`SMV`）。两者都在模拟器内部作用于客户机，不经宿主输入。

## 工作范围

- **可行性优先：** 先用烟测判断哪种模拟器内输入可用，再扩展工具；只实现被证实可用的方式。候选：
  - **进入路线：** 私有配置 `[autoexec]` 中、启动游戏之前的 `AUTOTYPE`，配合 P3-01 的 `gameSettings`（`STARTUP_PRACTICE`、`CURR_LEVEL`）只用键盘进入所选任务（group 0 / slot 1，难度 19）。核实 `AUTOTYPE` 的等待与间隔以模拟时间计算，且不受调试器暂停影响；否则改用下一种方式。
  - **定时按键：** 在已声明的暂停点，把字符与扫描码写入客户机 BIOS 键盘缓冲区并更新其头尾指针，需要 Shift、Ctrl 时同时写换档标志。核实原版下一次 INT 21h 读取得到该键，且只得到一次。
  - **摇杆偏转：** 按证据选择其一。（a）私有配置启用 DOSBox-X 的模拟摇杆，私有 `SRANGER.CFG` 写入校准串（`JOYSTICK=`，02 findings 第 6 节）。（b）在设备读取之后、变化比较之前的暂停点，写入已声明的设备状态字段。须核实偏转经原版自己的整数路径生效（控制块三轴、移动块速率与标志，02 的 M-02 链），也能回到零。
- **工具契约（`tools/baseline/`）：** 按既有契约增量扩展：
  - 配方逐项声明每个刺激：种类、触发（暂停点 ID 或启动脚本）、目标与取值。写入只允许落在声明的输入通道（BIOS 键盘区与换档标志、声明的设备状态字段），不得写入被测的运动、控制或任务状态；未声明的写入在解析时拒绝。
  - 报告逐条记录实际施加的刺激：时刻、暂停点、地址、写入前后的字节，以及写入后的回读。
  - 写入算入读写预算与日志预算，并沿用会话锁、私有副本保护与回收；基准文件与基准配置不变。
  - 用 `fake_debugger` 补合成测试，覆盖声明、拒绝、记录与预算各分支。
- **指南同步：** 在[运行时测量](../../../../guides/runtime-measurement.md)中增加“模拟器内输入”的角色与流程（agent 可独自完成需要游戏操作的运行），并同步[工具用法](../../../../guides/tools.md)。在[原版证据获取](../../../../guides/original-evidence.md#agent-运行原版)写明边界：经工具声明并记录的模拟器内刺激是允许的方法；宿主层注入（shell、AppleScript、后台按键）仍然禁止。
- **烟测（私有副本，无宿主输入）：** 证明以下各项，运行目录与笔记放在 `local/research/p3-06/agent-input/`：
  1. 进入所选任务的飞行状态，并以 P3-02/P3-01 的身份字段核对任务与难度；
  2. 在一个暂停点施加一次油门键（例如 `+` 或 Backspace），读到 03 预测的指令速度变化；
  3. 一个摇杆刺激产生 02 预测的速率与标志变化，并能回到零。
- **不可行时：** 写明尝试、失败点与原因；07、17 保持需用户，由协调者按 goal 记为 blocked。
