# 02 — 原版研究：操纵应用、旋转、按键与灵敏度

**契约来源：** [spec](../spec.md) 的 S-01、AC-09；[原版研究](../spec.md#原版研究)的 M-02、M-03；[操纵](../spec.md#操纵)；[技术决定](../spec.md#技术决定) 8；[执行检查点](../spec.md#执行检查点) C 的灵敏度部分。
**依赖：** 无。
**执行方式：** 自动。
**执行状态：** 仅由 [goal tracker](../goal.md#子任务跟踪) 维护。

## 工作范围

用只读 Ghidra 回答以下问题，结论写入被忽略的 `local/research/p3-06/controls/findings.md`（英文，只记地址、类型、作用与置信度，供 21 写入 `docs/original/`），并在完成证据中摘要：

- **M-02 操纵应用与旋转：**
  - `0x21dd0`、`0x21fd8` 的输入编码：取值范围、“不变”标记与零值的语义；
  - 三个轴与机型 +0xAC/+0xB0/+0xB4 的对应与符号，目标速度的计算；
  - +0x88 扰动的条件、抽取次数与次序及其写入者，+0x5C 锁定的写入者；
  - `0x21fd8` 的全部调用者（判断它是否只服务于自动驾驶）；
  - 旋转例程 `0x228cc`、`0x22a50`、`0x22990` 的轴、行、符号与角度公式，以及是否归一化；
  - 项目轴（抬头、机头右转、从驾驶员向前看顺时针横滚）到原版操纵值的对应。
- **M-03 仅键盘配置下的操纵值：**
  - 切片所用配置下的操纵驱动（`0x1761e4`、驱动表 `0x176204`）；
  - 键盘如何产生操纵值（经设备读取，还是经按键上下文）：取值集合、持续、渐变与归零；读取时刻与按视角模式的门禁；不读取的模式中已应用值是否保持；
  - 灵敏度档位的来源（`0x1b249c`、`0x57a70`、`0x57c24`）、初值，以及它是否改变键盘可产生的操纵值的效果；
  - 对应的物理键（俯仰、偏航、横滚）。静态无法确定时，在完成证据中写明需要 07 在运行准备阶段试键核实的内容。
- **为检查点 A、C 准备：** 在完成证据中列出操纵状态的候选字段、浮点路径是否需要实现，以及 G-10 是否需要的依据；不在本项定稿。
- **记录：** findings 中标明每条结论应写入的原版文档与受影响的 U 项（负责阶段不改），由 21 入档；脚本与输出在 `local/research/p3-06/controls/`。
- **冲突处理：** 若结论表明 spec 的逐 tick 轴契约不足以表示键盘可产生的操纵（例如需要跨 tick 的渐变状态），在完成证据中写明冲突，交协调者走 spec 修订。
