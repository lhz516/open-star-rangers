# 17 — 原版正式采集

**契约来源：** [spec](../spec.md) 的 S-09、AC-10；[对照方法与判据](../spec.md#对照方法与判据)（检查点 B 批准的判据）；M-10 的舍入方向。
**依赖：** 08。
**执行方式：** 需用户：在 DOSBox-X 的私有副本中只用键盘进入所选任务，按操作手册完成覆盖下限要求的飞行、按键、匹配与跨越活动区域和世界边界的操作（每次约 10–20 分钟，次数按检查点 B 定稿）。原因：本机 Computer Use 无法向 DOSBox-X 送达按键；agent 负责配方、启动、读数、应答、判定与记录。执行时若该限制已解除，协调者改为自动。
**执行状态：** 仅由 [goal tracker](../goal.md#子任务跟踪) 维护。

## 工作范围

- 按 B-008 已批准的方案与判据运行，配方与操作手册沿用 07（采集开始后不改方案；偏差写入运行笔记）。
- 取得检查点 B 定稿数量的合格运行（工具报告为 `complete`），覆盖 spec 的覆盖下限：步长、各轴与组合操纵、油门全部档位、手动匹配与辅助匹配、非玩家飞行器、起飞初态的两个时刻、跨越活动区域与世界边界的样本。不同 cycles 的运行分别报告，不混合样本。
- 用读数判定飞行中运动写回的舍入方向（M-10 运行部分），结论写入 executable 与 U-009；若有写回只与向零舍入一致，按 spec 技术决定 12 给出推荐方案，交协调者按检查点的授权修订并记录。
- 原版事实（运行时确认的规则、轴与符号的对应）写入 `docs/original/`，B-008 写入测量结果（只记安全身份、统计量与判定，不记读数原值）。
- 正常切片中无法复现的必需分支（例如速度辅助）记录原因与恢复条件，不删除该验收。
- **阻塞：** 无法取得必需的输入操作或合格样本时，本项记为 blocked，写明尝试、缺口与恢复条件，不用合成测试或静态结论代替。
