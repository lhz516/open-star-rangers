# 11 — 运动阶段与积分

**契约来源：** [spec](../spec.md) 的 S-03；AC-02，AC-07（首次运动的合成部分）；[运动阶段与积分](../spec.md#运动阶段与积分)；D-08 的阶段接入；技术决定 1、12。
**依赖：** 10。
**执行方式：** 自动。
**执行状态：** 仅由 [goal tracker](../goal.md#子任务跟踪) 维护。

## 工作范围

- **`movement` 阶段（第 8 阶段，`0x221fc`）：** 在 `PIPELINE` 中提供 `run`，阶段表与次序不变；实时种类遍历，按 M-01 筛选对象（非停放；被毁源或活动及以上），按移动块模式分派。实现飞行器使用的模式；弹丸与导弹的模式留给 P3-07，分派表在未知模式上为故障而非静默跳过（按 M-01 定稿）。
- **积分与旋转：** 按 M-01 的公式与次序实现规则函数：沿机头前进、速度按机型速率趋向目标与到达标志、速度比字段、角速率旋转、定时旋转及其到期、冲量及其衰减、+0xC4 的作用；旋转例程按 M-02 的轴、行与符号。函数以步长为参数，支持 0 与任意正偶数个时钟单位；公开 `World.step()` 仍只推进已配置的正步长。
- **数值：** 中间运算双精度，f32 写回用 `Math.fround`，浮点转整数向零截断；三角函数用 `Math.sin`/`Math.cos`，不引入查表或定点（除非 M-10 有相反证据）；非有限或超出支持域的结果锁存为 `invariant-violated` 故障，不发布部分输出。
- **位姿权威：** 实体的 `position` 与 `orientation` 仍是唯一位姿；若 M-01 证实原版有副本写回，按其时机更新实体位姿。
- **分阶段接入：** 冲量、定时旋转等由其他任务写入的分支，若 M-01 证实切片可达，在此实现并以内部状态测试；不可达的不实现，交 19 记入已知差异。非玩家飞行器在 P3-08 交付前按实例化时的移动块运动。
- **测试：** 每个已实现分支的独立期望；步长 0、2、4、6 与支持域边界；本 tick 实例化的实体不运动、下一 tick 按生命周期激活；故障锁存；起飞初态在首次运动之后的值。
