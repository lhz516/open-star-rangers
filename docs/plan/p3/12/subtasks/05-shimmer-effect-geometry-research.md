**Q-07（已确认，代码；颜色与光照外观高概率；接缝外观未确认，待 G-05b）：**

- 放置与朝向（A7）：弹丸 `0x3fb1c` 挂所选 RENS 记录的共用网格（无越界夹取）；导弹 `0x4457c` 挂类型的机身、尾翼、附加元素共用网格与元素副本，类型越界时**夹到最后一种**（spec 规定按契约错误拒绝，交 20 记为有意差异）；rand % 32 存而不用。帧为场景根的子帧，每 pass 由位姿项取对象位置与（方向 R2、上 R1），不加偏移、缩放或额外旋转。
- 是否受光（渲染质量，沿用 02 L5 的语义）：弹丸 1（不受光平面）；导弹机身与尾翼 2（平面受光，4 级）；导弹贴图元素与附加元素 1（不受光）；带贴图碎片形状 2；无贴图碎片形状 1（不可达）。
- 颜色的取值范围与通道：`0x7a698` 把 R、G、B 三个 f32 各夹到 [0, 1]、乘 255、以 2⁵² + 2³² 常量按当时的 x87 舍入方式取整，打包为 0xFF RR GG BB 写入每个面；之后经 ramp（受光 4 级、不受光即原色）映射到最近的 DATA。`0x7a698` 不设控制字，渲染器中实际的舍入方向是 02 的未决缺口 L-G6；本地谓词（`data/colour-rounding.py`）表明对切片的全部输入，两种方向只使记录 0、6 的一个分量不同，而其最近 DATA 项相同，导弹打包颜色完全相同，故显示的弹丸颜色与导弹打包颜色不受 L-G6 影响（其后的受光明暗与模型一样受影响）。本地谓词：切片的 4 条 RENS 记录分量都在 [0, 1]；9 种导弹的机身/尾翼乘积都在 [0, 1]；附加元素的立即数有两个分量超出 1 被夹取。
- 跨接缝插值（A8，原生）：多边形按存储次序以角 0 为扇心三角化；对标志非零的坐标（+0x54 对 u），三角形中与另两角都相距 > 0.5 的那个角（依次检查 b、c、a，等于 0.5 算近）朝它们移动 1，至多移动一个角，即“绕短路”；随后仿射插值、贴图坐标回绕；裁剪插值同样走短路（`0x113f20`）。包裹把 +0x54 设为 0x0C、+0x55 设为 0，故导弹元素、带贴图碎片与闪烁外壳只在 u 上做此处理。
- 外观（E）：截图 099 中导弹区域包含 TEX 10377 全部 16 个映射色（1,861 个非黑像素中 1,404 个），机身与尾翼各为两种逐面均匀的明暗 → 元素不受光、机身尾翼平面受光（高概率）；弹丸记录 0/6 的颜色只出现在 112、128（玩家炮 0 与基地炮 6），记录 1、2 的颜色在五张图中都有（也是 HUD 颜色，证据弱），与 P2-12 的一致结论相符（高概率）。接缝面在现有截图中无法单独对照，其外观为未确认，列为 G-05b（最小补证：侧面近距导弹截图与两种接缝处理的渲染对照）；G-05b 是 Q-07 最终外观结论的必需缺口，规则本身已确认。
