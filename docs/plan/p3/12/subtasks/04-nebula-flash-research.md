**Q-04（已确认，代码；外观由截图精确匹配确认）：**

- `0x484f0`（飞行初始化 `0x3ec70` 中每次程序运行一次）设六个槽：中心方向 +z、−z、+y、−y、+x、−x，各带沿一条世界轴 ±0.05 的两点 B、C；`0x486e4` 在任务建造时让槽 i 显示 NEBC 的第 (起点 + i) mod n 项（加载失败时不前进）。方向只由 `0x484f0` 写、只由 `0x489d0` 读；绘制只用相机行，不用相机位置（findings A1）。
- 门禁与视角：`0x489d0` 只在设置项 5（`SRANGER.CFG` 键 `DETAIL`，设置页的 BACKGROUND DETAIL，缺省为开）非零时绘制，只在视角 0xC–0x12（含 0x11/8）中由 `0x3ee58` 调用（A2）。
- 位置、可见与转角：zA = R2·A ≥ K 时绘制（K = F(cos(√2·atan 0.5)) ≈ 0.7926，约 37.57° 的圆锥；任意两个方向至少相差 90°，因此同一时刻至多一幅可见）；sx = chop(320 + 567.155·x/z)、sy = chop(240 − 567.155·y/z)（HI，K、S 由 `0x3fbc0` 写入）。这与三维投影（640，F1 中心行 158）不同；θ = atan2(yB − yC, xB − xC)（A3）。
- 读法：四个象限的镜像/转置标志组合起来总是正旋转、从不镜像，存储图像的行轴沿屏幕方向 θ（即投影后的 C→B），θ = −π/2 时与存储方向一致；半对角线 64√2，按 45 行查表 `0x1b2b20` 与两层 Bresenham 取样，斜步写两次；只写 0 ≤ x < 640、1 ≤ y ≤ 视口下边界（第 0 行从不写）；占位不超过 ±91 像素（A4，全部 1,057 个模板）。
- 清除：`0x488b4` 以索引 0 填充上次位置 ±100 的矩形（夹到屏幕与当前视口下边界），覆盖 ±91 的占位（A5）。
- 截图匹配：83 张截图中 19 张（覆盖 10 幅图像与全部四组象限标志）通过预设判据（≥ 1,000 个计分像素上得分 ≥ 0.9，三个对照都 ≤ 0.5），其中 008、012、040、091、097、112 为 1.0 或 0.999；镜像与 θ+π 对照得分 0.02–0.25。θ 恰为 0 与 −π/2 的轴对齐情形必须作为普通输入复现（规则网格会漏掉）。058 中图像恰在 (320, 240)、θ = π，只与单位相机（玩家的任务初始姿态）下的槽 0 吻合，佐证 F1 中星云中心行为 240（高概率，未读相机）（A6）。
- **U-018：** 这 15 幅在 DATA 下直接显示由代码与截图共同确认，“DATA 下颜色明显不对”的目视判断对它们不成立（findings C 给出 unknowns 的替换文字；状态仍为部分确认，因基地内部的 4 个 BITM 未解决）。

**Q-06（已确认，代码）：**

- 三个启动函数共用一份全局状态：每次启动（含同一种闪光再次启动）覆盖全部字段并从满级重新衰减，没有队列或优先级，最后一次启动生效；开关 `0x175c54`（`P` 键）只在启动时检查（D1）。
- 触发者（原始调用扫描完整）：闪光 0 `0x48d64` —— 命中消息 (2, 4) 落在玩家对象上且视角不是 0x11，以及 Warp 中每个碰到管壁（d² > 2500）且进度在 5–95 % 内的渲染 pass；闪光 1 `0x48dbc` —— 只由 X4 的 `0x24314` 投递的 (2, 6)，无视角检查；闪光 2 `0x48e14` —— Warp 开始（换成 Warp 调色板并重建闪光表之后）以及视角 1 中进度 D(D(n + u) ÷ L) > 0.95 的每个 pass（每帧重启，最后 5 % 保持接近满级）。即 spec 的“第三种”是 Warp 闪光（D2）。06 的 Warp 研究经协调者转来的结论与此一致。
- 节奏：`0x48e6c` 在视角 1、8 与 0xC–0x12 的每个渲染帧调用一次；经过时间超过持续时间（严格）时写回表 0 与平移 0 并结束；否则当 sample > next（无符号、严格）时抽一次 rand AND mask 并令 next = sample + interval；级别 = chop((持续 − 经过) ÷ 持续 × levelMax)，每帧重算。暂停与菜单不计时，闪光停在原处（D3）。
- 调色板公式与作用范围：写入第 level SAR 1 张表的全部 256 项 DAC；表 k = min(P6 + 2k, 63)（`0x48cc0`，P6 为最后一次 `0x58288` 的 6 位调色板快照，在飞行初始化、驾驶舱布局换调色板与 Warp 开始时重建），因此整个画面（含驾驶舱、HUD、文字）一起变亮（D4）。截图 044 与 120 的每个像素分别符合 +10 与 +56（偶数，符合 2·(level SAR 1)），非闪光对照 122 符合 +0；两张图属于哪种闪光不作归属（D6）。
- **另发现的画面平移：** 抽到的 r ≥ 0 且不在 LO 时，`0x48f14` 还把 CRTC 起始地址设为 80·(r AND 0xFFFE)（已确认，代码）；044 中整个画面恰好上移 3 行（标签掩码 IoU 0.994），对应 (r AND 0xFFFE)/2 行（4 字节单位，高概率）。按谓词，闪光 0 的最大平移超过 8 行，闪光 1 在 3–8 行之间，闪光 2 不平移（D4）。
- **时间单位（D5）：** duration 为 f32 秒，与 F(sample/64) 之差比较；`drawIntervalTicks` 实为 1/64 秒的任务时钟单位，加到每帧取样 `0x186414`，严格比较。按 Core 每 tick 2 个单位：记 due = 抽取时的 tick + interval/2，在第一个 tick > due 时再抽，即间隔 interval/2 + 1 个 tick（三个值都是偶数）；字段名中的 “ticks” 不是 Core tick。level 为 i32，经 SAR 1 得表号。
