## 完成证据

- **2026-10-16 — 研究结论（草稿全文：`local/research/p3-12/lighting/findings.md`，英文，按 executable/mesh/textures/unknowns 分节，供 08 并入）：** 只读静态分析（私有 Ghidra 副本，`-noanalysis -readOnly`），未运行 DOSBox-X；本地数据只输出谓词与计数。
  - **渲染模型（已确认，代码）：** 设备以颜色模型 0 创建，取 ramp 驱动与 `ramplt.c` 光照模块（`0x7b710` → `0x957b4`）。
  - **两盏灯（已确认，代码）：** 类型 3（方向光）挂在根帧的子帧上，朝向 (1, 0, 0)，不随相机；指向光源的向量为世界 (−1, 0, 0)，按物体 +0x54/+0x60 轴变换到模型空间。类型 0（环境光）挂在根帧。ramp 模型只用单色强度 I = ((C0·77 + C1·150) + C2·29)/256（`0x7b074`），灯光色相不起作用；环境级 a = min(255, 256·I 取整)/256。
  - **梯度（已确认，代码）：** 模型无材质，镜面与自发光为 0；明暗级数 4（设备与贴图），未受光部件 1 级。第 i 级 = min(255, chop(c·a + c·((i/3)·(1−a))))，第 3 级等于原色，第 0 级为仅环境光色；每级经已确认的最近色规则映射到 DATA。梯度表 4,096 槽，满时按 `0x6c598`（有符号分量差的特殊写法）共用最近梯度；以基线计数推断不会触发（高概率，缺口 L-G7）。
  - **设备字节（已确认，代码）：** RENS +0x18 经 vtable +0x34（`0x7d020`）写入设备渲染质量；实际质量 = min(设备, 网格质量)：0 线框（高概率）、1 不受光平面、2 平面受光（面法线）、3 Gouraud（逐角法线），基线为 3。设备 +0x48（高概率为抖动开关）被游戏置 0，所选光栅化路径没有抖动（已确认）。
  - **着色与取整（已确认，代码）：** 单光快速路径 `0x6e3b8` 给 8.8 定点明暗值；平面每三角形取 (值 + 0x80) >> 8，Gouraud 逐像素线性插值后四舍五入（插值装配细节为缺口 L-G1）。贴图最近点采样、按小数部分重复、仿射、无 mip，模型面不做接缝修正。
  - **部件标志（Q-12，已确认，代码）：** 第 0 列表的标志低字节就是部件网格的渲染质量（`0x3da54` → `0x8249c`），基线下 1 不受光、2 平面、3 Gouraud；第 1 列表不读标志、固定质量 2（`0x3e590`）；第 2 列表取首个部件的标志（`0x42058`，1 即不受光）。`0x6a7b4` 只收 MESH，不读部件。
  - **新发现（已确认，代码与计数）：** `0x6a7b4` 以着色槽数 ns 作为法线数复制，而 MESH 只存 nv 个法线；槽号 ≥ nv 的角读到面数据，按小值不归一化，结果只受环境光。第 0 列表标志 3 的部件中 113/382 个网格、2,593/11,643 个角受影响，读取都不越出数据块。
  - **舍入方向（缺口 L-G6）：** 精度 53 位已确认；光栅化例程置截断且不恢复，而 P3-02/10、P3-06/17 的运行时观察为就近舍入，原因未确认。按基线环境级，1,024 个梯度分量项中 127 个在两种方向下差 1；最小补证为飞行中在 `0x6c0e8` 入口读 FPU 控制字（同时闭合 executable 中 x87 舍入的未决原因）。
  - **外观（高概率）：** 本地截图颜色集合核对：`srangers_020.png` 敌机区域 6,302 个非黑像素中，除 HUD 颜色外全部落在推导颜色集合内，其中 3,888 个是不经明暗无法产生的仅环境光颜色；`srangers_067.png` 基地区域除 HUD 与一种颜色的 63 个像素外全部落入。按环境级偏移 ±6 时覆盖减少；该核对不区分舍入方向，也不核对哪一面受光（缺口 L-G3）。
  - **其余缺口：** L-G2（光向量归一化逐位，影响仅在边界）、L-G4（零件颜色/质量覆盖消息的发送者，有界未找到）、L-G5（贴图开关 `0x1863c8` 的飞行默认值，截图显示为开），各附最小补证。
- **给 17 的计算步骤（摘要；完整版见 findings 的 “Implementation input for subtask 17”）：** ① 由 `data/scene-settings` 算 I_d、I_amb 与环境级 a；② 世界光向量 (−1, 0, 0) 按物体轴变换并归一化；③ 部件质量 q：第 0 列表 min(设备字节, 标志)、第 1 列表 min(设备字节, 2)、第 2 列表 min(设备字节, 首部件标志)；④ 源颜色：贴图用该 TEX 自身调色板（`ImagePayload.indices` + 源 `PalettePayload.entries`），无贴图用部件颜色；⑤ 每级明暗色按上式；⑥ 在此处、且只在此处复用 `nearestColourMap`：每个明暗级各建一个不超过 256 项的合成源调色板，映射到 DATA，组成（纹素, 明暗级）→ DATA 表，不使用 `expandImage`/`expandModelTextures` 的量化结果；⑦ 法线：q=2 用面法线 normalize(normalize(b−a) × normalize(c−a))，q=3 用 `normals[slot]`，槽号 ≥ nv 的角明暗值为 0；⑧ k = f32(3·I_d)，L′ = f32(L·k)，d = f32(L′·n)，值 = d > 0 ? 256·d 就近偶数取整 : 0；⑨ 平面 s = (值 + 128) >> 8，Gouraud 屏幕空间线性插值后逐像素四舍五入，不受光 s = 0；⑩ 最近点、重复、仿射、无 mip，无抖动。若 07 确认渲染时为截断，按 findings 的说明改用向零舍入。
- **独立期望构造（Node，合成数据）：** 测试内独立写出明暗式与逐项暴力最近色（严格小于、低索引优先），不调用 `nearestColourMap`；用 a = 0.25 等手算值覆盖 chop 边界与并列；I_d = 0.5 时 n·L = 1、1/3、≤ 0 与极小正值分别得 s = 2、1、0、0；ns > nv 的合成网格在越界角得 s = 0；标志 1/2/3 在设备字节 3 与 2 下的质量；世界 −x 依次映射到模型 ±x、±y、±z 轴以检出光向反向、矩阵转置与轴错位；构造 nearest(shade(c)) ≠ shade(nearest(c)) 的调色板以检出“先量化后明暗”；同一模型中有贴图与无贴图部件；UV 小于 0 与大于 1、放大与缩小三角形以检出重复、最近点与无 mip。
