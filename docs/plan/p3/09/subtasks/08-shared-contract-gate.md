## 工作范围

- 依 07 的汇总，把具体形状写入 [P3-02 spec](../../02/spec.md) 正文的新增修订节（P3-09 的契约修订）：
  - 玩家状态中的地图状态、Warp 状态、保存页与选择资格：类型、单位、初值、null/失效、合法值，以及每个阶段的写入者与关闭/再次打开/重试/移除/救援的责任；玩家状态字节 +0 是复用、派生还是新增；
  - 种类 25 实体与模式 4 移动块变体：来源、名称引用、表现判别、参与的阶段与生命周期；
  - 地图可见标志、两个集合与刷新历史，及与 P3-08 的共用；若有历史探索数据，其索引、单位、更新与重置；
  - 命令结果表：`toggle-map`、`map-point`、`request-warp` 每个拒绝的原因码、ignored/rejected 与优先级；地图中 `select-number`、`confirm-selection`、`navigate-selection` 改为 `wrong-context`；关闭地图与基地内打开的玩家门禁例外；
  - 有序命令的有效上下文、`request-handling` 的实际提交位置、早先请求与自动选敌的次序，以及最终上下文决定连续轴；
  - 领域事件的封闭联合与每项字段（[事件最低要求](../spec.md#共享契约修订p3-02)）；比较器、快照、日志与桥接关键字段的同步清单；
  - `map` 分区的封闭形状（框架与像素几何、接触点、覆盖、光标与放大范围、放大窗口成员与多选框、信息行、标签与连线、目的地与能量读数、可执行性原因）；`flight.combat` 中的 Warp 读模型；Render State 的 Warp 进度与标记判别；
  - `object-sets`、`warp-completion`、`frame-end` 的阶段接入与 completion 消费前一次 frame-end 的边界；`CORE_LIMITS` 的新上限与依据；`RULES_VERSION`、快照与 replay 格式的递增规则。
- 把地图几何的内容输入写入 [P3-03 spec](../../03/spec.md) 的增量修订：Asset ID、角色与分组、payload schema、字段与单位、读取器、预算、切片定义版本与 `ConverterVersion` 的递增、`createWorld` 的 `{ id, content }` 输入与 setupHash。
- 同步 [P3-05 spec](../../05/spec.md) 对右键编号的交接（按 04 的读者结论）；其他受影响的 spec（P3-04、P3-06、P3-07）只加交接注记，不改其已批准的范围或历史证据。
- 每批修订写明所选方案、理由与被排除的方案；取得批准后在对应 spec 的审批节记录日期与原话。研究推翻本 spec 方向时，先修订本 spec 并重新取得批准。
