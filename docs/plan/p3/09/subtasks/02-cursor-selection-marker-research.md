**Q-02（已确认，代码；数值在启动控制字即双精度、就近舍入下成立，U-009）：**

- 玩家状态块 `0x1b0638` 由常量取址函数 `0x52694` 返回，“玩家状态非空”门禁恒真。+0x00 字节为“已选择目的地”（标记已尝试创建），+0x04–+0x0C 为光标世界点，+0x10–+0x18 为目的地。
- `0x49e74`：主地图边长取记录竖直范围（含末像素），信息窗与放大窗在右侧条带（宽度不含记录末列）；像素/单位比例先以双精度相除再存 f32，单位/像素是双精度比值的倒数再存 f32（不是 f32 比值的倒数，本地 3/52 个任务两者不同）。
- `0x4c4c0`：世界最小角加像素偏移乘单位/像素，只在 f32 存储时舍入，z 为 0；可达像素 0…边长−1，像素 0 恰为世界最小值，末像素小于最大值。`0x4c524`：两端含在内的世界范围判定，各轴向零截断为地图局部像素。
- `0x2bc30`：放大范围以半宽为中心，每边分别夹取到世界矩形（靠边时缩小而不平移）；范围大小只由任务构建中的 `0x2b814` 写入，来自换算后的 SCEN 头部比例：x 为一个扇区，y 为两个扇区，对所有任务相同，不是布局字段。
- `0x4c310`：候选为地图图标表中在世界矩形内、且种类位序号非 0 的项（玩家自身图标从不命中）；以 ±3 像素的含边正方形取窗，按整数平方距离严格更小者替换，并列取表中最早项。
- `0x2bd74`：z 门禁字段为玩家状态 +0x8C（玩家对象）；命中时 z 为该图标表项保存的 z（建表时对象的 z），未命中为 0。门禁为空的分支在左键路径上不可达。
- 本地数据（CCKD 10103/10101 布局 6 的 10 型记录各 1 条且相同；52 个 SCEN）：起点在主地图内、左上象限、不是中心，与 spec 公式一致；52 个任务比例有限且为正、两轴相同、像素 0 映射到最小值、末像素低于最大值且单调；光标像素换回地图像素时各轴为同一像素或少一像素（就近舍入下，高概率）。

**Q-03（已确认，代码，另注者除外）：**

- `0x3cb80`：种类 `0x2000000`，名称 +0x15C 取 EXE 字符串 `0x171860`，活动 1、状态 1，机型记录为空（第 25 位不小于 CINF 机型数），回调 `0x20ae4`；**创建时消耗一次共享 rand()**（`0x56cd4` 从 64 个启动旋转中取姿态）；移动块模式 4，只记创建位置副本，不积分。
- 生命周期：第 N 帧请求处理中创建；N+1 帧对象更新提交状态 7、同帧请求处理生效；从 N+1 帧相机步骤起为雷达接触（颜色 8）；从 N+2 帧玩家回调起成为友方目标模式候选（敌方模式与 `u` 不含）。只由之后的 select 在请求处理中改位置。
- 参与：对象更新（状态 7 后无动作）与运动遍历（模式 4 不动）、雷达、友方目标、目标窗口（T7 分支只读两点距离，以三条 EXE 字符串替换其他读数，仍画名称）、Warp 完成的最近对象搜索、AI（`0x5dab0` 对标记目标不读记录）。不参与碰撞、能量、对象集合与地图图标、面积检查、停放更新；场景渲染跳过该种类（无 3D 表现）。
- 移除：所有掩码、伤害、停放、面积与消息路径均已确认不含标记，只在拆除时进入状态 6；`0x21650` 的五个辅助调用者的对象未逐一追踪，故“只在拆除时移除”为高概率。标记失效后的再次选择（已确认行为）：仍更新目的地、z 与点击音，但不重建标记；Warp 读的是保存的目的地。

**命中列表、select、多选框与初值（已确认，代码）：**

- select 在轮询的同一帧请求处理中执行，读的是上一帧渲染（`0x49f8c`）按上一帧相机步骤（`0x2b8ec`）发出的图标项建立的列表，顺序为种类位升序再按分配顺序。Core 须自行保存并序列化该列表，不能以当前全实体查询替代。
- 按住或坐标不变的 select：每次读取都重写目的地、重算命中与 z、移动标记并发出点击音（音效到期为 sample+4，短于读取间隔）。
- 放大窗口选中方框只是绘制时的按轴测试（以目的地为中心，各轴截断差的绝对值小于 1000.0），可一次框住多个单位；地图代码不调用目标设置器、不发消息 2，不改玩家战斗目标。
- 初值：玩家实例化（每次任务构建与重试）把 +0x00 置 0、光标点与目的地置零向量；唯一的置 1 者是 `0x2b9bc`。救援、关闭地图与 Warp 不清除。未选择前飞行与地图中的 `w` 都不发 Warp 请求（无消息、无声音），也不绘制目的地标记与方框。零距离属 Q-07。
