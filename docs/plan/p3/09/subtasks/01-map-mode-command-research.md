# 01 — 地图模式与命令门禁研究

**契约来源：** [spec](../spec.md) 的 S-11、AC-14；[原版研究](../spec.md#原版研究) Q-01，Q-12 中地图消息与命令次序的部分；[地图模式](../spec.md#地图模式)。
**依赖：** 无。
**执行方式：** 自动。
**执行状态：** 仅由 [goal tracker](../goal.md#子任务跟踪) 维护。

## 工作范围

- **Q-01：** 在 `0x270c0`、派发器子命令 8 与 9、`0x33504` 中核实打开地图的完整资格（战役标志之外是否还看被毁、停靠子状态、Warp、通讯菜单页）、关闭的条件，以及打开与关闭时复位或保存的全部规则状态（`0x49e3c`、`0x1747dc`、`0x18649c`、`0x1864c4`、左显示屏页、`statusDisplay`、光标与放大范围）。
- 通讯页与能量页前置处理对 `m`、`w` 的占用次序；基地上下文 `0x271e0` 中 `m` 的路径与“从基地打开的地图拒绝 `w`”。
- 玩家被毁、能量耗尽与停靠子状态 3–5 时，地图能否打开、能否保持，以及被毁视角对视角 8 的处理。
- **Q-12（本项部分）：** 地图消息在派发器消息循环中的处理位置，以及它与同帧其他消息（目标、开火、速度、自动选敌）的先后，供 D-01 定“有序命令按前一命令生效后的上下文判定”的对应关系。
- 关闭地图时是否清除跃迁目标、标记或任何选择资格（与 02 交叉核对）。
- 事实写入 `local/research/p3-09/map-mode/findings.md`：英文，按目标文档与节写成可直接并入的草稿，带置信度（Confirmed/Likely/Unconfirmed）与证据，只记地址、结构与行为，不含原版内容或反编译输出；受影响 U 项的状态变化一并列出。由 07 统一写入 `docs/original/`；本项不改跟踪的原版文档，使 01 至 06 可以并行。
- 完成证据给出交 07/08 的摘要：所需状态字段、原因码与结果候选、阶段位置，以及与 spec 已批准方向一致或冲突之处。
