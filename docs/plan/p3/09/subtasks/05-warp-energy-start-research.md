- **Q-06（已确认，代码）：** `0x30d2c` 有四个直接调用者、无指针：开始检查 `0x2be00`、完成扣费 `0x30d94`（唯一调用者 `0x2bf08`）与地图绘制的光标读数、目的地读数；都传玩家句柄，只有玩家机型记录到达。参数是 `0x56b14` 求得的三维距离（x87 双精度，各分量差与其 f32 舍入相乘后按 y、x、z 次序相加再开方）向零截断的整数，单位为世界单位；按表序取第一个满足 trunc(n÷1000) ≤ 首值（有符号）的数值对，否则取最后一对；结果为系数×n（32 位回绕）÷1000 向零截断，单位为能量单位；计数 ≤ 0 时读数组之前的字（未定义）。检查：消耗 ≤ 当前能量（有符号，等号通过）。地图百分比 = trunc(消耗÷当前能量×100)，基准是当前能量而非容量；显示值至少 1；颜色阈值 100 与 66 比较的是夹取后的显示值，≥100 恰好对应消耗 ≥ 能量，因此也包含能量恰好够用而被接受的情形。光标读数用光标世界点（z 为 0），目的地读数用保存的目的地（带 z）而非标记对象，起点都是本帧地图图标列表中玩家的位置。能量为 0 时地图读数在未屏蔽的 x87 异常下触发除零/无效运算，其后果未确认，列入 09 的观察计划。切片数值对（已确认，数据）：CINF 4037 玩家记录 3 对，首值严格递增且非负、系数为正且不减，消耗随距离单调、零距离为 0，在 SCEN 3019 的平面对角线内乘积不溢出、最后一对的分段覆盖该距离；满能量够开始检查，但不一定够完成时最多 1.5 倍的扣费。24 个 CINF 的玩家记录都满足同样的结构判定。
- **Q-07（已确认，代码）：** 玩家状态字节 +0：只由首次地图选择 `0x2b9bc` 置 1、玩家实例化清零（02）；Warp 开始、完成、视角切换与 `0x50188` 都不写它。按键门禁：飞行 `0x26f6a` 与地图 `0x27189` 是 0x400 子命令 0 仅有的两个发送者，`w`/`W` 均可；飞行只要求 +0 = 1，地图先要求上一视角 ≠ 6（不是从基地打开）再要求 +0 = 1；Warp 与基地上下文没有 `w`。`0x2be00` 的次序：间隔（+0xC8 ≠ 0 且 +0xC8 + 64×+0xA4 > 取样，无符号，等号通过）→ 把玩家当前位置存为起点 `0x1864c8` → 消耗 ≤ 能量（作弊标志可绕过）→ 提交。派发器与 `0x2be00` 不检查任务主状态、子状态、视角、被毁标志或 +0xCC。未设目标：按键时不发请求，静默；零距离：消耗为 0，能量 ≥ 0 时通过（能量非负为高概率）；标记失效：不读标记。所有拒绝都无提示、无音效。开始时不写能量；完成时（`warp-completion` 阶段，在同一帧 energy 阶段之后）按起点到实际到达点的距离计算消耗，并扣 ⌈消耗×(1+s/2)⌉、钳到 0，不调用耗尽处理（由下一次能量更新发现）；s（`0x175fdc`）在开始时置 0，只由渲染中的 Warp 视图 `0x50a28` 逐帧递增并钳到 ≤1，其完成时的取值归 Q-08（06）。+0xC8：玩家创建时为 0，正常玩法只由完成写入：将来时刻 取样 + max(trunc(64×A4×min(d÷30000,1)), 0x280)（A4 = 0 时为取样）。模式 3 初值：`0x2be00` 只写模式字节；同一消息中视角切换 `0x3f158(1, …)` 的 `0x50188` 把玩家位姿写为固定 Warp 路径空间的起点、速度 0、+0x78 为 0、指令速度为参考最大值，并在共享随机数发生器上至少抽取 60 次（表现路径）。页面与状态：进入时保存当前左页并切到页 6，不置状态显示重绘（+0xF0），离开时恢复（5 变 0）。12 型指示灯在 +0xC8 + 64×A4 < 取样时才亮（严格），与开始的非严格比较差一个时钟单位。
