# 09 — 原版预实验与运行观察

**契约来源：** [spec](../spec.md) 的 S-11、AC-15；[对照方法与判据](../spec.md#对照方法与判据)的运行与自助边界；Q-04 的历史探索、Q-08 的时长、Q-09 的分布。
**依赖：** 07。
**执行方式：** 自动。
**执行状态：** 仅由 [goal tracker](../goal.md#子任务跟踪) 维护。

## 工作范围

- 在私有副本中、独占基准会话下，先核实所需输入能否用[模拟器内输入](../../../../guides/runtime-measurement.md#模拟器内输入)取得：`m`、`w`、`p`、Esc 用 `key` 通道；地图鼠标位置与左键能否经原版自己的读取路径（例如在地图读取前写鼠标块的声明输入字段）取得，且不把光标世界点、目的地、位姿、能量等被测状态声明成设备；飞行到所需场景能否用已有的操纵设备字段完成。工具能力不足时，按既有契约增量扩展 `tools/baseline/` 并补合成测试。
- 只看原版的预实验：帧步长分布、地图读取间隔与输入取样边界、读数分辨率与运行间离散；核实所选世界范围内能否到达能量显示的最小值与两个颜色阈值、各数值对分段、可见边界与每类友方来源。
- 运行观察（研究部分）：历史探索是否保留（来源移开/消失前后的覆盖与敌机显示）；Warp 的时长与进度读数；到达偏移的样本；Q-10 中断分支的可达性。这些读数作为 03、06 静态结论的补充事实，交 07 的后续修订或 24/25 引用，不计入 AC-15 的合格运行。
- 读数满足[合格条件](../../../../guides/runtime-measurement.md#读数的合格条件)：身份、可读范围、稳定读数与停止证据；不合格不补零。
- 确实无法用允许的途径取得的操作，在完成证据中记录已尝试的途径、缺失能力与用户需要做的最小操作，再请用户在私有副本中操作；不用宿主层注入。

## 验收标准

- [ ] 输入途径已核实并记录：哪些由配方输入完成，哪些（如有）需要用户最小操作及原因；没有宿主层注入，没有把被测状态声明成设备。
- [ ] 预实验给出步长分布、取样边界、分辨率、离散与各边界/阈值的可达性，足以让 10 写出误差预算与样本理由。
- [ ] 历史探索、Warp 时长与到达偏移的运行观察已取得或按 spec 阻塞；新事实写入原版文档并带置信度。
- [ ] 改动 `tools/baseline/` 时 `python3 -B -m unittest discover -s tools/baseline -p 'test_*.py'` 通过；仓库中没有原版内容或读数。

## 验证方法

- 工具报告 `status` 为 `complete`，刺激全部 `applied`；按方案核对每个刺激在后续读数中的效果。
- 预实验不查看或计算新版的任何连续行为输出。
