# 10 — D-02 连续行为判据关卡

**契约来源：** [spec](../spec.md) 的 S-11、AC-15；[实施关卡](../spec.md#实施关卡) D-02；[对照方法与判据](../spec.md#对照方法与判据)。
**依赖：** 09。
**执行方式：** 需用户：明确批准 D-02 定稿的判据（用户本人的决定）；若用户在批准 goal 时预先授权 agent 按推荐方案定稿，协调者改为自动并在 goal 审批节记录授权。
**执行状态：** 仅由 [goal tracker](../goal.md#子任务跟踪) 维护。

## 工作范围

- 依 09 的预实验，为每类连续行为（Warp 时长与进度链、地图打开期间的推进、可见边界跨越时刻、世界坐标与距离等连续数值）在本 spec 新增判据节：单位、窗口、输入边界、分辨率、误差预算、样本数与理由；不使用未经推导的百分比、固定常数或“允许一个 tick”。
- 写明既有批准差异（P3-05 检查点 K、P3-06 入图归零、P3-02 CR-11 差异 1 与 8、项目 Esc 菜单）在每类对照中的配对条件。
- 写明采样覆盖下限中经 09 证实不可达的分支；不可达分支改为代码证据加 Node 独立期望核对，须经用户决定并在 spec 中记录。
- 新建行为文档 `docs/original/behavior/B-010-map-warp.md`（按[行为模板](../../../../original/behavior/_template.md)，中文；编号已占用时取下一个未用编号）：场景、观测量、暂停点、读法与判据批准出处，在采集前写定。
- 定稿早于正式采样（24），也早于看到新版的连续行为结果；取得批准后在本 spec 审批节记录日期与原话。
