# 03 — 地图鼠标研究（Q-03）

**契约来源：** [spec](../spec.md) 的 S-01、S-11，[原版研究](../spec.md#原版研究) Q-03，[执行检查点](../spec.md#执行检查点)规则 4，[战略地图输入](../spec.md#战略地图输入)的“初始位置”；AC-01 的研究部分与 AC-02 的地图项。
**依赖：** 无。
**执行方式：** 自动。
**执行状态：** 仅由 [goal tracker](../goal.md#子任务跟踪) 维护。

## 工作范围

- **静态（先做）：** 只读 Ghidra 读 `0x27800`：鼠标读取方式（INT 33h 的功能号与调用时机）、打开地图时的初始位置与跨次打开是否保持、限制区域、移动比例、左键在按下还是松开时生效、右键与其他按键、除选取框外是否另绘鼠标指针；主地图矩形的来源及其与地图布局内容的对应。结论与[战略地图投影](../../../../original/formats/executable.md#strategic-map-projection)、[B-001](../../../../original/behavior/B-001-strategic-map.md) 对照。
- **运行证据（静态不足时）：** 初始位置、触发时机等若静态无法定论，取运行证据。基准环境由协调者操作，同一时间一个 DOSBox-X，与 P3-06、P3-07 的会话协调；先核实所用输入路径确实经过 INT 33h（宿主鼠标经模拟器，或调试器在该函数处观察），注入只能证明其后的处理。所需工具尚不在本工作树时，只把依赖该事实的地图项记为阻塞并写明恢复条件，不以“中心、按下生效”等默认值代替。
- 交接：原版指针外观交 P3-13，世界坐标换算与像素量化交 P3-09；在摘要中注明。
- 输出到 `local/research/p3-05/map/`：调用与数据流、地址清单、运行样本记录与只写结构和结论的摘要，供 05 整理入库与定稿。
