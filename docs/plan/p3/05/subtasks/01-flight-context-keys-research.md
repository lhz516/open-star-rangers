**读键路径（已确认，代码）**

- 键盘轮询 `0x26284` 经 `0x3c970` 读一键：DOS 字符输入 `0x74ec8`（扩展键再读一次取扫描码）→ `0x75048` 换算（导航键与功能键经跳转表 `0x74f30` 与范围判断换成专用码，其余扩展键换成任何上下文都不处理的码）→ CapsLock 大小写互换 → 输入词匹配器（从不吞键）→ 按视角模式选上下文。飞行处理 `0x264a0` 先交 `0x27b44`（通讯）、再交 `0x27ab4`（能量页），未被占用才进入自身比较树。
- CapsLock：`0x3c970` 在 BIOS 标志的 CapsLock 位为 1 时互换字母大小写，抵消 BIOS 的 CapsLock，使字母大小写只取决于 Shift（BIOS 侧为已确认，模拟器源码）。
- 作弊门禁 `0x3cb78` 返回的标志只由输入词匹配器切换（引用扫描只有匹配器经其表项指针写入）。
- 模拟器侧（已确认，模拟器源码）：BIOS 按 Alt、Ctrl、Shift、无修饰的优先次序取码；DOS 控制台在 VGA 机型上用增强 BIOS 读键，所以 F11、F12、小键盘中键与 Ctrl+方向键能到达游戏，灰色导航键与小键盘导航键得到相同的码。宿主物理键到 PC 扫描码（macOS/SDL）与布局未追踪（标准 US 键为高概率），由 06 的运行样本核对。

**Q-01：飞行处理与前置处理（已确认，代码；数据键为已确认，数据）**

- 动作族：油门（Backspace、`\`、`+`/`=`、`-`、Shift+数字十档、Enter 手动匹配、Ctrl+Enter 辅助开关）；武器（Space、`/`、`,`/`<`、`.`/`>`）；目标（`t`、`f`、`r`、`y`、`u`）；视角（F1–F10、方向键、Home、PgUp、小键盘中键）；页面与模式（`e`、`d`、`m`、`w`/`W`、`a`、Esc 选项页、Shift+`J` 摇杆页、F11 灵敏度）；暂停 `p`。另有三键不在 README 中：Shift+`P` 切换屏幕闪光开关 `0x175c54`；Shift+`\` 截图（`0x174b18` → 帧末 `0x5800c` 写编号 BMP 文件）；`b` 经消息 0x200000 由 `0x38780` 以玩家姿态生成一个种类 0x4000 的对象（M2ID 槽 14，玩法作用未确认，交 P3-08/P3-10）。
- 作弊门禁下：大写 `D`、`I`、`M`、`T`，小写 `i`，F12 及其 Shift/Ctrl/Alt 形式。
- 无作用：未按 Shift 的数字、`?`、`x`、`j`、`k`、`l`、进入比较树的 `c` 与 `s`/`g`/`S`/`G`、End、PgDn、Ins、Del、F1–F11 的全部 Shift/Ctrl/Alt 形式、主键盘的全部 Alt+字母/数字/标点，以及其余可打印码与控制码。
- `0x27b44`：左显示页 2–4（菜单）时，只占用与当前菜单某项按键相符的键（`0x27e10` 两侧经 `0x754d9` 折叠大小写，取首个匹配）；其他页只占用小写 `c`，且仅当通讯子系统（槽 0xD）未处于状态 2。菜单键：类别菜单 `0x2c850` 与对象列表 `0x2c9d0`（只列状态不低于 7 的对象）从键表 `0x174b40` 的第 1 项起按位置生成（先数字 1–9，再字母），第 36 位起改为位置的十进制数字、被前面的项遮住；数据键只有数字 1–7 与 `x`（已确认，数据）。每个菜单的最后一项值为 0，选中即关闭菜单、回到保存的页。`0x27ab4`：只在页 1，`S`/`s`/`G`/`g` 在档位实际改变时被占用。按页与条件的逐码结果在 `out/prefilter-codes.tsv`。

**修饰组合与小键盘（已确认，代码与模拟器源码）**

- Shift+字母为大写（与 CapsLock 无关）。Ctrl 或 Ctrl+Shift+字母得到控制字符：Ctrl+H 同 Backspace，Ctrl+J 同 Ctrl+Enter，Ctrl+M 同 Enter，Ctrl+[ 同 Esc，其余 Ctrl+字母无作用。
- Alt：主键盘的全部 Alt+字母/数字/标点得到无人处理的码，Alt+空格即空格，Alt+Enter 不产生键，Alt+F1–F11 无作用（所以 README 的 Alt+F4 并不切换视角）。故按住 Alt（主炮）期间，飞行中只有空格仍立即起作用（另有作弊的 Alt+F12）；Alt 加小键盘数字是 DOS 十进制字符输入，在松开 Alt 时才送出一个字符。这是与项目“Alt 不抑制其他绑定”的差异。
- Shift+数字为十档；Shift+`/` 得到 `?`，无作用；Shift 与 `,` `.` `=` `\` 分别为上一导弹、下一导弹、加速、截图；Shift 不改变 Backspace、Enter、Esc、空格。Ctrl+数字无作用。
- 小键盘：NumLock 与 Shift 同为关或同为开时，7/8/9/4/5/6/2 分别为 Home（F2 别名）、上（前视 F1 别名）、PgUp、左、中键、右、后视角（2026-10-16 更正旧称“下视角”：下是方向键名，不是观察方向，见[键位表](../../../../original/input/key-map.md#小键盘p3-0501)），1/3/0/. 无作用；恰有一个为开时为数字（飞行中无作用，在通讯菜单中与主键盘数字一样选项），`.` 为下一导弹。Ctrl 下 7/9/4/6 仍为相同视角，其余无作用；Alt 下为 DOS 十进制字符输入。小键盘 `+`、`-`、`*`、`/`、Enter 不受 NumLock 与 Shift 影响，分别为加速、减速、Shift+8 档、下一主武器、手动匹配；其 Ctrl 形式除 Ctrl+小键盘 Enter（辅助开关）外无作用。灰色导航键不受 Shift 与 NumLock 影响。

**`I`/`J`/`K`/`L`（K 规则 1 的输入；已确认，代码与模拟器源码）**

- 飞行处理：`i`、Shift+`i` 只在作弊门禁下有作用；`j`、`k`、`l`、Shift+`k`、Shift+`l` 无作用；**Shift+`j` 打开摇杆设置页（非作弊）**；**Ctrl+`j` 与 Ctrl+Shift+`j` 与 Ctrl+Enter 相同，切换速度辅助（非作弊）**；Ctrl 与 Ctrl+Shift 配 `i`、`k`、`l` 无作用；Alt 形式无作用。
- 通讯前置处理：四个字母只在对象列表页、列表至少有 18、19、20、21 项时被占用（I、J、K、L，大小写不敏感）；控制字符从不是菜单键。能量页不占用它们。Warp 中的核查归 02。

**Q-02 飞行部分（已确认，代码）**

- 只有小写 `p` 进入暂停（Shift+`P` 是闪光开关）。暂停冻结游戏时基（`0x258f8`）与声音（`0x538a0`），然后在阻塞读键循环中等待 `p` 或 `P`；期间没有帧、绘制、摇杆、鼠标、AI 或调度，其他键经输入词匹配器后丢弃；Esc 不结束暂停。
- Esc 投递页面请求（消息 0x400 子命令 10），在本帧消息循环中由页面运行器 `0x32fec`（时间与声音暂停）显示 `0x186840` 指定的页（已确认，代码；战役任务中为页 9，见 executable 的战役重开一节）。前置处理从不占用 Esc，所以通讯菜单打开时 Esc 仍进入该页。Shift+`J` 用同一子命令的另一参数，经 `0x32f80` 把页号临时设为 0xE 再运行同一页面运行器（已确认，代码）。页 9 是选项菜单（MESC 5013）、页 0xE 是摇杆设置页（MESC 5009）出自页面资源中的控件名（已确认，数据，P3-01 的本地读数）；页 9 自身的 Esc 热键为“继续”属高概率（数据，未追页面代码）。
