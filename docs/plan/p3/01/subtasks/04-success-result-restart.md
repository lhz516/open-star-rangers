## 工作范围

- **结果状态：** 从主任务流程 `0x3266c` 与调试命令 `0x282bf` 引用的成功与失败状态出发，定位设定任务结果的代码与结果值的存放（已确认，代码）。把成功、失败与其他结束方式（主动退出、放弃等）的结果值和设置位置都记下，供 05 使用。
- **成功路径：** 追踪所选任务（group 0 / slot 1，SCEN 3019，难度 19）中到达成功结果的一条正常玩法路径（至少高概率）：可发生的前提 → 触发 → 结果。与 [B-003](../../../../original/behavior/B-003-campaign-flow.md#成功到下一关) 的成功观察对应，并注明该观察的限度。调试命令强制成功、改写内存或身份未核实的观察不计为可达性证据。
- **重开入口：** 研究战役设置页“重开任务”入口的行为：恢复到哪一状态、哪些战役状态保留（至少高概率）；达不到时记为未确认并写明原因，不阻塞本项。
- **基准运行（需要时）：** 由协调者用 Computer Use 在私有副本中开始新战役（难度 19）进入所选任务，观察成功流程；需要读数时用 02 完成后的工具。原版运行不改动基准文件。
- **记录：** 代码事实写入 executable 的新节（英文，只记地址与作用）；成功观察与重开行为写入 B-003；U-022 的结果条件线索更新，负责阶段不改。脚本与输出在 `local/research/p3-01/terminal/`。
