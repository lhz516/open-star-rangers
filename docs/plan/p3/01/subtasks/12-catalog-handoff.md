# 12 — 对照目录证据途径与契约交接

**契约来源：** [spec](../spec.md) 的 S-01、S-08、S-10、AC-13、AC-15；[闭环步骤](../spec.md#闭环步骤)、[闭环运行](../spec.md#闭环运行)、[缺省清单](../spec.md#缺省清单)、[标注规则](../spec.md#标注规则)、[视角范围](../spec.md#视角范围)、[规则对照目录](../spec.md#规则对照目录)、[表现对照目录](../spec.md#表现对照目录)、[对照方式与判定](../spec.md#对照方式与判定)、[对下游任务的约束](../spec.md#对下游任务的约束)；技术决定 2、6、7。
**依赖：** 03, 04, 05, 07, 08, 09, 10。
**执行方式：** 自动。
**执行状态：** 仅由 [goal tracker](../goal.md#子任务跟踪) 维护。

## 工作范围

在本项完成证据中形成交接记录，并更新行为模板：

- **R 条目证据途径（AC-13）：** R-01 至 R-23 每项记录至少一条证据途径（代码入口地址、可读的运行时量或可观察的现象）、当前置信度、限制与负责任务，吸收 03–10 的研究结果。尚无途径的非前置细节写出具体的恢复计划与风险，不写成功标签；这不能豁免本任务的 AC-02、AC-03、AC-05、AC-08、AC-10 门槛。
- **映射：** L-01 至 L-10、G-01 至 G-08、R-01 至 R-23、V-01 至 V-06 与 [P3 阶段索引](../../tasks.md#4-任务范围与责任)的任务范围逐项映射；指出不一致之处。若需修改 spec 或阶段索引，在证据中写出建议，交协调者与用户，不由本项修改。
- **契约交接（AC-15）：**
  - L：成功、失败与重试的运行组合，配置身份与拒绝边界；
  - G：每项的依据、必须保留的信息、标注规则与补齐阶段；吸收 08 的 G-02 实例与 09 的视角结论；
  - R、V：负责任务、对照方式、完成门槛（核心规则不能套用视觉范围例外）；
  - 明确这些都是下游契约，没有下游测试或实现被写成本任务已通过。
- **行为模板：** 更新 [行为模板](../../../../original/behavior/_template.md)，使容差记录包含：原版版本与配置（含 cycles）、测量方法、样本数、单位与分辨率、误差来源与误差预算、事先经用户批准的判据；与 spec 的[对照方式与判定](../spec.md#对照方式与判定)一致。
