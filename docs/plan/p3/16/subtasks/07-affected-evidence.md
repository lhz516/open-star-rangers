# 07 — 受影响证据的补验与适用性定稿

**契约来源：** [spec](../spec.md) 的 S-04、AC-07、AC-08（补验部分），以及[技术决定](../spec.md#技术决定) 3。
**依赖：** 01、04、19。
**执行方式：** 自动。
**执行状态：** 仅由 [goal tracker](../goal.md#子任务跟踪) 维护。

## 工作范围

- **影响分析：** 以 01 的底稿为基础，按 04 的最终差异逐类判断影响。比较范围包括 Core 生产者对 HUD、音效、事件时序与画面的间接影响，不只看改动的文件。
- **补验受影响的类别：** 按原判据重做新版一侧。
  - 预计至少涉及：R-15、R-16（Warp 门禁与开始）、R-17、R-18（停靠与离港）、P3-15 的联合闭环与 replay。实际清单以影响分析为准。
  - 只有直接读取合格的私有原版样本、输出原方法要求的全部观测量与比较结果的检查才算重做；对应单测通过不算。
  - 原样本的身份、场景、配置或所需字段不适用时，保留缺口，不运行 DOSBox-X、不增加启动。
- **需要用户的补验：** 若影响分析表明 P3-14/26 的试听项或 P3-15/06 的物理键盘项受影响，交协调者请用户重做受影响的部分，并写明原因。未受影响则复用，并写明理由。
- **适用性表定稿：** 覆盖 S-04 的全部类别。每类写原候选、内容与环境，实际差异，原判据，以及复用理由或补验结果或缺口；并吸收 06 的复跑结果（06 完成后由协调者告知）。

## 不包含

- 修改 R/V 的原分类或容差；新的原版运行；R-22 的处置（12）；判定汇总（13）。

- [ ] AC-08：受修复影响的对照已按原判据在最终候选上重做新版一侧，结论与原分类分开记录；不适用的样本保留为缺口。
- [ ] 受影响的测量、画面、试听与实机证据没有被普通单测替代；需要用户的补验已写明原因，或写明不受影响的理由。
