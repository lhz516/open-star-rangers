# 06 — 完整 Runtime 契约最终对齐

**契约来源：** [spec](../spec.md) 的 S-01 至 S-08、AC-01 至 AC-14，包含“不包含”范围与技术决定 1–14。
**依赖：** 01, 02, 03, 04, 05, 07。
**执行状态：** 仅由 [goal tracker](../goal.md#子任务跟踪) 维护。

## 工作范围

- 逐项核对已批准 spec、[goal 覆盖表](../goal.md#验收覆盖)、01–05 的真实代码与完成证据；验证最终公共类型和行为完整，没有未接入的方法、接受后静默忽略的参数或虚假的录制结果。
- 运行最终 `pnpm check`，确认 Runtime、既有 Core、解析器与工程边界测试均通过，无删除、跳过或放宽上游测试的做法。
- 复核关键不变量：
  - Core 始终纯，唯一 step 路径由 Runtime 持有；消费者没有可推进世界或任意发布事件的入口。
  - 时间换算溢出拒绝，有限超限才截断；数值容差不用于放宽 tick 数。
  - 输入与命令在帧边界定格，输出先更新后分发；分发副作用只作用后续 tick。
  - 同步监听器与错误汇总契约成立，不以 Promise rejection 假装同步捕获。
  - Core 故障的成功前缀保留、通知批次丢弃；导出不是 Event Bus 投递日志。
  - 两份 Render State 隔离；recording 不另建世界或重做 Core 哈希/记录。
- 复核 AC-07 同帧跨 tick 事件收集顺序、AC-14 ID 耗尽守卫的代码审阅证据；不能用现有场景无法生成的测试场景或不可达次数冒充自动验收。
- 范围核对：Core 生产与既有测试、App/main、依赖清单/锁文件、构建及类型配置不变；无浏览器接线、存储、原版读取或原版内容。
- 验证全部通过后，允许在 [STATUS](../../../../STATUS.md) 更新 P1-04 的部分交付证据和下一步，但 **GameRuntime 退出项仍不勾选**：它还需要 P1-05 的控制通道与生命周期。本目标不宣称浏览器、StrictMode/HMR 或整个 P1 通过。
- 本项只做验证与证据记录；发现实现缺口时新增未使用 ID 的修复子任务，插到本项之前并加入依赖，不在本项实现功能或改 spec。
