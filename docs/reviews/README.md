# 阶段评审记录

每个阶段结束时写一份评审记录，文件名为 `P<阶段>-<主题>.md`，例如 `P0-feasibility.md`。写完即冻结，不再修改；之后的变化写进新的记录或 ADR。

每份记录包括：

1. **结论**：通过 / 有条件通过 / 不通过；不通过时写明缩小范围或调整路线的方案。
2. **退出条件逐项核对**：对照[总计划 §12](../plan/master-plan.md#12-开发阶段与验收条件)和相应阶段 `tasks.md` 的责任覆盖，逐项附上证据链接并给出判定。
3. **遗留事项**：未关闭的 `U-###` 及其负责阶段。
4. **对后续阶段的影响**：需要调整的计划或新增的 ADR。
