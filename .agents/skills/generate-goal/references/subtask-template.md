# Subtask 模板

输出到 `docs/plan/<phase>/<task>/subtasks/NN-<slug>.md`。替换全部占位符；依赖必须与 goal tracker 一致。保留验收 checkbox，“完成证据”初始为空，不另设执行状态。下面链接相对生成后的 subtask。

“执行方式”写 `自动`，或者在需要用户亲自操作（实机核对、真实界面确认等）时写 `需用户：<用户要做的事>`。“写入范围”列出本项可能新建或修改的每个仓库相对路径或 glob，包括测试、文档、夹具以及 `local/` 下的研究输出；每项一行，路径放在反引号中。本 subtask 文档本身不必列出。goal.md、阶段 tasks.md 与 docs/STATUS.md 只由协调者修改，不得列入。只写本文档时写“无。”。execute-goal 用写入范围判断哪些子任务可以并行；拿不准时列出目录 glob，误判重叠只会让工作串行。
