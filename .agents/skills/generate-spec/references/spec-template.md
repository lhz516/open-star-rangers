# Spec 模板

输出到 `docs/plan/<phase>/<task>/spec.md`。替换全部占位符；不适用的部分写明原因。以下链接相对生成后的 spec，而不是本模板。`status` 初始为 `draft`，不能自动批准。

```markdown
---
type: plan
status: draft
phase: "[PHASE]"
task: "[TASK]"
updated: "[YYYY-MM-DD]"
---
```
